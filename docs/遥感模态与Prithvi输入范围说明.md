# 遥感模态与 Prithvi 输入范围说明

本说明对应当前项目的 `configs/models/prithvi.yaml`：Prithvi-EO-2.0 300M-TL；不将整个 Prithvi 家族的不同模型与任务混为一谈。官方资料核对日期为 2026-10-14。

## 1. 除光学与 SAR，还有哪些数据

以下按工程输入类型分类，既有传感器观测，也有派生产品，并非严格互斥的物理分类。广义光学也可以包括热红外；本项目“光学入口”目前特指以反射为主的可见光、近红外、短波红外影像。

| 类型 | 主要信息 | 本项目的处置 |
| --- | --- | --- |
| 全色、RGB、多光谱、高光谱 | 不同光谱采样方式的光学观测；高光谱仍属于光学的一类 | 首版主要支持实际训练过的反射型多光谱，不能仅凭可变通道接口宣称任意高光谱泛化 |
| 热红外 TIR | 热辐射相关观测，可形成辐亮度、亮温或经反演的地表温度产品 | 尚无 NAS 明确数据证据，首版暂不纳入；辐射量和单位不同于反射率 |
| LiDAR 点云/波形 | 主动激光测距与三维结构信息 | 不在首版输入范围；点云/波形需要相应编码与配准，不能直接当普通影像通道 |
| DEM/DTM、DSM、坡度等 | 地形或表面高度及其派生量；DSM 可含树木建筑表面，裸地形模型强调地面 | NAS 已有相关资料；先用于预处理和分组评测，额外输入或监督另做消融 |
| 被动微波 | 与 SAR 主动雷达不同的微波辐射观测 | 当前清单未确认，暂不设计专门分支 |
| 气象、再分析、地面观测和矢量 GIS | 环境与地理辅助信息；不都属于遥感影像 | 以后按任务增加，明确时间可用性、空间尺度及标签泄漏风险 |

立体影像是采集方式，可用于重建高程，并非新增一种光谱模态。DEM/DSM 可由激光、雷达、立体摄影等生成，所以高程产品与其测量来源也要区分。[USGS 高程与 LiDAR 说明](https://www.usgs.gov/faqs/what-difference-between-lidar-data-and-a-digital-elevation-model-dem)、[DEM 与 DSM 产品说明](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services)

## 2. 当前 Prithvi 是否全部包含

**没有。Prithvi-EO-2.0 的标准预训练输入为六个 HLS 光学波段：Blue、Green、Red、Narrow NIR、SWIR1、SWIR2。** 官方模型说明给出 30m HLS 预训练与时序输入；TL 版本包含时间/地理位置嵌入，TL 不表示 Thermal。[官方 300M-TL 模型说明](https://huggingface.co/ibm-nasa-geospatial/Prithvi-EO-2.0-300M-TL)

| 输入/能力 | 当前标准预训练模型的范围 |
| --- | --- |
| RGB、窄近红外、SWIR1/SWIR2 | 属于原始六波段预训练输入 |
| 多时相光学 | 支持时序输入，实际任务仍需锁定日期选择和缺测处理 |
| 日期和地理位置 | TL 元数据编码；不是额外遥感影像模态 |
| 热红外 TIR | 不在这六个预训练波段中 |
| SAR | 不在该标准预训练输入中 |
| DEM/DSM、LiDAR | 不在该标准预训练输入中 |
| 任意八/十/十三波段、高光谱或 GF-2 四波段 | 与原始输入不完全一致，需要明确波段选择、入口适配/权重处理和训练协议；不能默认全部原生支持 |

这不等于无法基于 Prithvi 扩展新输入；意味着适配后的模型需要额外设计、训练和验证。软件框架允许配置额外通道，不证明发布权重学过该模态。原始下游数据集含 DEM 或 SAR，也不证明所用参考配置实际输入了它们。

## 3. SWIR 不等于热红外

在常规地表反射率任务中，NIR/SWIR 与 TIR 采用不同物理量和处理方式。Landsat 的官方波段表将 SWIR 与 Thermal Infrared 分开列出。[USGS 波段说明](https://www.usgs.gov/faqs/what-are-band-designations-landsat-satellites)

火烧迹地识别可以利用火后植被、含水量和地表光谱变化，不等于直接观测正在燃烧物体的温度。仅凭 Prithvi 能做火灾相关任务或拥有“红外”波段，不能推断其输入热成像。也不能将 TIR 值放进 SWIR 通道沿用反射率归一化。

对自研模型，暂时坚持光学＋SAR；DEM/DSM 后续优先作为有数据支撑的扩展。热红外只有在目标任务、数据质量和规模明确时再加入，单独定义单位、入口及缺失处理，不因对照模型名称而扩大首版范围。
