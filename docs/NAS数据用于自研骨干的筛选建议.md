# NAS 数据用于自研遥感骨干的筛选建议

依据：2026-10-12 版 `E:\Supermap\GIS Advanced Lab\NAS数据清单_简版.md`。本次只读取清单，未访问 NAS 原始数据、核实样本数量或运行影像检查。以下是候选用途，不代表数据已可直接训练。

目标更新（2026-10-15）：团队已有强高清 RGB 主干，新模型以非 RGB 光谱、SAR、多时相与真实多分辨率适配为重点，主要依赖 RGB 的任务只要求基本可用。中国地区优先、5–15M 参数、单张 4090。对应[骨干设计草案](./自研轻量光学SAR骨干设计草案.md)。

到公司可直接填写[NAS 现场核查表](./NAS现场核查表.md)，包含逐项路径、勾选项、每景记录模板和当天汇总。训练后的评价方法见[自研骨干接入现有评测计划](./自研骨干接入现有评测计划.md)。

## 1. 结论

清单不能支持“大部分数据只有 RGB”的判断：多个目录明确记录四波段多光谱，GF-6 WFV、GFDM、ZY1E 记录八波段，S2 L1C 记录十三波段，另有多种雷达。目录种类不等于文件数或数据量；实际 RGB 占比仍未知。软件中的彩色显示也不能说明原始文件只有三个波段。

建议主体：中国 S1/S2 多光谱/SAR 时序＋元数据可靠的国产多光谱；FBP/NAS 高清四波段和 RGB 标签作为辅助空间监督。八波段是否提供额外有效光谱信息须核实，不能用通道数替代语义判断。RGB 可以贡献纹理与边界，但不占据主要训练和搜索预算。

## 2. 优先核查和纳入的候选

表中分辨率、波段数均沿用清单样例，不扩展为整个目录的保证。四波段的具体名称与顺序需读取元数据；八波段不能直接推断为某个固定红边/SWIR 组合。

| 候选 | 清单证据 | 对模型的价值 | 采用条件 |
| --- | --- | --- | --- |
| GF-2 | 四波段，样例网格 3.24m；GF2 与辽宁水利目录 | 与 FBP 接近的高分辨率输入域，补充中国地区地貌与空间细节 | 优先原始多光谱；确认传感器分辨率、当前网格、处理级别、日期和地域；不直接当成 FBP 的 4m 同产品 |
| GF-7 | 四波段；西藏、川西等目录 | 中国山地和地形复杂地区的数据候选 | 地名只作为线索，实际覆盖与正射质量需核实；全色/立体与多光谱分开管理 |
| SuperView-1 | 广东目录样例四波段、2m | 较细空间纹理、跨传感器和中国地区适配 | 排查融合、匀色和原始版本；2m 是样例，不能套用所有 SuperView 产品 |
| BJ2/BJ3、JL1KF | 四波段样例，GSD 部分未知 | 增加真实高分辨率传感器变化 | 核实光谱、位置与场景数量；建议保留部分传感器/地区作为未见域测试 |
| GF-6 WFV、GFDM、ZY1E | 三类八波段数据 | 最值得先检查的可变光谱输入候选，可能补足四波段训练的不足 | 必须取得波段名称/响应、数值单位、分辨率、质量；不填入猜测的波长 |
| Sentinel-2 L1C | 十三波段，10/20/60m | 同一传感器内多分辨率、多光谱，以及时序候选 | 是否多时相取决于相同 footprint 的真实日期数；L1C 与地表反射率训练域分开处理 |
| Sentinel-1 GRD | VV/VH 各单文件 | 首版 SAR 最直接的输入路线 | 核实标定、噪声处理、地形校正与配准状态，保存轨道及单位；不能默认 GRD 已是可直接对齐的后向散射栅格 |
| 已有 RGB 分割集 | `wxm/training_data/Images`、`Masks` | 若标签可靠，可快速监督训练细节分支，并验证遥感 RGB 输入路径 | 核对类别、人工/模型标签来源、GSD、地理分组和图像标签对齐 |

建议首轮优先抽查 S1 GRD、S2、GF-6 WFV、GFDM、ZY1E，重点统计同地点日期与光学/雷达配对；再查 GF-2、GF-7、广东 SuperView-1 和 RGB 标注集作为辅助。每类先选约 5–10 景，覆盖不同目录/日期/处理版本；不足则检查全部。这是可用性审计样本，不是正式训练量。

## 3. 可以补充，但不必首轮全部纳入

| 数据 | 候选用途与取舍 |
| --- | --- |
| GF-1、GF-1B/1C、GF-6 PMS、CBERS-04A | 四波段真实传感器/尺度变化；优先选能补足地点、季节或 GSD 的场景，避免重复覆盖压倒其他数据 |
| CM1、SuperViewNeo1/Neo1-03 | 多光谱适配或未见传感器测试；先确认 GSD、处理版本和数据量 |
| IKONOS | 清单已有 B/G/R/NIR 分文件；单文件单通道不等于整组只能做灰度输入。按配准与波段对应关系读取，可用于异构文件格式和光谱输入验证 |
| WorldView 其他目录 | 四波段与高分辨率候选；先确认覆盖是否符合中国主目标 |
| WorldView 美国目录 | 更适合留作地域外部测试或少量预训练补充；不应因文件多而占据中国主任务采样主体 |
| GF-3 | 有价值的国产 SAR 扩展；优先从元数据完整、可标定和配准的实值产品开始。HH/HV 与 VV/VH 用不同极化标识，不能互换 |
| ICEYE GRD | 更广雷达传感器适配或外部测试候选，质量与成像参数核实后再加；名称本身不能证明样例分辨率或地域 |
| GF-1/其他 REF、SuperView DOM、正射/融合/匀色结果 | 可训练或验证处理域适应，记录来源；原图与派生版本归同组，不能一边训练一边独立测试 |
| 中国参考底图、蒙古/巴基斯坦影像 | RGB 空间学习或地域外部测试候选；后两者与中国主目标相关性较低，且原始产品信息尚不完整 |

同一数据不同时充当训练补充和“未见传感器”测试；先确定用途，再锁定划分。全色融合 RGB/四波段可以作为实际产品域，但不能当作未处理的原生多光谱。

## 4. 暂缓或只用于辅助工作的数据

| 数据 | 首版处置 |
| --- | --- |
| LT-1 SLC、S1 SLC、GF-3 中疑似复数产品、ICEYE SLC | 先审计复数/IQ 表达、极化和处理链；需要转成一致的已校准实值表示才能进入当前设计。不把两个通道直接当作两个极化 |
| TerraSAR | 描述不足，先查产品类型、波段/极化、GSD 与地域，暂不分配训练权重 |
| ZY3、JLGF 中仅确认的全色/立体部分 | 可留给后续单波段或立体扩展；若查到对应多光谱，再提升优先级。首版不为零散全色数据扩张目标 |
| DEM/DSM | 优先服务地形校正、配准审计和按高程/坡度分组评价；直接输入模型或作监督目标均作为后续单独消融。DSM 不默认是可靠人工真值 |
| 无人机 JPEG | 若只是未正射、视角变化较大的原始照片，首版暂缓；若有可靠 DOM、GSD/坐标和标注，则可补充高分辨率空间训练 |
| 建筑 Mask/结果、`wxm/202409GPA` 推理结果 | 先查标签来源。人工核验结果可监督；模型结果只能按伪标签管理，并保留人工审计集，不能作为独立真值 |
| `temp`、`empty`、新特性测试材料 | 明确排除训练主体，用于读取器和异常输入测试；工程文件、构造数据、损坏样例不计真实训练样本 |

S1 官方产品定义区分 SLC 复数数据与 GRD 检测产品；SLC 的 I/Q 不表示两种极化。该定义解释审计必要性，不能据此断言清单中 GF-3/LT-1 文件的具体编码。[S1 产品说明](https://sentiwiki.copernicus.eu/web/s1-products)、[产品规格](https://sentinels.copernicus.eu/documents/247904/1877131/Sentinel-1-Product-Specification-18052021.pdf)

S2 L1C 是大气顶反射率，L2A 是地表反射率；若与此前地表反射率训练池合并，需作一致处理或明确域标记。不要仅除以一个常数就假定完成大气校正，具体 scale/offset 按产品元数据读取。[S2 产品说明](https://sentiwiki.copernicus.eu/web/s2-products)

## 5. 最关键的缺口：训练规模和真实时序

清单没有每类独立景数、有效面积、采集日期分布与标签统计，因此目前无法判断 NAS 是否足以支撑全部预训练。多个 `testData` 目录可能只是少量测试场景；也可能保存足够多的原始大图，必须统计后判断。

多时相必须是同一地区的多个真实日期；不同城市、不同卫星、同景的原始/正射/融合版本都不能自动组成时序。影像生成时间、文件修改时间和目录名不代替采集时间。光学/SAR 配对须同时核查 footprint 与日期差；单纯位于同一省份不足以配对。

将清单升级为逐景 manifest，至少包含：

- `scene_id`、原始路径、原始/派生关系、传感器、处理级别、采集日期、地域 footprint。
- 宽高、CRS/affine、当前网格间距、原生 GSD（已知时）、有效面积、波段名称/顺序、dtype、单位、scale/offset、nodata。
- 光学云/阴影和图像质量；SAR 极化、实值/复数编码、轨道、数值域与标定状态。
- 标签类别与人工/伪标签来源，划分组、重复/重叠组、是否可用于独立测试。

读取到的 3.24m、7.87×7.90m、9.84×10.88m 应先视作样例网格描述，核实其坐标单位和计算方法；不能据此认定传感器原生分辨率。经纬度坐标中的度不能直接作为米，重采样网格也不代表增加真实空间细节。

先按传感器×地区×日期汇总独立景数及重叠程度，再按同地点时间序列统计可配对观测数。全色、多光谱、融合、压缩副本和不同目录拷贝按源场景关联去重。

## 6. 对训练方案的具体调整

1. 优先建设非 RGB 光谱/SAR/时序主池，将 FBP 和 NAS 高分辨率四波段作为辅助空间监督；少量优质标签可设独立任务头。记录现有 RGB 主干能处理的输入范围，作为应用对照。
2. 从八波段候选中先选元数据最完整的一类，验证“同一模型接收四波段和八波段”是否稳定，再增加传感器；不一次混入全部未知数据。
3. S1 GRD 与 S2 使用实际可用日期组成时序池；若 NAS 时序稀疏，仍需外部补充。分开训练的 GF-2 与 SAR 不能作为已验证联合融合的证据。
4. 按能力池管理采样：多光谱主池、时序/SAR 主池、空间细节辅助池。原 GF-2:S1/S2=60:40 默认取消；不根据目录数量设比例，核查有效量后按主要任务开发集曲线分配预算。
5. 锁定独立地区与部分传感器作保留测试，再开展任何自监督。NAS 与 GID/FBP 也要按位置和日期排查重叠；未知重叠不能声称严格外部泛化。

最优先的下一步是生成逐景元数据统计和小样本质量报告，而不是复制全部 NAS 或直接开始大规模训练。本次未修改 NAS 原清单，未下载或转换影像。
