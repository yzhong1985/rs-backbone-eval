# Backbone 能力评分卡（D1–D4）与输入扰动协议

本文档定义"如何判断一个 backbone 好不好"的四个维度，以及 D2 输入灵活性的
具体扰动协议。它是结果汇总口径，不改变任何实验轨道（B0–B3）的定义。

## 1. 维度与轨道的关系

- **轨道（B0–B3）** 描述"怎么把模型接到任务上"：B0 复现参照，B1 全量微调，
  B2 冻结表征，B3 原生输入。轨道决定训练过程。
- **维度（D1–D4）** 描述"从哪些角度看 backbone 的能力"，是把多条轨道、多个
  任务的结果汇总后的视角。

| 维度 | 名称 | 主要使用的轨道 | 量化方式 |
|---|---|---|---|
| D1 | 任务效果 | B1（主）、B2（辅） | 每个任务上 `模型均值 ÷ 该任务最优模型均值`，再对任务取平均；1 表示每个任务都最优 |
| D2 | 输入灵活性 | B2（冻结，推理时扰动） | 扰动后指标 ÷ 原始指标（保持率） |
| D3 | 适配成本 | B1、B2 | B1 训练耗时的相对值，并列出参数量、峰值显存、B1−B2 的微调增益 |
| D4 | 稳定性 | B1 | 各任务种子标准差的相对值 |

评分是**相对值**：只在同一份报告内可比，加入新模型后会变化。覆盖任务数不足
时，该维度只能参考。

## 2. D2 输入扰动协议

### 2.1 原则

- 一次训练，在**推理阶段**施加扰动并分别评估；不重新训练。因此 D2 衡量的是
  "冻结特征对输入变化的容忍度"，不是"重新适配后的能力"。所有结果都会标注
  `perturbation_note = inference-time input robustness, not re-adaptation`。
- **统一填充协议**：缺失波段用**训练集该波段的均值**替换，绝不补零（设计禁止
  零填充）。三个模型使用完全相同的填充方式和扰动参数。
- 扰动的指标记录在独立的 split 名下（例如 `test_band_drop-NIR_NARROW+SWIR_1+SWIR_2`），
  不覆盖原始 `test` 结果，原始结果始终保留。

### 2.2 默认扰动集合

| 名称 | 参数 | 目的 |
|---|---|---|
| RGB only（主） | `band_drop:NIR_NARROW,SWIR_1,SWIR_2` | 只保留可见光，直接回答"模型有多依赖红外"；也是现实中常见的传感器配置 |
| SWIR only 缺失（次） | `band_drop:SWIR_1,SWIR_2` | 针对强依赖 SWIR 的烧毁区任务（T2、T3） |
| 分辨率 ×2 | `resolution:2` | 降采样再插值回原尺寸，模拟 20 m 级输入 |
| 分辨率 ×4 | `resolution:4` | 模拟 40 m 级输入 |

可选诊断项（默认关闭，若启用需标注为非现实场景）：`band_drop:BLUE,GREEN,RED`
（只留红外），用于观察模型实际依赖哪些波段。

不含可见光的输入（如 SAR）不通过扰动覆盖，而是用独立任务 T1S 处理。

### 2.3 验收标准

1. **一致性**：`none` 的评估结果必须与原始 `test` 完全一致。
2. **单调性**：丢三个波段应比丢两个退化更多；分辨率 ×4 应比 ×2 退化更多。
   出现反常需先排查实现。
3. **交叉验证**：至少对一项扰动，用真实低分辨率数据（而非合成降采样）确认
   结论方向一致。
4. **可追溯**：填充方式、扰动参数、是否重新训练都写入运行记录 tags。

## 3. 已知局限

- 合成降采样是低分辨率的代理，不等于真实低分辨率数据。
- 波段缺失用均值填充是一种人为约定；对 Clay 这类"原生支持任意波段"的模型，
  另一种测法是直接告诉它只输入剩余波段。本协议统一采用均值填充，以保证三家
  可比；若后续采用原生测法，必须作为单独设置报告，不与本协议混排。
- D2 只覆盖单日期任务（T1）。多时相任务（T5）的时相减少扰动成本较高，暂缓。
