### 波段物理意义能确认到哪一步

**GF-6 WFV：可以从本地原始 XML 明确确认顺序与波长。** 六张 TIFF 均为 8 通道；25 点/文件抽样中八通道均有非零变化。

| 通道 | XML 波长 | 解释 |
| --- | --- | --- |
| B1 | 450–520nm | 蓝 |
| B2 | 520–590nm | 绿 |
| B3 | 630–690nm | 红 |
| B4 | 770–890nm | 近红外 |
| B5 | 690–730nm | 红边 |
| B6 | 730–770nm | 红边 |
| B7 | 400–450nm | 短波可见光/近紫端 |
| B8 | 590–630nm | 黄/橙 |

这八个波段均在 400–890nm，**没有 SWIR 波段**，不能填进 S2 的 B11/B12 槽位。`ImageGSD` 在 XML 中为空；按四角和整体像素尺寸粗估约 16–17m，最终网格应由产品说明/RPC 和正射结果确定。

**GFDM/ZY1E：真实八通道与像素变化已经确认，逐通道响应表尚未取得。** 本地 XML 记录 Bands=8 或 1–8，但无明确逐波段波长。不能用八通道数量直接推断红边或 SWIR。GFDM 的 9094×10677 MUX 在 25 个抽样点中，后四通道各有 5 个点为零、前四通道在这些点均非零，需审计不同通道的有效区。ZY1E 两景尺寸约 11781×11172、11794×11465，XML 记录约 9.84×10.88m。

**GF-2/GF-7/SuperView：四通道真实存在，物理波段顺序仍应绑定产品说明。** 不以 RGB 预览的色彩顺序推断原图顺序。GF-2 部分 XML 的 ImageGSD=3.24；SuperView 样例 XML/UTM 网格为 2m。GF-7 多数 XML 的 ImageGSD 为空，TIFF 常有 `pixel_scale=(1,1)`、无 CRS 和近零 tiepoint 的占位信息，不能据此宣称 1m。需随原图带走 RPC/XML，在正射后确定真实网格。

1. 先拷 A 池约 51GiB，用于 S2 十波段/SWIR、GF-6 红边与 SAR 单模态入口验证。保留原始位深、波段文件与产品元数据。

3. RGB 标签按需要再拷约 69GiB；团队已有 RGB 主干时，优先把训练预算留给非 RGB 信息收益。
4. 正式波长条件训练前补 GFDM/ZY1E/四通道产品响应表；完成国产影像几何处理和 S1 GRD 定标/校正。对零值、云、边缘以及跨通道有效区建立 mask。
