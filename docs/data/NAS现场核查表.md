## 4. 每景检查要点

- [ ] 文件能完整读取；边缘和中部均有有效数据；小样例正常不代表全目录正常。
- [ ] 多光谱实际通道数和波段语义已核实；缺元数据明确未知，不猜测 NIR/SWIR。
- [ ] 分文件波段属于同一场景且网格一致；单文件单通道不直接判为单波段数据集。
- [ ] CRS 单位已确认；经纬度的度不当米；重采样后的像元间距不当原生分辨率。
- [ ] 数值是 DN、反射率、辐亮度、亮温还是 SAR 功率/dB 已记录；未知则暂不自动归一化。
- [ ] 采集日期来自产品元数据，不用文件修改时间；同地点、同源派生图不能冒充多时相。
- [ ] SLC 两通道是否为 I/Q 已核实；极化与复数分量分别记录。
- [ ] 标签值、无效区域、类别映射和图像尺寸一致；叠加边界检查配准。
- [ ] 原图、融合、匀色、正射、压缩副本已建立关联；禁止跨训练/测试分组泄漏。

若公司环境已有 GDAL，可用 `gdalinfo -json "影像完整路径" > "报告路径.json"` 导出元数据；该命令不自动证明波段物理意义、标定状态或正射精度。范围统计可对抽样窗口完成，不必首轮扫描所有大型影像。预览仅用于检查，训练保留原数据数值。
