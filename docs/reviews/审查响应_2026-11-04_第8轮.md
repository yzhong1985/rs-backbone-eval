## reviewer 2

### P1：GPU 标准化设备冲突（AnySat / Clay / OlmoEarth）

确认是真实缺陷：三个 worker 都把 `mean/std` `.to(device)`，再与
`torch.from_numpy(...)`（CPU）相减；CPU 测试路径不暴露，GPU 上必然报
device mismatch。统一改为 **numpy 侧标准化**：

```python
mean_np = mean[:, None, None]; std_np = std[:, None, None]
x = torch.from_numpy((frames - mean_np) / std_np).to(device)
```

OlmoEarth 的 `_batch_input` 同样改为接收 numpy 统计量。结构上不再存在
CPU/CUDA 张量混算。

### P1：AnySat token 间距混入正式 cell

删除 `ANYSAT_T11_PATCH_M` 环境覆写，`PATCH_M=80` 固定（1280 m patch →
16×16 token）。80 m 是协议定义的一部分，写进 docstring；将来若要试 160 m，
必须声明新协议，不能靠 env 悄悄改。

### P1：镜像地址设置过晚

`huggingface_hub` 在 **import 时**读取 `HF_ENDPOINT`，原 notebook 在 import
之后才设置，请求仍去主站。现在第一个 cell 在 `from huggingface_hub import
snapshot_download` 之前设置 `HF_ENDPOINT`；随后仍写入 Drive
`hf_endpoint.json` 和 run 的 `tags.hf_endpoint`。
