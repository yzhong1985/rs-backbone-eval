## 2. P1：采样索引

Zarr 的 `spatial:transform` 是 GDAL 约定，`(c, f)` 是像元**角点**；像元中心在
`c + a*(k+0.5)`。旧代码：

```python
col0 = int(round((xmin - c) / a))   # 少了半个像元
row0 = int(round((ymax - f) / e))
```

当小数部分 > 0.5 时会取到东侧相邻列。逐 patch 核对：

- 列索引不同：**1,087 / 2,433**（与审查数字一致）
- 行索引不同：0（这批 bbox 的行方向小数部分都 < 0.5）
- 例：patch 10000，`(xmin-c)/a = 62489.74`，旧 62490、新 62489

修复：

```python
col0 = int(np.floor((xmin - c) / a))   # 包含像元 = 最近中心（a>0, e<0）
row0 = int(np.floor((ymax - f) / e))
```

验证：

- patch 10000（受影响）重提后特征改变；patch 20000（未受影响）逐元素不变；
- 旧 sidecar 不含 `sampling`，因此 2,433 个 patch 全部重提（64 维 8.8 s，128 维 13.2 s）；
- 新 sidecar 写 `sampling: center_floor_v2` 与 `sampling_origin: pixel_corner_floor_center_nearest`。
