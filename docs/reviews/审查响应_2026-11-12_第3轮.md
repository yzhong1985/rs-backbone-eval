## P1-2 随机初始化仍跨 seed 共用缓存

**问题**：指纹只加了 `init=random`，没有加 seed。seed 17/42 的随机初始化权重
不同，但特征缓存键相同，后跑的 seed 会复用先跑 seed 的特征。

**修复**：

- `_feature_fingerprint` 增加 `seed` 参数；
- **pretrained 不写 seed**：预训练权重与 seed 无关，缓存继续跨 seed 共享；
- **random 写 seed**：`init != "pretrained"` 时把 seed 放进 payload，每个 seed
  独立缓存；
- 蒸馏和探针的所有特征指纹调用都传 `seed=request.seed`。

**测试**：`test_cache_fingerprints_separate_init_normalisation_and_random_seed`
断言：

- pretrained、同 seed/normalization → 指纹相同；
- random 与 pretrained → 不同；
- pretrained 跨 seed → 相同；
- random 跨 seed → 不同；
- normalization 变化 → 不同。
