# AnySat 缓存分支审查响应（2026-10-16）

上级对本分支（`feat/anysat-frozen-cache` `6116840`）的指示与响应。原审查要点引用及逐条对应改动见下表；本轮在分支上的 `4d8: ` 后续 commit 落实。

## 结论

接受全部 5 点。分支从"在线训练的缓存直通改造"调整为**两阶段训练协议实现**：阶段 A 在线学习适配器+头（不缓存），阶段 B 冻结适配器做一次提取后仅训头（缓存）。该协议**另表报告**，与既有联合冻结训练不混判；主线分支保留原在线路径不变。

## 第四轮：真实 GPU 等价性实测 + 缓存体积治理（2026-10-16）

### 等价性（GPU 实测，seed 42，6 epoch，200 行/epoch）

| 配置 | mean_iou |
| --- | --- |
| 在线（cache off，200 行） | 0.3662 |
| 缓存 fp16（200 行，行数对齐） | **0.3749**（+0.0087，单 seed 噪声带内） |
| 缓存 fp32（100 行） | 0.3517 |
| 缓存 fp16（100 行，cap 错配） | 0.3517 |

- **fp16 与 fp32 结果逐位相同** → 存储 dtype 不是差异来源；
- **eval/句 train 模式 dense 差 = 0.000**（探针）→ 模式不是来源；
- 早期 0.0145 差距真因 = **smoke 参数错配**（`LIMIT_BATCHES` 数优化器步数→200 行，`CACHE_MAX_ROWS` 数行→100 行），非缓存 bug；
- 结论：**缓存在噪声内无损**（单 seed，多 seed 复核列为后续）。

### 耗时收益（同 200 行实测）

| 阶段 | 耗时 |
| --- | --- |
| Stage A 在线 epoch | 74s |
| Stage B 在线 epoch | 29s |
| Stage B 缓存 epoch | ~17s（稳态） |
| populate | 0.27 s/行 |

基线（联合冻结）每 epoch = 74s；两阶段 Stage B = 17s → **~4.6×**。全量 T5 外推：35.6h → 21.8h，**省 ~13.8h/seed（39%）**。

### 缓存体积治理（新）

dense 为 1536×224×224 全分辨率：fp16 **154MB/行**、fp32 308MB/行；全量 train split 2775 行 = **fp16 ~404GB / fp32 ~808GB per seed**。
- **保持 fp16**（对 bf16 特征值域 ±5 无损 + 实测与 fp32 一致），加**溢出保护**（峰值 >65504 报错而非静默写 inf）；
- **跑完自动删缓存**（成功时 `shutil.rmtree`，失败保留以便断点续训；`ANYSAT_FROZEN_CACHE_KEEP=1` 可保留）→ 峰值始终 1 份，不随 seed 堆积；
- `RS_EVAL_CACHE_ROOT` 改到系统 NVMe（1.4TB 空闲），`/geodata`（仅 276G 空闲）不再承载缓存。

测试 187 项通过（含清理断言 + 溢出保护 + bf16 无损）。
