## 1. "超过原始特征"这个标准偏低（评论第 2 节）

**问题**：T11P 里 AnySat 的 train-only PCA128（0.3159）超过原始 1536 维（0.3044），
而 PCA 不引入任何信息。因此 NCE 的 +0.016 可能有一部分只是对比目标把特征分布摊开、
尺度统一，让 8 epoch 的小探针更好学，而不是教师信息。

**处理**：新增两个对照（Clay T11D、3 种子、复用缓存，9 条 run，14:08–14:24）：

| 协议 | 做法 |
|---|---|
| `clay_rgbn_distill_rand64_nce` + `clay_rgbn_probe_rand64_nce` | 完全相同的对称 InfoNCE（τ=0.07、每步 8 patch、抽 1024 token），正样本目标换成学生**自身** 1024 维 token 的固定高斯投影（seed = `RANDPROJ_SEED + seed`，矩阵 sha256 入 tags）。不读教师、不读标签。 |
| `clay_rgbn_probe_raw_zscore` | 训练集上算每维均值/标准差，对原始 1024 维做 z-score，再用同一条 8 epoch 探针；统计量存 `zscore_mean.npy`/`zscore_std.npy` 并登记 artifact。 |

**结果**（test mIoU，3 种子）：

| 读出 | s17 / s42 / s73 | 均值 |
|---|---|---:|
| 原始 1024 维 | 0.3358 / 0.3133 / 0.3062 | 0.3185 |
| OE64 InfoNCE（有教师） | 0.3322 / 0.3359 / 0.3340 | 0.3340 |
| 无教师 NCE（rand64） | 0.2076 / 0.2283 / 0.1955 | **0.2105** |
| 原始 + z-score | 0.3020 / 0.3586 / 0.3156 | **0.3254** |

- **去教师 NCE 掉到 0.2105**，`val_retrieval_top1` 0.996～1.000（教师臂 0.32～0.33）：
  没有外部结构时，学生精确学出那个随机投影，这一臂的上限就是随机投影读出 →
  **教师结构确实在起作用，单纯做对比学习不会改善特征几何**。该对照的边界也写进文档：
  目标可精确学习，它测的是"无外部结构的上限"，不是"同分布但无关的教师"。
- **z-score 原始探针 0.3254**：相对未标准化只 +0.007（逐种子 −0.034 / +0.045 / +0.009），
  没有系统性提升；种子波动 0.024，seed 42 的 0.359 比任何 NCE 种子都高。
  NCE 相对"标定后的原始读出"只剩 **+0.009（2/3 种子）**。
- 配合 AnySat 上 NCE（0.3188）与 PCA128（0.3159）持平（1/3 种子更高）→
  **"对比学习超过原始特征"这条收回。**

**改动**：`docs/evaluation/T11D_对比学习蒸馏对照_实验说明_2026-11-13.md` 新增 §7
（预声明判据）、§7.1（结果）、§7.2（解读）；阶段结论 §3.1 第 4/5 条与 §5 关闭表同步降级为

## 4. 额外发现并修复：Prithvi/AnySat 的 InfoNCE epoch 选择 bug

**现象**：`prithvi_t11p_distill_o128_nce` / `anysat_t11p_distill_o128_nce` 的 6 条 run
`best_epoch=0`、`best_validation_infonce/cosine/top1` 全为 NaN。

**原因**：两个 worker 的 `_loss_improved` 只把 `mse` 当最小化，`infonce` 落到
`score > best` 分支，而初始 `best=+inf` → 永不更新；发布的 projector 是最后一轮而不是
val InfoNCE 最优轮（Clay 的实现本来就对）。

**修复**：

- 代码 `8419828`：`_loss_improved` 改为 `loss_kind in {"mse", "infonce"}` 时最小化，并在
  `tests/test_prithvi_t11p.py` / `tests/test_anysat_t11p.py` 增加 infonce 方向断言。
- 审计 `7d6d0ab`：新增 `T11P_NCE_SELECT = "8419828"`，作用域限定
  `T11P + {prithvi, anysat} + *_o128_nce`（Clay 不受影响）。
- 旧 12 条用 `scripts/supersede_run.py` 标记 superseded（原因写明），保留审计轨迹。
- 用 `-v2` 重跑 12 条（14:25–14:37，全部 completed）：test 数字与旧记录完全一致
  （Prithvi 0.2339/0.2341/0.2272，AnySat 0.3208/0.3148/0.3208），但 `best_epoch=8`、
  val 指标正常（Prithvi val_infonce 4.70～4.73 / top-1 0.18～0.20；AnySat 4.43～4.46 /
  0.23～0.24）。也就是说这次修复没有改变结论，只是让"按 val InfoNCE 选 epoch"的声明
  与记录一致。
