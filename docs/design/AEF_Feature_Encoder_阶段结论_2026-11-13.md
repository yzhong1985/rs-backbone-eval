# “用 AEF embedding 引导主干特征”路线：阶段结论

- 日期：2026-11-13
- 对应设计：`docs/design/AEF_Feature_Encoder.md`（下称“原设计”）
- 依据：`/geodata/rs-eval/runs` 账本中已完成、未被 superseded 的 run（T11 / T11O /
  T11D / T11P / T8），数字为 PASTIS-HD test mIoU，三个种子（17/42/73）的均值，另有
  说明的除外。账本是唯一权威，本文只是快照。
- 一句话结论：**“把主干特征对齐到 AEF 的 64 维空间，从而得到更好的表征”这条路线，
  按原设计走不通。** 对齐本身做到了，但对齐后的特征下游效果反而变差；真正带来提升的
  是用标签微调主干，与教师无关。

---

## 1. 原设计想做什么（简述）

原设计的想法是：AEF 的 64 维年度 embedding 冻结使用时效果很好，那就训练一个小的
“特征编码器”，把 Prithvi 等主干的 1024 维特征压成 64 维，并让它尽量像 AEF。
希望得到的结果是：

1. **冻结档位下超过 AEF**（只训练编码器和下游头）；
2. **全量微调档位下超过现有主干和 LIM**。

主实验定为：Prithvi-300M 冻结 + MLP 编码器（1024→256→64）+ 余弦蒸馏，先做 PASTIS。

## 2. 我们实际做了什么

原设计的第一阶段（冻结主干 + 投影器 + 蒸馏）已经做完，而且比原设计多做了几步：

| 做了什么 | 对应原设计 | 用到的主干 |
|---|---|---|
| 冻结主干，把特征蒸馏到 AEF 64 维 / OlmoEarth 64、128 维 | 第二、三阶段（Linear/MLP + 直接蒸馏） | Clay、Prithvi、AnySat |
| 同样维度下用标签直接训练的投影（不看教师）作对照 | 第七阶段（任务监督） | 同上 |
| PCA 64 维对照 | 第一阶段 | Clay |
| 解冻主干最后几块，标签 + 教师一起训练 | §5.1 的“后续联合微调” | Clay、Prithvi、AnySat |
| 只给 10% 标签，看教师能不能补上 | 原设计未写 | Clay |
| 把对齐后的特征拿到另一个数据集（GF-2，T8）上用 | 第三层“迁移”评价 | Clay |

和原设计的两点差别：

- **教师多了 OlmoEarth。** 测下来在 PASTIS 上 OlmoEarth v1.3 年度 embedding 比 AEF
  明显更强（见 §3），所以多数实验用它当教师；AEF 64 维也做了，结论一致。
- **主干从 Prithvi 扩到 Clay、AnySat。** 结论在三个主干上方向一致，不是某一个主干的
  特例。

## 3. 结果，用大白话说

### 3.1 “像教师”做到了，但“像教师”没有带来“和教师一样好用”

学生（压缩后的主干特征）和教师在验证集上的余弦相似度能到 **0.92～0.955**，说明
“长得像”这件事做到了。但拿去做分割：

| 64/128 维左右的冻结特征 | test mIoU |
|---|---:|
| **AEF 原生 64 维**（教师之一，T11） | **0.485** |
| **OlmoEarth 原生 64 / 128 维**（教师，T11O） | **0.579 / 0.614** |
| Clay 原始特征，不压缩（T11D，RGB+NIR，20 期） | 0.319 |
| Clay → 蒸馏到 OlmoEarth 64 维 | 0.301 |
| Clay → 蒸馏到 AEF 64 维 | 0.287 |
| Clay → PCA 64 维 | 0.267 |
| Prithvi 原始特征 / 蒸馏到 OlmoEarth 128 维（T11P，六波段，4 期） | 0.207 / 0.197 |

可以看出三件事：

1. **蒸馏后的学生离教师差得很远**（0.29 vs 0.49～0.61）。
2. **蒸馏后的学生还不如它自己没压缩之前**。三个主干都是这样。
3. 蒸馏比 PCA 好，跟 OlmoEarth 学比跟 AEF 学好一点。所以“教师在起作用”，只是
   作用有限。

**打个比方：** 学生只看了几张照片，教师看了一整年的多种传感器录像。冻结主干时，
编码器只能对学生“已经看到的东西”换个说法，没法凭空补出它没看到的信息。换个说法
能让它“说话的方式像教师”（余弦很高），但信息量不会变多，反而在压缩时丢了一些。
所以**冻结档位下超过教师在原理上就做不到**，换成 Transformer 编码器、MAE、对比
学习、JEPA 也一样，它们都只是“换说法”的不同方式。

### 3.2 解冻主干确实涨分，但涨分来自标签，不来自教师

| Clay，T11D（RGB+NIR，20 期） | test mIoU |
|---|---:|
| 冻结，原始特征 | 0.319 |
| 解冻末 4 块，仅用标签 | 0.427 |
| 解冻末 4 块，标签 + 教师 | 0.435（+0.007，验证集不支持） |
| 解冻末 4 块，去掉 128 维投影、换宽头，仅用标签 | **0.458** |
| 解冻末 8 块，仅用标签 | 0.430 |

| T11P（六波段，4 期）上“加教师”比“不加”多出 | test | 说明 |
|---|---:|---|
| Clay | **+0.015** | 三个种子都为正，唯一一致的正效应 |
| Prithvi | −0.002 | 方向不一致 |
| AnySat | +0.003 | 接近零 |

说白了：**放开主干、用标签训练，涨了 0.1 左右；在此基础上加教师，最多再涨 0.015，
多数情况约等于 0。** 最高分（0.458）是完全不用教师得到的。

原设计的标准 (2)“微调档超过现有主干和 LIM（0.434）”从数字上算是达到了，但这是
普通微调的功劳，不能算作“AEF 引导”的成果。

### 3.3 标签少的时候，教师也没帮上忙

一般认为蒸馏在标签少时最有用。我们只给 10% 标签（146 个 patch）：

| Clay，T11D，10% 标签 | s17 | s42 | s73 | 均值 |
|---|---:|---:|---:|---:|
| 仅标签 | 0.215 | 0.237 | 0.209 | 0.220 |
| 标签 + 教师 | 0.213 | 0.193 | 0.191 | 0.199 |

**加教师反而低了 0.021，三个种子都是负的。**

### 3.4 换个数据集，对齐过的特征更差

把在 PASTIS 上得到的特征冻结，拿到 GF-2 地物分类（T8，25 类，只训新的下游头；
seed 17、缩减预算，仅作方向参考）：

| 迁移过去的特征 | test mIoU |
|---|---:|
| Clay 原始特征 | **0.367** |
| 蒸馏到 OlmoEarth 128 维的特征 | 0.258 |
| 蒸馏到 AEF 64 维的特征 | 0.256 |

**对齐到教师空间后，换个任务掉了 0.11。** 原因是压缩时只保留了“教师关心的信息”
（对 PASTIS 农田有用），把主干原来那些更通用的信息丢掉了。这与原设计“提升跨任务
泛化”的预期正好相反。

## 4. 对照原设计的两条验证标准

| 原设计的标准 | 结果 | 说明 |
|---|---|---|
| (1) 冻结档位下超过 AEF | **未达到，且原理上做不到** | 最好 0.301，AEF 0.485。冻结时学生信息量不会超过它自己的原始特征（0.319） |
| (2) 微调档位下超过现有主干和 LIM | **数字上达到，但与 AEF 无关** | 0.458 来自“解冻 + 宽头 + 只用标签”；教师项 ≤ +0.015，10% 标签时为负 |

原设计最后一句的目标是：“映射到与 AEF 一致的 64 维空间，**同时**尽可能保留下游
能力”。前半句做到了（余弦约 0.95），后半句没做到。**“像教师”和“好用”之间没有
必然联系**，这是这轮实验最主要的发现。

## 5. 原设计里还没做的部分，要不要做

| 原设计里没做的 | 建议 | 理由 |
|---|---|---|
| Linear / Bottleneck / Transformer 编码器（A1、A3、A4、A5） | **关闭** | 冻结时都是“换说法”，受 §3.1 的同一上限约束 |
| MAE / 对比学习 / JEPA 范式（第四至六阶段） | **关闭** | 同上，只是逼近教师的方式不同 |
| Prithvi-600M（第五阶段） | **关闭** | 300M 冻结原始特征只有 0.207，换大模型补不上这么大的差距 |
| WHU-OPT-SAR 跨传感器 | **暂缓** | T8（GF-2）上对齐后的特征已经比原始特征差 0.11，预计结论相同 |
| 宽头 B 层上的教师项（Clay、Prithvi 正在跑） | **跑完收尾** | 只用来把“教师项约等于 0”这个结论写死，不期待增益 |

## 6. 如果还想沿这个方向走

唯一还没被排除的做法，和原设计已经是两回事了：

> **把年度 embedding 当作“大范围、不要标签的监督信号”，在大量无标签区域上继续训练
> 主干（要解冻），再看主干在多个下游任务上微调后有没有变好。**

和这轮实验的区别：

| | 这轮实验 | 新方向 |
|---|---|---|
| 训练数据 | PASTIS 训练集 1455 个 patch，本来就有标签 | 几万个无标签 patch，覆盖多个区域 |
| 主干 | 多数冻结 | 解冻 |
| 判据 | 在 PASTIS 上超过教师 | 在 T1–T5、T8 等**没参与训练**的任务上，比原版主干好 |

现有信号（冻结读出持平、微调时教师项很小、迁移变差）对它都偏负面，**先验上不看好**。
如果要做，建议先做小规模验证再决定：一个主干、2,000～5,000 个无标签 patch、两三个
下游任务；只有“多数任务不掉分、部分任务涨分”才值得扩大。

还有一个值得先想清楚的问题：AEF 和 OlmoEarth 本身已经覆盖全球、每年发布。近似它们
只有在**它们给不了的地方**才有用，例如 1～4 m 的 GF 影像、尚未发布的年份、单期影像
的即时推理。目前唯一触及这类场景的证据是 T8（GF-2），结果是负的。

## 7. 读这些数字时要注意

- 教师（全年多源观测）和学生（4 期或 20 期光学）的输入不对等，差距大部分来自
  “多看了一年的数据”，不能直接解读为学生架构弱。
- AnySat 的预训练数据包含 PASTIS-HD，它的绝对分数不能当作架构优势。
- T11D（RGB+NIR，20 期）、T11P（六波段，4 期）、T11（各模型原生输入）的设置不同，
  跨任务的数字只能看方向，不能逐位相减。
- T8 迁移是 seed 17、缩减预算的诊断结果；10% 标签实验只做了 Clay、T11D。
- 统计口径：均值为三个种子的算术平均；配对差按同一种子相减后取均值。
