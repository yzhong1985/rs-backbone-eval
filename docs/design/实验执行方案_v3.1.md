## 0. 方案总体结论（对齐技术审计第 VII 节规范）

> 本方案以单期高分影像语义分割为首个验证任务，在全链路自主构建数据管线与训练代码的条件下，分别研究**纯 RGB 教师蒸馏路线 `D`**，以及**单权重兼容 `RGB` / `RGB+NIR` 的 `P-Flex` 路线**。`D` 的当前学生结构仅使用 3 波段 `RGB`；`P-Flex` 与同结构无教师控制组 `Bcap-Flex` 使用完全相同的网络结构，通过教师对齐损失开关检验监督收益。训练期教师配对须先通过我方独立的地理配准验收（`G0`），部署期模型不依赖外部教师栅格或地理坐标。`RGB` 性能保持、`NIR` 独立增益、教师监督贡献与部署资源开销均须通过我方自跑的匹配控制实验验证，不作先验保证。通过小规模实验仅表示具备进一步验证价值，标准产品交付还需满足目标数据域和部署设备上的性能要求。

## 2. 核心架构规格：明确区分 `D` 路线与 `P-Flex` 路线

### 2.1 各实验臂与交付路线的能力边界（响应审计 A-02）

| 路线 / 实验臂 | 推理期输入通道 | 第 4 通道 `NIR` 是否参与计算 | 相对于 `B0` 的推理期额外参数量（以 `[128,256,512,1024]` 为例） | 适用交付场景 |
| :--- | :--- | :--- | :--- | :--- |
| **`B0`**（纯影像基线） | 3 通道 `[R, G, B]`（或 4 通道原生主干） | 3 通道主干下不参与 | $0$（基准参照） | 基础分割基线 |
| **`D`**（融合教师蒸馏学生） | 3 通道 `[R, G, B]` | **不参与**（忽略第 4 通道） | **$0$**（训练期辅助投影 `student_q_proj` 在导出部署时移除） | **纯 RGB 零额外开销交付首选** |
| **`A`** / **`B_A`**（共享 Adapter 路线） | 3 通道 `[R, G, B]` | 不参与 | $+1,399,296$（推理时移除 `aux_heads`，但必须保留 `stem_adapters`） | 验证训练期辅助表征正则是否改善共享层 |
| **`P`** / **`Bcap`**（纯 RGB 代理融合） | 3 通道 `[R, G, B]` | 不参与 | 轻量版 (`light_dw`)：$+844,416$<br>标准版 (`standard_3x3`)：$+5,051,520$ | 纯 RGB 代理特征预测与融合验证 |
| **`P-Flex`** / **`Bcap-Flex`**（3/4 波段自适应） | **单权重同时支持** `(B,3,H,W)` 与 `(B,4,H,W)` | **参与**（仅当输入为 4 通道时激活单通道 `nir_stem` 与残差头） | 轻量版 (`light_dw`)：3ch 推理执行 $844,416$ 参数；4ch 推理执行 $1,175,328$ 参数 | **客户同时存在 3 波段 RGB 与 4 波段 RGB+NIR 数据的自适应交付** |

### 2.2 轻量化代理分支与单通道 NIR 解耦设计（响应审计 A-03 & A-10）

为了避免旁路参数膨胀并确保第 4 波段增益可被干净归因，将 `FlexibleRGBNIRProxyModule` 改进如下：

$$\hat{E}_l = \underbrace{g_{\text{RGB}}^{(l)}(F_l)}_{\text{瓶颈深度可分离卷积（仅依赖 RGB 主干特征）}} + \quad m_{\text{nir}} \cdot \underbrace{g_{\text{NIR}}^{(l)}\Big(F_l, \phi_{\text{nir}}\big(X_{\text{ch4}}\big)\Big)}_{\text{单通道 NIR 残差修正（末层 Zero-Init）}}$$

1. **轻量化 RGB 代理头 $g_{\text{RGB}}^{(l)}$（参数量缩减 $93.7\%$）**：
   * 采用 `Conv1x1(c -> 128) -> GroupNorm -> GELU -> DWConv3x3(128, groups=128) -> GroupNorm -> GELU -> Conv1x1(128 -> 64)`。在 `[128, 256, 512, 1024]` 四级特征金字塔上，4 个层级的总参数量仅为 **$284,416$**（原标准 $3 \times 3$ 卷积为 $4,491,520$）。
2. **单通道解耦 NIR 分支 $\phi_{\text{nir}}(X_{\text{ch4}})$ 与占位对照（响应 A-03）**：
   * `nir_stem` 的第一层卷积输入通道数设为 **`1`**（仅切片提取第 4 通道 `x_ch4 = img[:, 3:4, :, :]`），彻底消除“4 波段模式对前 3 通道 RGB 重复做卷积”带来的混淆变量。
   * 同时支持切换 `nir_input_mode`：
     * `"real_nir"`（默认）：输入真实的第 4 波段 `img[:, 3:4, :, :]`；
     * `"rgb_mean_placeholder"`（归因对照）：输入前 3 通道均值 `img[:, :3, :, :].mean(dim=1, keepdim=True)` 并从头训练。若 `"real_nir"` 显著优于 `"rgb_mean_placeholder"`，即可严格证明增益来自真实的近红外光谱信息而非额外分支结构。
3. **两种训练策略可选（响应 A-04 & A-08）**：
   * **策略 A（联合 Modality Dropout 训练 + 单检查点选模）**：以初始超参 $p_{\text{drop}} = 0.5$ 随机丢弃 NIR 残差，按验证集指定规则选出**唯一检查点**同时评测 3ch 与 4ch。
   * **策略 B（两阶段分步训练：确保 RGB 模式数学级零退步）**：
     * **第一阶段**：仅用 3 波段 RGB 训练 `P`（或 `Bcap`），保存最优 RGB 检查点；
     * **第二阶段**：调用 `model.enable_stage2_nir_only_training()`，**完全冻结骨干、`rgb_to_proxy`、`injectors` 以及共享解码器 `TinyUPerNet` 的全部权重，并将 `TinyUPerNet` 内部的所有 `BatchNorm2d` 层强制锁死为 `.eval()` 模式（固定 running mean/var）**，仅更新 `nir_stem` 与 `nir_residual_heads`。这样当推理输入为 3 波段 RGB 时，输出与第一阶段最优纯 RGB 模型逐位 $100\%$ 相等。

## 3. 自主构建数据、配准核验与评测协议（响应审计 A-01 / A-05 / A-06）

由于我们不依赖同事的任何中间数据文件，所有数据准备与评测契约均按以下标准自行构建：

### 3.1 数据集选择与训练期地理配准核验（关闭 A-01）

1. **路线 A（我方已有现成配准基础：FBP / T8 国产 GF-2 数据集）**：
   * 我方在前期的 `T8` 迁移实验中（见 `教师蒸馏路线_总结_2026-11-16.md` §4.7），已在 `/geodata/rs-eval` 环境中具备了 FBP（GF-2，$4\text{ m}$ 分辨率，4 波段 `[B, G, R, NIR]`）影像以及对应区域的 `AEF 64` 维和 `OlmoEarth 128` 维特征。
   * **验收动作**：抽查 5 个训练景，将已提取的 AEF/OE 特征图做 PCA 伪彩色渲染后与 GF-2 原始影像叠加，核验水体边界与主干道路的平移误差是否小于 $1$ 个 AEF 像素（$10\text{ m}$）。
2. **路线 B（从公开源从头构建：WHU-OPT-SAR 光学分支）**：
   * 原始数据为 100 景 $5556 \times 3704$ 的 $5\text{ m}$ 分辨率 GF-1 四波段影像。
   * **空间隔离划分**：按 100 景原始大图图幅号（禁止将同一景大图切出的 $512 \times 512$ 小 tile 分散到 train 和 test）自主划分为固定 `train / val / test` 清单（例如 $70 / 15 / 15$ 景）。
   * **配准核验与止损规则（A-01）**：公开仓库中的 `.tif` 若不含内嵌 CRS 投影头，先用图幅号计算候选经纬度框去拉取 GEE 上的 `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL`（AEF），必须人工叠加检查四角与中心地物是否吻合。**若发现公开版 WHU-OPT 图像经过非标准裁剪导致图幅公式存在大于 $20\text{ m}$ 的偏移且无法通过仿射变换校正，则不强行在 WHU-OPT 上跑局部对齐，直接将 `G1–G5` 主实验放在带精确坐标的 FBP（GF-2）上执行**。

### 3.2 标签重映射与全局混淆矩阵 `mIoU` 协议（关闭 A-05）

1. **显式标签映射**：
   * **WHU-OPT-SAR**：官方原始标签像素值为 `{0, 10, 20, 30, 40, 50, 60, 70}`（其中 `0` 为未标注/背景，`10..70` 为农田、城市、村庄、水体、林地、道路、其他共 7 类）。数据读取时必须执行显式查表映射至连续整数 `{0, 1, 2, 3, 4, 5, 6, 7}`，模型输出通道数设为 `8`。
   * **FBP (GF-2)**：官方为 `0`（`unlabeled` 未标注背景）与 `1..24`（24 个标注地物类）。模型输出通道数设为 `25`。
2. **训练忽略与评测累积规则**：
   * 训练交叉熵损失统一设置 `ignore_index=0`（背景像素不产生梯度）。
   * 评测时：遍历整个验证集/测试集，先剔除真值标签 `target == 0` 的背景像素，将所有有效前景像素的预测结果累积到一张全局混淆矩阵 $M \in \mathbb{Z}^{K \times K}$ 中，最后仅在前景类别集合 $c \in \{1, \dots, K-1\}$ 上计算 $\text{IoU}_c = \frac{M_{c,c}}{M_{c,c} + \sum_{i \neq c} M_{i,c} + \sum_{j \neq c} M_{c,j}}$ 并取算术平均（若某前景类在整个评测集中真值与预测全为 $0$，则跳过该类并记录日志）。

### 3.3 教师解码、有效区掩膜与聚合顺序契约（关闭 A-06）

1. **格式显式区分与防二次解码**：函数 `decode_and_mask_teacher(raw_teacher, teacher_format)` 强制要求指定 `"aef_float"` 或 `"olmoearth_int8"`。
2. **OlmoEarth 官方公式与全通道检查**：
   * 当 `teacher_format == "olmoearth_int8"` 时，检查所有通道是否均不等于 `-128` 且有限：$\text{valid\_mask} = \big(\forall c, q_c \neq -128\big)$；
   * 按官方导出文档公式反量化：$\text{decoded} = \text{sign}(q) \times \left(\frac{|q|}{127.5}\right)^2$，对非零有效向量做逐像素 $L_2$ 归一化，并将无效位置原地清零。
3. **浮点 `NaN/Inf` 物理清除**：
   * 当 `teacher_format == "aef_float"` 时，先检查 $\text{isfinite}(x)$ 且全通道绝对值和大于 $10^{-6}$，生成 `valid_mask`，随即调用 `torch.nan_to_num(x, nan=0.0, posinf=0.0, neginf=0.0)` 彻底清除非有限值（防止 `NaN * 0.0 = NaN` 污染池化与梯度）。
4. **聚合与归一化顺序契约**：统一规定为“**先在原始 $10\text{ m}$ 分辨率解码并逐像素归一化 $\to$ 按有效掩膜加权平均池化至学生特征图 Footprint $\to$ 在损失函数内对池化后的非零目标向量再次 $L_2$ 归一化后算余弦**”。

### 5.1 核心网络与轻量化六臂模型 (`six_arm_models.py`)

```python
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F


# =====================================================================
# 1. Head 侧可训注入器 (复刻 02_实现规格.md §1，严格末层 Zero-Init)
# =====================================================================
class AEFInjector(nn.Module):
    """
    特征层注入器：
      - linear 档: Conv1x1(in_dim -> out_c), weight 与 bias 全 0 初始化
      - mlp 档: Conv1x1(in_dim -> 256) [随机初始化] -> GELU -> Conv1x1(256 -> out_c) [全 0 初始化]
    在相同公共权重与评测模式下，确保训练第 0 步残差输出恰为 0。
    """
    def __init__(self, in_dim: int = 64, out_c: int = 256, mode: str = "mlp"):
        super().__init__()
        self.mode = mode
        if mode == "linear":
            self.proj = nn.Conv2d(in_dim, out_c, kernel_size=1, bias=True)
            nn.init.zeros_(self.proj.weight)
            nn.init.zeros_(self.proj.bias)
        elif mode == "mlp":
            self.fc1 = nn.Conv2d(in_dim, 256, kernel_size=1, bias=True)
            self.act = nn.GELU()
            self.fc2 = nn.Conv2d(256, out_c, kernel_size=1, bias=True)
            nn.init.zeros_(self.fc2.weight)
            nn.init.zeros_(self.fc2.bias)
        else:
            raise ValueError(f"Unsupported injector mode: {mode}")

    def forward(self, aef_feat: torch.Tensor, target_hw: tuple[int, int]) -> torch.Tensor:
        if aef_feat.shape[-2:] != target_hw:
            aef_feat = F.interpolate(aef_feat, size=target_hw, mode="bilinear", align_corners=False)
        if self.mode == "linear":
            return self.proj(aef_feat)
        return self.fc2(self.act(self.fc1(aef_feat)))


# =====================================================================
# 2. 轻量化深度可分离代理预测头 (响应审计 A-10：参数量缩减 93.7%)
# =====================================================================
class DepthwiseSeparableProxyHead(nn.Module):
    """
    响应审计 A-10：
    原版 Conv3x3(c -> 256) 在 [128, 256, 512, 1024] 下高达 4,491,520 参数。
    现改为瓶颈深度可分离结构: Conv1x1(c -> mid_c) + DWConv3x3(mid_c) + Conv1x1(mid_c -> aef_dim)，
    当 mid_c=128 时，四级总参数量仅为 284,416 (减少 93.7%)。
    """
    def __init__(self, in_c: int, aef_dim: int = 64, mid_c: int = 128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(in_c, mid_c, kernel_size=1, bias=False),
            nn.GroupNorm(16, mid_c),
            nn.GELU(),
            nn.Conv2d(mid_c, mid_c, kernel_size=3, padding=1, groups=mid_c, bias=False),
            nn.GroupNorm(16, mid_c),
            nn.GELU(),
            nn.Conv2d(mid_c, aef_dim, kernel_size=1, bias=True),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)


# =====================================================================
# 3. 单权重 3/4 波段自适应代理模块 (响应审计 A-03 / A-04 / A-10)
# =====================================================================
class FlexibleRGBNIRProxyModule(nn.Module):
    """
    响应审计 A-03、A-04、A-10 的改进设计：
      1. 轻量化 RGB 基础分支 (DepthwiseSeparableProxyHead 或可选 standard_3x3)；
      2. 严格解耦的单通道 NIR 分支：nir_stem 第一层仅输入 1 个通道 (第 4 波段 NIR)，
         不再重复卷积前 3 通道 RGB，从而干净剥离 NIR 物理信息；
      3. 支持 nir_input_mode 归因控制：
         - 'real_nir': 读取真实的第 4 波段 img[:, 3:4, :, :]
         - 'rgb_mean_placeholder': 读取 RGB 均值 img[:, :3].mean(dim=1, keepdim=True) 作为无 NIR 信息的同结构对照 (A-03)。
    """
    def __init__(
        self,
        in_channels_list: list[int],
        aef_dim: int = 64,
        flexible_nir: bool = True,
        nir_stem_dim: int = 64,
        nir_drop_prob: float = 0.5,
        proxy_arch: str = "light_dw",
        nir_input_mode: str = "real_nir",
    ):
        super().__init__()
        assert proxy_arch in ("light_dw", "standard_3x3")
        assert nir_input_mode in ("real_nir", "rgb_mean_placeholder")
        self.flexible_nir = flexible_nir
        self.nir_drop_prob = nir_drop_prob
        self.nir_input_mode = nir_input_mode

        # 1. 常驻 3 波段 RGB 基础预测流
        if proxy_arch == "light_dw":
            self.rgb_to_proxy = nn.ModuleList([
                DepthwiseSeparableProxyHead(c, aef_dim=aef_dim, mid_c=128) for c in in_channels_list
            ])
        else:
            self.rgb_to_proxy = nn.ModuleList([
                nn.Sequential(
                    nn.Conv2d(c, 256, kernel_size=3, padding=1, bias=False),
                    nn.GroupNorm(16, 256),
                    nn.GELU(),
                    nn.Conv2d(256, aef_dim, kernel_size=1, bias=True),
                ) for c in in_channels_list
            ])

        # 2. 可插拔单通道 NIR 残差修正流 (输入严格为 1 通道，响应 A-03)
        if flexible_nir:
            self.nir_stem = nn.Sequential(
                nn.Conv2d(1, 32, kernel_size=3, stride=2, padding=1, bias=False),
                nn.GroupNorm(8, 32),
                nn.GELU(),
                nn.Conv2d(32, nir_stem_dim, kernel_size=3, stride=2, padding=1, bias=False),
                nn.GroupNorm(8, nir_stem_dim),
                nn.GELU(),
            )
            self.nir_residual_heads = nn.ModuleList([
                nn.Sequential(
                    nn.Conv2d(c + nir_stem_dim, 128, kernel_size=1, bias=False),
                    nn.GroupNorm(8, 128),
                    nn.GELU(),
                    nn.Conv2d(128, aef_dim, kernel_size=1, bias=True),
                ) for c in in_channels_list
            ])
            for head in self.nir_residual_heads:
                nn.init.zeros_(head[-1].weight)
                nn.init.zeros_(head[-1].bias)

    def forward(self, feats: list[torch.Tensor], img_input: torch.Tensor) -> dict[str, list[torch.Tensor]]:
        C_in = img_input.shape[1]
        assert C_in in (3, 4), f"Expected 3 (RGB) or 4 (RGB+NIR) channels, got {C_in}"

        hat_rgb_list = [rgb_head(f) for f, rgb_head in zip(feats, self.rgb_to_proxy)]

        if (not self.flexible_nir) or (C_in == 3):
            return {
                "hat_active": hat_rgb_list,
                "hat_rgb_only": hat_rgb_list,
                "hat_rgb_nir": [],
            }

        # 提取单通道第 4 波段输入（真实 NIR 或 RGB 均值占位对照，响应审计 A-03）
        if self.nir_input_mode == "real_nir":
            ch4_in = img_input[:, 3:4, :, :]
        else:
            ch4_in = img_input[:, :3, :, :].mean(dim=1, keepdim=True)

        nir_feat = self.nir_stem(ch4_in)
        hat_full_list = []
        for f, hat_rgb, nir_head in zip(feats, hat_rgb_list, self.nir_residual_heads):
            nir_resized = F.adaptive_avg_pool2d(nir_feat, output_size=f.shape[-2:])
            delta_nir = nir_head(torch.cat([f, nir_resized], dim=1))
            hat_full_list.append(hat_rgb + delta_nir)

        if self.training and (torch.rand(1).item() < self.nir_drop_prob):
            active_list = hat_rgb_list
        else:
            active_list = hat_full_list

        return {
            "hat_active": active_list,
            "hat_rgb_only": hat_rgb_list,
            "hat_rgb_nir": hat_full_list,
        }


# =====================================================================
# 4. 轻量解码头 TinyUPerNet (channels=128)
# =====================================================================
class TinyUPerNet(nn.Module):
    """
    注（响应审计 A-08）：内部包含 BatchNorm2d。
    在两阶段无损训练模式下，可通过 freeze_bn_stats=True 锁死 BatchNorm 统计量。
    """
    def __init__(self, in_channels_list: list[int], channels: int = 128, num_classes: int = 8):
        super().__init__()
        self.freeze_bn_stats = False
        self.lateral_convs = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(in_c, channels, kernel_size=1, bias=False),
                nn.BatchNorm2d(channels),
                nn.ReLU(inplace=True),
            ) for in_c in in_channels_list
        ])
        self.fpn_convs = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(channels, channels, kernel_size=3, padding=1, bias=False),
                nn.BatchNorm2d(channels),
                nn.ReLU(inplace=True),
            ) for _ in in_channels_list
        ])
        self.fuse_conv = nn.Sequential(
            nn.Conv2d(channels * len(in_channels_list), channels, kernel_size=3, padding=1, bias=False),
            nn.BatchNorm2d(channels),
            nn.ReLU(inplace=True),
        )
        self.cls_seg = nn.Conv2d(channels, num_classes, kernel_size=1)

    def train(self, mode: bool = True):
        super().train(mode)
        if self.freeze_bn_stats:
            for m in self.modules():
                if isinstance(m, nn.BatchNorm2d):
                    m.eval()
        return self

    def forward(self, feats: list[torch.Tensor], out_hw: tuple[int, int]) -> tuple[torch.Tensor, torch.Tensor]:
        laterals = [lat(f) for lat, f in zip(self.lateral_convs, feats)]
        for i in range(len(laterals) - 1, 0, -1):
            laterals[i - 1] = laterals[i - 1] + F.interpolate(
                laterals[i], size=laterals[i - 1].shape[-2:], mode="bilinear", align_corners=False
            )
        fpn_outs = [fpn(lat) for fpn, lat in zip(self.fpn_convs, laterals)]
        base_hw = fpn_outs[0].shape[-2:]
        upsampled = [
            fpn_outs[0] if i == 0 else F.interpolate(f, size=base_hw, mode="bilinear", align_corners=False)
            for i, f in enumerate(fpn_outs)
        ]
        fused_feat = self.fuse_conv(torch.cat(upsampled, dim=1))
        logits = F.interpolate(self.cls_seg(fused_feat), size=out_hw, mode="bilinear", align_corners=False)
        return logits, fused_feat


# =====================================================================
# 5. 六臂统一分割模型封装 (支持端到端部署导出与两阶段无损训练切换)
# =====================================================================
class SixArmSegmentationModel(nn.Module):
    """
    支持全链路自主训练的实验臂：
      - 'B0'   : 纯影像基线
      - 'R'    : 真 AEF 特征层融合教师 (或 'R_null' 噪声对照)
      - 'D'    : 纯 RGB 学生 (训练期对齐冻结 R 教师，导出部署时移除 student_q_proj，忽略第 4 通道 NIR)
      - 'Bcap' : 同结构无教师容量对照 (仅用 CE 训练)
      - 'P'    : 代理特征预测与融合 (支持纯 3ch 或 3/4ch 自适应 P-Flex)
      - 'A'    : 共享 Adapter + 训练期辅助对齐头 (配对控制组 'B_A' 为相同 Adapter 仅用 CE 训练)
    """
    def __init__(
        self,
        backbone: nn.Module | None,
        in_channels_list: list[int],
        num_classes: int = 8,
        aef_dim: int = 64,
        arm: str = "B0",
        inject_mode: str = "mlp",
        flexible_nir: bool = False,
        proxy_arch: str = "light_dw",
        nir_input_mode: str = "real_nir",
        backbone_in_channels: int = 3,
        freeze_backbone: bool = True,
    ):
        super().__init__()
        assert arm in ("B0", "R", "Bcap", "P", "D", "A", "B_A"), f"Invalid arm: {arm}"
        self.backbone = backbone
        self.arm = arm
        self.backbone_in_channels = backbone_in_channels
        self.freeze_backbone = freeze_backbone
        self.strict_deploy_mode = False

        if self.backbone is not None and self.freeze_backbone:
            for p in self.backbone.parameters():
                p.requires_grad = False
            self.backbone.eval()

        self.head = TinyUPerNet(in_channels_list, channels=128, num_classes=num_classes)

        if arm == "R":
            self.injectors = nn.ModuleList([
                AEFInjector(in_dim=aef_dim, out_c=c, mode=inject_mode) for c in in_channels_list
            ])

        elif arm in ("Bcap", "P"):
            self.proxy_module = FlexibleRGBNIRProxyModule(
                in_channels_list=in_channels_list,
                aef_dim=aef_dim,
                flexible_nir=flexible_nir,
                proxy_arch=proxy_arch,
                nir_input_mode=nir_input_mode,
            )
            self.injectors = nn.ModuleList([
                AEFInjector(in_dim=aef_dim, out_c=c, mode=inject_mode) for c in in_channels_list
            ])

        elif arm in ("A", "B_A"):
            # B_A 与 A 拥有完全相同的 stem_adapters，但 B_A 不加教师对齐损失 (响应审计 A-09)
            self.stem_adapters = nn.ModuleList([
                nn.Sequential(
                    nn.Conv2d(c, c, kernel_size=1, bias=False),
                    nn.GroupNorm(16, c),
                ) for c in in_channels_list
            ])
            for adapter in self.stem_adapters:
                nn.init.zeros_(adapter[0].weight)
            if arm == "A":
                self.aux_heads = nn.ModuleList([
                    nn.Sequential(
                        nn.Conv2d(c, 256, kernel_size=1),
                        nn.GELU(),
                        nn.Conv2d(256, aef_dim, kernel_size=1),
                    ) for c in in_channels_list
                ])

        elif arm == "D":
            self.student_q_proj = nn.Conv2d(128, 128, kernel_size=1, bias=True)

    def train(self, mode: bool = True):
        super().train(mode)
        if self.backbone is not None and self.freeze_backbone:
            self.backbone.eval()
        return self

    def enable_stage2_nir_only_training(self) -> None:
        """
        响应审计 A-04 & A-08：
        两阶段分步训练法 Stage 2：完全冻结 RGB 主路、rgb_to_proxy、injectors 以及共享解码器 TinyUPerNet
        (含固定其 BatchNorm 统计量)，仅训练 nir_stem 与 nir_residual_heads。
        """
        assert self.arm in ("P", "Bcap") and self.proxy_module.flexible_nir
        for p in self.parameters():
            p.requires_grad = False
        for p in self.proxy_module.nir_stem.parameters():
            p.requires_grad = True
        for p in self.proxy_module.nir_residual_heads.parameters():
            p.requires_grad = True
        self.head.freeze_bn_stats = True
        self.head.eval()
        self.proxy_module.nir_drop_prob = 0.0

    def export_for_deployment(self) -> None:
        """
        响应审计 A-02 & A-07：
        切换为严格纯影像部署状态：移除训练期专用分支 (student_q_proj / aux_heads)，
        并开启 strict_deploy_mode (拒绝任何 aef_map 或 cached_feats 传入)。
        """
        if hasattr(self, "student_q_proj"):
            delattr(self, "student_q_proj")
        if hasattr(self, "aux_heads"):
            delattr(self, "aux_heads")
        self.strict_deploy_mode = True
        self.eval()

    def forward(
        self,
        img: torch.Tensor,
        aef_map: torch.Tensor | None = None,
        cached_feats: list[torch.Tensor] | None = None,
    ) -> dict[str, torch.Tensor | list[torch.Tensor]]:
        if self.strict_deploy_mode or (not self.training and self.arm in ("B0", "Bcap", "P", "D", "A", "B_A")):
            if aef_map is not None:
                raise RuntimeError(f"Security Violation: Arm '{self.arm}' forbids aef_map during inference/deploy!")
        if self.strict_deploy_mode and cached_feats is not None:
            raise RuntimeError("Security Violation: Deployment mode requires end-to-end raw image inference!")

        out_hw = img.shape[-2:]
        if cached_feats is not None:
            assert self.freeze_backbone, "Static cached_feats are strictly forbidden when fine-tuning backbone!"
            feats = cached_feats
        else:
            assert self.backbone is not None, "Backbone must be provided for end-to-end forward!"
            bb_in = img[:, :self.backbone_in_channels, :, :]
            feats = self.backbone(bb_in)

        proxy_rgb_only: list[torch.Tensor] = []
        proxy_rgb_nir: list[torch.Tensor] = []

        if self.arm in ("B0", "D"):
            fused_feats = feats

        elif self.arm == "R":
            assert aef_map is not None, "Arm 'R' requires real AEF (or null noise) input!"
            fused_feats = [f + inj(aef_map, f.shape[-2:]) for f, inj in zip(feats, self.injectors)]

        elif self.arm in ("Bcap", "P"):
            proxy_out = self.proxy_module(feats, img)
            hat_active = proxy_out["hat_active"]
            proxy_rgb_only = proxy_out["hat_rgb_only"]
            proxy_rgb_nir = proxy_out["hat_rgb_nir"]
            fused_feats = [
                f + inj(hat_e, f.shape[-2:]) for f, hat_e, inj in zip(feats, hat_active, self.injectors)
            ]

        elif self.arm in ("A", "B_A"):
            fused_feats = [f + adapter(f) for f, adapter in zip(feats, self.stem_adapters)]
            if self.training and self.arm == "A" and hasattr(self, "aux_heads"):
                proxy_rgb_only = [aux(f_new) for f_new, aux in zip(fused_feats, self.aux_heads)]

        logits, decoder_feat = self.head(fused_feats, out_hw)
        result: dict[str, torch.Tensor | list[torch.Tensor]] = {
            "logits": logits,
            "decoder_feat": decoder_feat,
            "proxy_rgb_only": proxy_rgb_only,
            "proxy_rgb_nir": proxy_rgb_nir,
        }
        if self.arm == "D" and self.training and hasattr(self, "student_q_proj"):
            result["q_feat"] = self.student_q_proj(decoder_feat)
        return result
```

```python
import numpy as np
import torch
import torch.nn as nn
import torch.nn.functional as F
from six_arm_models import SixArmSegmentationModel


# =====================================================================
# 1. 标签显式重映射与全局混淆矩阵评测器 (响应审计 A-05)
# =====================================================================
WHU_RAW_TO_TRAIN_ID = {0: 0, 10: 1, 20: 2, 30: 3, 40: 4, 50: 5, 60: 6, 70: 7}


def remap_whu_labels(raw_label: torch.Tensor) -> torch.Tensor:
    """
    将 WHU-OPT-SAR 官方原始标签 {0, 10, 20, 30, 40, 50, 60, 70} 显式映射为 {0..7}。
    若遇到未知像素值，统一映射为 0 (ignore_index)。
    """
    out = torch.zeros_like(raw_label, dtype=torch.long)
    for raw_val, train_id in WHU_RAW_TO_TRAIN_ID.items():
        out[raw_label == raw_val] = train_id
    return out


class DatasetConfusionMatrix:
    """
    响应审计 A-05：先在整个验证/测试集上累积混淆矩阵，再计算封闭类 mIoU。
    背景像素 (target == ignore_index) 不进入混淆矩阵统计。
    """
    def __init__(self, num_classes: int = 8, ignore_index: int = 0):
        self.num_classes = num_classes
        self.ignore_index = ignore_index
        self.mat = np.zeros((num_classes, num_classes), dtype=np.int64)

    def reset(self) -> None:
        self.mat.fill(0)

    @torch.no_grad()
    def update(self, logits: torch.Tensor, targets: torch.Tensor) -> None:
        preds = logits.argmax(dim=1).cpu().numpy().reshape(-1)
        targs = targets.cpu().numpy().reshape(-1)
        valid = (targs != self.ignore_index) & (targs >= 0) & (targs < self.num_classes)
        preds = preds[valid]
        targs = targs[valid]
        indices = self.num_classes * targs + preds
        counts = np.bincount(indices, minlength=self.num_classes ** 2)
        self.mat += counts.reshape(self.num_classes, self.num_classes)

    def compute_closed_class_miou(self) -> dict[str, float | dict[int, float]]:
        valid_classes = [c for c in range(self.num_classes) if c != self.ignore_index]
        per_class_iou: dict[int, float] = {}
        for c in valid_classes:
            tp = int(self.mat[c, c])
            fp = int(self.mat[:, c].sum()) - tp
            fn = int(self.mat[c, :].sum()) - tp
            denom = tp + fp + fn
            if denom > 0:
                per_class_iou[c] = float(tp / denom)
        miou = float(np.mean(list(per_class_iou.values()))) if per_class_iou else 0.0
        return {"closed_miou": miou, "per_class_iou": per_class_iou}


# =====================================================================
# 2. 教师栅格安全解码、NaN/Inf 物理清理与 Footprint 池化 (响应审计 A-06)
# =====================================================================
def decode_and_mask_teacher(
    raw_teacher: torch.Tensor,
    teacher_format: str = "aef_float",
) -> tuple[torch.Tensor, torch.Tensor]:
    """
    响应审计 A-06：
      - 显式区分 'aef_float' 与 'olmoearth_int8'，防止重复解码；
      - OlmoEarth 严格采用官方公式 sign(q) * (|q| / 127.5)^2，并检查全通道 != -128；
      - 浮点路径先判断 torch.isfinite 再用 torch.nan_to_num 清除 NaN/Inf (避免 NaN * 0 = NaN)。
    返回:
      decoded_feat: (B, C, H, W) 清理后的有效特征
      valid_mask  : (B, 1, H, W) 1.0 表示有效，0.0 表示 NoData/无效
    """
    assert teacher_format in ("aef_float", "olmoearth_int8"), f"Unknown teacher_format: {teacher_format}"

    if teacher_format == "olmoearth_int8":
        finite_ok = torch.isfinite(raw_teacher.float()).all(dim=1, keepdim=True)
        nodata_ok = (raw_teacher != -128).all(dim=1, keepdim=True)
        clean_q = torch.nan_to_num(raw_teacher.float(), nan=0.0, posinf=0.0, neginf=0.0)
        x = clean_q / 127.5
        decoded = torch.sign(x) * (x ** 2)
        norms = decoded.norm(p=2, dim=1, keepdim=True)
        valid_mask = (finite_ok & nodata_ok & (norms > 1e-6)).float()
        decoded = (decoded / norms.clamp_min(1e-6)) * valid_mask
    else:
        finite_ok = torch.isfinite(raw_teacher).all(dim=1, keepdim=True)
        clean_x = torch.nan_to_num(raw_teacher.float(), nan=0.0, posinf=0.0, neginf=0.0)
        norms = clean_x.norm(p=2, dim=1, keepdim=True)
        valid_mask = (finite_ok & (norms > 1e-6)).float()
        decoded = (clean_x / norms.clamp_min(1e-6)) * valid_mask

    return decoded, valid_mask


def pool_teacher_to_footprint(
    aef_target: torch.Tensor,
    valid_mask: torch.Tensor,
    target_hw: tuple[int, int],
) -> tuple[torch.Tensor, torch.Tensor]:
    """
    响应审计 A-06：先在清理掉 NaN 的特征上做掩膜加权平均池化，再对非零池化向量重新 L2 归一化。
    """
    clean_target = torch.nan_to_num(aef_target, nan=0.0, posinf=0.0, neginf=0.0)
    clean_mask = torch.nan_to_num(valid_mask, nan=0.0, posinf=0.0, neginf=0.0)
    masked_sum = F.adaptive_avg_pool2d(clean_target * clean_mask, output_size=target_hw)
    mask_ratio = F.adaptive_avg_pool2d(clean_mask, output_size=target_hw)
    pooled_raw = masked_sum / mask_ratio.clamp_min(1e-6)
    norms = pooled_raw.norm(p=2, dim=1, keepdim=True)
    pooled_valid = ((mask_ratio > 0.5) & (norms > 1e-6)).squeeze(1).float()
    pooled_aef = (pooled_raw / norms.clamp_min(1e-6)) * pooled_valid.unsqueeze(1)
    return pooled_aef, pooled_valid


# =====================================================================
# 3. 代理对齐损失与六臂总损失 (响应审计 A-06 & A-10：限流 InfoNCE + 教师掩膜)
# =====================================================================
def compute_proxy_alignment_loss(
    proxy_preds: list[torch.Tensor],
    aef_target: torch.Tensor,
    valid_mask: torch.Tensor,
    mode: str = "cosine",
    temperature: float = 0.07,
    max_infonce_tokens: int = 1024,
    layer_weights: list[float] | None = None,
) -> torch.Tensor:
    if not proxy_preds:
        return aef_target.new_tensor(0.0)
    if layer_weights is None:
        layer_weights = [0.1, 0.2, 0.3, 0.4][:len(proxy_preds)]
    weight_sum = sum(layer_weights)
    total_loss = aef_target.new_tensor(0.0)

    for w, pred in zip(layer_weights, proxy_preds):
        t_footprint, v_mask = pool_teacher_to_footprint(aef_target, valid_mask, pred.shape[-2:])
        valid_count = v_mask.sum()
        if valid_count < 1.0:
            continue

        if mode == "cosine":
            cos_sim = F.cosine_similarity(pred, t_footprint, dim=1, eps=1e-6)
            loss_l = ((1.0 - cos_sim) * v_mask).sum() / valid_count.clamp_min(1.0)
        elif mode == "infonce":
            # 响应审计 A-10：限制最大采样点数 max_infonce_tokens (默认 1024)，防止 65536x65536 矩阵炸 16GiB 显存
            C = pred.shape[1]
            s_flat = F.normalize(pred, dim=1, eps=1e-6).permute(0, 2, 3, 1).reshape(-1, C)
            t_flat = F.normalize(t_footprint, dim=1, eps=1e-6).permute(0, 2, 3, 1).reshape(-1, C)
            v_idx = torch.nonzero(v_mask.reshape(-1) > 0.5, as_tuple=False).squeeze(-1)
            if v_idx.numel() > 8:
                if v_idx.numel() > max_infonce_tokens:
                    perm = torch.randperm(v_idx.numel(), device=pred.device)[:max_infonce_tokens]
                    v_idx = v_idx[perm]
                s_v, t_v = s_flat[v_idx], t_flat[v_idx]
                logits_ab = (s_v @ t_v.T) / temperature
                targets = torch.arange(s_v.shape[0], device=pred.device)
                loss_l = 0.5 * (F.cross_entropy(logits_ab, targets) + F.cross_entropy(logits_ab.T, targets))
            else:
                loss_l = aef_target.new_tensor(0.0)
        else:
            raise ValueError(f"Unknown alignment mode: {mode}")

        total_loss = total_loss + (w / weight_sum) * loss_l
    return total_loss


def compute_six_arm_loss(
    arm: str,
    student_out: dict,
    labels: torch.Tensor,
    aef_target: torch.Tensor | None = None,
    aef_valid_mask: torch.Tensor | None = None,
    teacher_out: dict | None = None,
    ignore_index: int = 0,
    lambda_aef: float = 0.5,
    align_mode: str = "cosine",
    kd_beta: float = 1.0,
    kd_temp: float = 4.0,
    feat_kd_weight: float = 0.0,
) -> tuple[torch.Tensor, dict[str, float]]:
    logits = student_out["logits"]
    valid_label_mask = (labels != ignore_index)
    if valid_label_mask.sum() > 0:
        loss_ce = F.cross_entropy(logits, labels, ignore_index=ignore_index)
    else:
        # 响应审计 A-06：当整批标签全为 ignore_index 时避免产生 NaN
        loss_ce = logits.sum() * 0.0

    metrics = {"loss_ce": float(loss_ce.item())}
    total_loss = loss_ce

    if arm in ("P", "A") and lambda_aef > 0.0:
        assert aef_target is not None and aef_valid_mask is not None
        loss_rgb = compute_proxy_alignment_loss(
            student_out["proxy_rgb_only"], aef_target, aef_valid_mask, mode=align_mode
        )
        if student_out["proxy_rgb_nir"]:
            loss_nir = compute_proxy_alignment_loss(
                student_out["proxy_rgb_nir"], aef_target, aef_valid_mask, mode=align_mode
            )
            loss_align = 0.5 * (loss_rgb + loss_nir)
            metrics["loss_align_rgb"] = float(loss_rgb.item())
            metrics["loss_align_nir"] = float(loss_nir.item())
        else:
            loss_align = loss_rgb
            metrics["loss_align_rgb"] = float(loss_rgb.item())

        total_loss = total_loss + lambda_aef * loss_align

    elif arm == "D":
        assert teacher_out is not None, "Arm 'D' requires frozen teacher outputs!"
        with torch.no_grad():
            t_logits = teacher_out["logits"].detach()
            t_feat = teacher_out["decoder_feat"].detach()

        # 响应审计 A-06：D 臂同时结合标签有效掩膜与教师有效区掩膜
        valid_pix = valid_label_mask.unsqueeze(1).float()
        if aef_valid_mask is not None:
            t_valid_up = (
                F.interpolate(aef_valid_mask.float(), size=labels.shape[-2:], mode="nearest") > 0.5
            ).float()
            valid_pix = valid_pix * t_valid_up

        if valid_pix.sum() > 0:
            s_log_prob = F.log_softmax(logits / kd_temp, dim=1)
            t_prob = F.softmax(t_logits / kd_temp, dim=1)
            kl_pixel = F.kl_div(s_log_prob, t_prob, reduction="none").sum(dim=1, keepdim=True)
            loss_kl = (kl_pixel * valid_pix).sum() / valid_pix.sum().clamp_min(1.0) * (kd_temp ** 2)
        else:
            loss_kl = logits.sum() * 0.0

        total_loss = total_loss + kd_beta * loss_kl
        metrics["loss_kl"] = float(loss_kl.item())

        if feat_kd_weight > 0.0 and "q_feat" in student_out:
            q_feat = student_out["q_feat"]
            if aef_valid_mask is not None:
                f_valid = (
                    F.interpolate(aef_valid_mask.float(), size=q_feat.shape[-2:], mode="nearest").squeeze(1) > 0.5
                ).float()
            else:
                f_valid = torch.ones_like(q_feat[:, 0, :, :])

            if f_valid.sum() > 0:
                cos_f = F.cosine_similarity(q_feat, t_feat, dim=1, eps=1e-6)
                loss_fkd = ((1.0 - cos_f) * f_valid).sum() / f_valid.sum().clamp_min(1.0)
            else:
                loss_fkd = logits.sum() * 0.0
            total_loss = total_loss + feat_kd_weight * loss_fkd
            metrics["loss_fkd"] = float(loss_fkd.item())

    metrics["loss_total"] = float(total_loss.item())
    return total_loss, metrics


# =====================================================================
# 4. G0 阶段端到端自动化验收套件 (响应审计 A-05 / A-06 / A-07 / A-10)

class DummyMultiScaleBackbone(nn.Module):
    """用于 G0 端到端验收的轻量多尺度骨干（替代随机缓存特征，验证从原始影像到预测的完整链路）"""
    def __init__(self, in_ch: int = 3, out_channels_list: list[int] = [128, 256, 512, 1024]):
        super().__init__()
        self.stages = nn.ModuleList()
        curr_c = in_ch
        for out_c in out_channels_list:
            self.stages.append(
                nn.Sequential(
                    nn.Conv2d(curr_c, out_c, kernel_size=3, stride=2, padding=1, bias=False),
                    nn.GroupNorm(16, out_c),
                    nn.GELU(),
                )
            )
            curr_c = out_c

    def forward(self, x: torch.Tensor) -> list[torch.Tensor]:
        feats = []
        for stage in self.stages:
            x = stage(x)
            feats.append(x)
        return feats
```
