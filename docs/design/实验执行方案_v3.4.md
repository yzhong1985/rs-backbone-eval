## 0. 方案总体结论与边界声明

> 本方案以单期高分影像语义分割为首个验证任务，在全链路自主构建数据管线与训练代码的条件下，分别研究**纯 RGB 教师蒸馏路线 `D`**，以及**单权重兼容 `RGB` / `RGB+NIR` 并支持按省/区域定制的 `P-Flex-Prov` 路线**。
> * **能力边界**：`D` 的当前学生结构仅使用 3 波段 `RGB`；`P` 与同结构无教师控制组 `Bcap` 使用完全相同的 `ScaleDecoupledProvincialFlexPlugin` 网络结构，通过“训练集 AEF 字典初始化 + 教师对齐损失”开关分别检验监督收益。省级插件提供的是从区域影像与训练区 AEF 学习到的**区域先验约束**，不等同于恢复该地点、该年份未观测到的真实多模态信息。
> * **交付与验收边界**：训练期教师配对须先通过我方独立的地理配准验收（`G0b`），部署期模型不依赖外部教师栅格或精确经纬度坐标。在“只换特征插件”的交付模式下，**公共 `LIM` 底座与公共解码头在省级训练阶段完全冻结**（参数与运行缓冲区零变化），仅允许替换或合并区域插件权重；`RGB` 性能保持、`NIR` 独立增益、区域训练净收益、教师监督贡献与实际存储/时延/显存开销均须通过我方自跑的匹配控制实验实测验证，不作先验保证。

### 2.2 `ScaleDecoupledProvincialFlexPlugin` 尺度解耦结构与精确参数表

为兼顾高分辨率任务（如 $0.5\text{ m}\sim 1\text{ m}$）的几何边界锐利度与中分辨率卫星影像（$4\text{ m}\sim 5\text{ m}$）的宏观类别区分度，插件按特征金字塔层级 `[stride-4, stride-8, stride-16, stride-32]`（通道 `[128, 256, 512, 1024]`）实行尺度解耦分工：
* **浅层（`shallow_levels=(0, 1)`，即 `stride-4, 8`）**：**不注入 10m AEF**，保护 `LIM` 原生几何边缘；当客户传入 4 波段 `RGB+NIR` 时，由单通道 `nir_pyramid_stem` 提取原生高分辨率近红外特征，经 `shallow_nir_injectors` 做零初始化边缘残差修正。
* **深层（`deep_levels=(2, 3)`，即 `stride-16, 32`）**：由 `deep_rgb_query`（若有 NIR 则叠加 `deep_nir_query_res`）生成 64 维查询向量，检索该区域专属原型记忆库 $M_{\text{prov}} \in \mathbb{R}^{K \times 64}$，加权合成高仿 AEF 表征并经 `deep_aef_injectors` 注入。

**默认配置（`in_channels=[128, 256, 512, 1024]`, `K=512`, `aef_dim=64`, `shallow=(0,1)`, `deep=(2,3)`）精确参数明细**：

| 插件子模块 | 所在层级 | 参数量 | 省级训练状态（默认冻结字典） | 说明 |
| :--- | :--- | ---: | :--- | :--- |
| `deep_rgb_query` | `l = 2, 3` (`512, 1024`) | **216,448** | 可训练 | 两级深度可分离查询头：$(128\times 512+9920)+(128\times 1024+9920)$ |
| `nir_pyramid_stem` | `l = 0, 1, 2, 3` | **28,192** | 可训练 | 单通道高分 NIR 四级特征金字塔流 |
| `shallow_nir_injectors` | `l = 0, 1` (`128, 256`) | **12,672** | 可训练 | 浅层高分 NIR 线性零初始化边缘注入器 |
| `deep_nir_query_res` | `l = 2, 3` (`512, 1024`) | **110,976** | 可训练 | 深层 NIR 残差查询分支（零初始化末层） |
| `deep_aef_injectors` | `l = 2, 3` (`512, 1024`) | **428,032** | 可训练 | 深层两层 MLP 零初始化 AEF 注入器 |
| `province_codebook` | 全局共享 (`512 × 64`) | **32,768** | 冻结（首轮默认） | 训练集 AEF 余弦 K-Means 聚类原型字典 |
| **插件总参数量** | — | **829,088** | — | 理论 `FP32` 约 `3.16 MB`，理论 `FP16` 约 `1.58 MB`（含元数据实际文件体积以实测为准） |
| **冻结字典后可训练参数** | — | **796,320** | — | 仅占 $300\text{M}$ `LIM` 主干参数量的 $0.265\%$ |

> **注**：若使用标准四级全挂载的 `DepthwiseSeparableProxyHead`（覆盖 `[128, 256, 512, 1024]` 全部四层），其独立参数量为 $\sum_{c} (128c + 9920) = \mathbf{285,440}$。

### 2.3 双模式交付契约（公共底座哈希绑定与完整元配置序列化）

1. **公共底座哈希绑定（`compute_base_model_hash`）**：先训练并锁定公共 `LIM` + 公共 `TinyUPerNet`，计算二者结构与全部参数/缓冲区的 SHA-256 摘要（取前 16 位 `base_model_hash`）。任何独立导出的省级插件（`.pt`）均须携带该哈希；加载插件时若 `base_model_hash` 不匹配，立即抛出 `ValueError` 拒绝挂载。
2. **合并单文件导出与重载（`export_merged_province_checkpoint` / `load_merged_province_checkpoint`）**：仅适用于 `P-Flex-Prov`（及满足前提的纯线性折叠路线）。导出文件严格写入完整构造配置 `meta`：
   * `num_prototypes`、`aef_dim`、`in_channels_list`、`shallow_levels`、`deep_levels`、`temperature`
   * `nir_input_mode`（区分 `"real_nir"` 与 `"rgb_mean_placeholder"`，防止重载后行为静默偏移）
   * `backbone_in_channels`、`plugin_enabled`、`folded_linear_proxy`、`base_model_hash`
   * 实际训练数据标识（区域名、AEF 年份、支持 GSD、波段顺序与归一化规范）。
3. **`D` 路线独立纯推理导出（`export_student_d_inference` / `load_student_d_inference`）**：明确与省级合并导出解耦，导出时剥离训练期对齐投影器 `student_q_proj`，重载时显式断言 `missing_keys` 仅包含 `student_q_proj.*` 且 `unexpected_keys` 为空。

## 3. 数据协议与区域字典构建规范（`V32-07 / V32-08` 落实）

1. **波段顺序与辐射归一化**：原始 4 波段影像读入后显式重排为 `[R, G, B, NIR]`；若影像已按地表反射率缩放至 `[0, 1]`，归一化步骤跳过 `/ 10000.0` 防止二次缩放，仅减均值除标准差。
2. **标签与无效值防护**：
   * `ignore_index = 0`（WHU-OPT 映射 `{0,10..70} -> {0..7}`；FBP 映射 `{0..24}`）。若某批次全部像素均为 `0`，交叉熵损失安全返回带梯度图的 `0.0`，防止 `NaN`。
   * 教师特征（`AEF 64`）全零像素、越界填充像素与 `NaN/Inf` 统一置零并生成 `valid_mask`，仅在有效区计算 Cosine + SmoothL1 对齐损失。
3. **严格训练区字典构建与时间记录**：
   * 先按**原始大图景号（Scene ID）**隔离划分 `train / val / test`（严格禁止同景切片跨集合）。
   * 区域原型字典 `fit_and_init_codebook_kmeans()` **严格仅从 `train` 集合对应的 AEF 栅格采样**，执行确定性随机种子的余弦 K-Means 聚类（记录采样数量、各类别/季节覆盖统计、影像成像日期与 AEF 年份）。若额外测试“使用目标省无标签全图（含测试区地理范围但无语义标签）构建字典”，须单列为独立消融设置，不得与严格地理隔离测试结果混淆。
4. **高分辨率与多尺度边界**：
   * 首轮实验锁定中分辨率卫星影像（$4\text{ m}$ GF-2 / $5\text{ m}$ GF-1）验证，明确标注支持 GSD 范围。
   * 针对亚米级（$0.5\text{ m}\sim 1\text{ m}$）任务，单列真实亚米级评测子集，同时报告整体 `mIoU`、边界 `Boundary-F1` 与小目标类别 `IoU`，不以中分辨率降采样增广代替亚米级实测结论。

import torch.nn.functional as F


def compute_base_model_hash(backbone: nn.Module, head: nn.Module) -> str:
    """计算冻结公共底座与公共解码头的结构+参数/缓冲区 SHA-256 摘要（前 16 位）"""
    h = hashlib.sha256()
    h.update(repr(backbone).encode("utf-8"))
    h.update(repr(head).encode("utf-8"))
    for prefix, mod in [("backbone", backbone), ("head", head)]:
        for k, v in sorted(mod.state_dict().items()):
            h.update(f"{prefix}.{k}:{tuple(v.shape)}:{v.dtype}".encode("utf-8"))
            h.update(v.detach().cpu().contiguous().numpy().tobytes())
    return h.hexdigest()[:16]


def set_frozen_eval(module: nn.Module) -> None:
    """冻结模块全部参数并将含统计量的归一化层（如 BatchNorm）锁定在 eval 状态"""
    for p in module.parameters():
        p.requires_grad_(False)
    module.eval()


def pool_teacher_to_footprint(
    teacher_aef: torch.Tensor,
    target_hw: tuple[int, int],
    valid_mask: Optional[torch.Tensor] = None,
) -> tuple[torch.Tensor, torch.Tensor]:
    """
    将空间对齐的教师特征按目标网格尺寸做有效区加权池化（上游须已完成地理范围配准）。
    """
    teacher_clean = torch.nan_to_num(teacher_aef, nan=0.0, posinf=0.0, neginf=0.0)
    if valid_mask is None:
        valid_mask = (teacher_clean.abs().sum(dim=1, keepdim=True) > 1e-8).float()
    else:
        valid_mask = torch.nan_to_num(valid_mask.float(), nan=0.0, posinf=0.0, neginf=0.0)
        valid_mask = (valid_mask > 0.5).float()

    masked_teacher = teacher_clean * valid_mask
    pooled_sum = F.adaptive_avg_pool2d(masked_teacher, output_size=target_hw)
    pooled_cnt = F.adaptive_avg_pool2d(valid_mask, output_size=target_hw)
    pooled_teacher = pooled_sum / pooled_cnt.clamp_min(1e-6)
    pooled_valid = (pooled_cnt > 0.1).float()
    pooled_teacher = pooled_teacher * pooled_valid
    return pooled_teacher, pooled_valid


def safe_cross_entropy(logits: torch.Tensor, target: torch.Tensor, ignore_index: int = 0) -> torch.Tensor:
    """防止全忽略标签切片产生 NaN 的安全交叉熵"""
    valid = target != ignore_index
    if not valid.any():
        return logits.sum() * 0.0
    return F.cross_entropy(logits, target, ignore_index=ignore_index)


def safe_aef_distill_loss(
    pred_aef: torch.Tensor,
    target_aef: torch.Tensor,
    valid_mask: Optional[torch.Tensor] = None,
    cos_weight: float = 1.0,
    l1_weight: float = 0.5,
) -> torch.Tensor:
    """仅在有效教师区域内计算 Cosine + SmoothL1 对齐损失"""
    target_clean = torch.nan_to_num(target_aef, nan=0.0, posinf=0.0, neginf=0.0)
    if valid_mask is None:
        valid_mask = (target_clean.abs().sum(dim=1, keepdim=True) > 1e-8).float()
    valid_2d = valid_mask.squeeze(1) > 0.5
    if not valid_2d.any():
        return pred_aef.sum() * 0.0

    pred_norm = F.normalize(pred_aef, p=2, dim=1)
    tgt_norm = F.normalize(target_clean, p=2, dim=1)
    cos_map = 1.0 - (pred_norm * tgt_norm).sum(dim=1)
    cos_loss = cos_map[valid_2d].mean()

    l1_map = F.smooth_l1_loss(pred_aef, target_clean, reduction="none").mean(dim=1)
    l1_loss = l1_map[valid_2d].mean()
    return cos_weight * cos_loss + l1_weight * l1_loss


def safe_infonce_loss(
    student_feat: torch.Tensor,
    teacher_feat: torch.Tensor,
    valid_mask: Optional[torch.Tensor] = None,
    max_samples: int = 1024,
    temperature: float = 0.1,
) -> torch.Tensor:
    """带像素采样上限的对称 InfoNCE 损失（防显存溢出与空有效区 NaN）"""
    B, D, H, W = student_feat.shape
    teacher_clean = torch.nan_to_num(teacher_feat, nan=0.0, posinf=0.0, neginf=0.0)
    if valid_mask is None:
        valid_mask = (teacher_clean.abs().sum(dim=1, keepdim=True) > 1e-8).float()

    s_flat = student_feat.permute(0, 2, 3, 1).reshape(-1, D)
    t_flat = teacher_clean.permute(0, 2, 3, 1).reshape(-1, D)
    v_flat = valid_mask.reshape(-1) > 0.5

    s_valid = s_flat[v_flat]
    t_valid = t_flat[v_flat]
    n = s_valid.shape[0]
    if n < 2:
        return student_feat.sum() * 0.0

    if n > max_samples:
        idx = torch.randperm(n, device=student_feat.device)[:max_samples]
        s_valid = s_valid[idx]
        t_valid = t_valid[idx]

    s_norm = F.normalize(s_valid, p=2, dim=-1)
    t_norm = F.normalize(t_valid, p=2, dim=-1)
    logits = (s_norm @ t_norm.T) / temperature
    labels = torch.arange(s_norm.shape[0], device=student_feat.device)
    return 0.5 * (F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels))


class DepthwiseSeparableProxyHead(nn.Module):
    """单级深度可分离代理头：参数量 = 128 * in_c + 9920（四级 [128,256,512,1024] 共 285,440）"""

    def __init__(self, in_c: int, aef_dim: int = 64, mid_c: int = 128):
        super().__init__()
        self.net = nn.Sequential(
            nn.Conv2d(in_c, mid_c, kernel_size=1, bias=False),
            nn.GroupNorm(8, mid_c),
            nn.GELU(),
            nn.Conv2d(mid_c, mid_c, kernel_size=3, padding=1, groups=mid_c, bias=False),
            nn.GroupNorm(8, mid_c),
            nn.GELU(),
            nn.Conv2d(mid_c, aef_dim, kernel_size=1, bias=True),
        )

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return self.net(x)


class AEFInjector(nn.Module):
    """零初始化残差特征注入器"""

    def __init__(self, in_dim: int, out_c: int, mode: str = "mlp"):
        super().__init__()
        self.mode = mode
        if mode == "linear":
            self.proj = nn.Conv2d(in_dim, out_c, kernel_size=1, bias=True)
            nn.init.zeros_(self.proj.weight)
            nn.init.zeros_(self.proj.bias)
        elif mode == "mlp":
            mid = max(64, in_dim * 2)
            self.proj = nn.Sequential(
                nn.Conv2d(in_dim, mid, kernel_size=1, bias=False),
                nn.GroupNorm(8, mid),
                nn.GELU(),
                nn.Conv2d(mid, out_c, kernel_size=1, bias=True),
            )
            nn.init.zeros_(self.proj[-1].weight)
            nn.init.zeros_(self.proj[-1].bias)
        else:
            raise ValueError(f"Unsupported injector mode: {mode}")

    def forward(self, feat_in: torch.Tensor, target_hw: tuple[int, int]) -> torch.Tensor:
        if feat_in.shape[-2:] != target_hw:
            feat_in = F.interpolate(feat_in, size=target_hw, mode="bilinear", align_corners=False)
        return self.proj(feat_in)


class LinearRGBProxyModule(nn.Module):
    """纯线性 RGB 代理模块（支持发货前通过矩阵重参数化折叠进解码头第一层）"""

    def __init__(self, in_channels_list: list[int], aef_dim: int = 64):
        super().__init__()
        self.rgb_to_proxy = nn.ModuleList([
            nn.Conv2d(c, aef_dim, kernel_size=1, bias=False) for c in in_channels_list
        ])
        self.injectors = nn.ModuleList([
            AEFInjector(in_dim=aef_dim, out_c=c, mode="linear") for c in in_channels_list
        ])

    def forward(self, feats: list[torch.Tensor]) -> dict[str, list[torch.Tensor]]:
        fused, proxies = [], []
        for f, proj, inj in zip(feats, self.rgb_to_proxy, self.injectors):
            p = proj(f)
            proxies.append(p)
            fused.append(f + inj(p, f.shape[-2:]))
        return {"fused_feats": fused, "proxy_rgb_only": proxies, "proxy_rgb_nir": []}


class ScaleDecoupledProvincialFlexPlugin(nn.Module):
    """
    尺度解耦省级特征插件（默认 K=512, shallow=(0,1), deep=(2,3) 下总参数 829,088）：
      - 浅层 (0, 1): 不注入 10m AEF；仅在提供有效第 4 波段 NIR 时注入高分 NIR 边缘残差；
      - 深层 (2, 3): 检索训练集构建的省级 AEF 原型记忆库 M_prov 并经零初始化 Injector 注入语义。
    """

    def __init__(
        self,
        in_channels_list: list[int] = [128, 256, 512, 1024],
        aef_dim: int = 64,
        num_prototypes: int = 512,
        shallow_levels: tuple[int, ...] = (0, 1),
        deep_levels: tuple[int, ...] = (2, 3),
        nir_drop_prob: float = 0.5,
        temperature: float = 0.07,
        nir_input_mode: str = "real_nir",
    ):
        super().__init__()
        if nir_input_mode not in ("real_nir", "rgb_mean_placeholder"):
            raise ValueError(f"Unsupported nir_input_mode: {nir_input_mode}")

        self.in_channels_list = list(in_channels_list)
        self.aef_dim = aef_dim
        self.num_prototypes = num_prototypes
        self.shallow_levels = tuple(shallow_levels)
        self.deep_levels = tuple(deep_levels)
        self.nir_drop_prob = nir_drop_prob
        self.temperature = temperature
        self.nir_input_mode = nir_input_mode
        self.province_name = "uninitialized"
        self.codebook_metadata: dict[str, Any] = {}

        # 1. 省级 AEF 原型记忆库 (512 x 64 = 32,768)
        self.province_codebook = nn.Parameter(
            F.normalize(torch.randn(num_prototypes, aef_dim), p=2, dim=-1)
        )

        # 2. 原生高分单通道 NIR 金字塔提取流 (28,192)
        self.nir_pyramid_stem = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(
                    1 if i == 0 else 32,
                    32,
                    kernel_size=3,
                    stride=4 if i == 0 else 2,
                    padding=1,
                    bias=False,
                ),
                nn.GroupNorm(8, 32),
                nn.GELU(),
            )
            for i in range(len(in_channels_list))
        ])

        # 3. 浅层高分 NIR 边缘注入器 (12,672)
        self.shallow_nir_injectors = nn.ModuleDict({
            str(l): AEFInjector(in_dim=32, out_c=in_channels_list[l], mode="linear")
            for l in self.shallow_levels
        })

        # 4. 深层 RGB 查询头 (216,448) + 深层 NIR 残差查询 (110,976) + 深层 AEF 注入器 (428,032)
        self.deep_rgb_query = nn.ModuleDict({
            str(l): DepthwiseSeparableProxyHead(in_channels_list[l], aef_dim=aef_dim, mid_c=128)
            for l in self.deep_levels
        })
        self.deep_nir_query_res = nn.ModuleDict({
            str(l): nn.Sequential(
                nn.Conv2d(in_channels_list[l] + 32, 64, kernel_size=1, bias=False),
                nn.GroupNorm(8, 64),
                nn.GELU(),
                nn.Conv2d(64, aef_dim, kernel_size=1, bias=True),
            )
            for l in self.deep_levels
        })
        for head in self.deep_nir_query_res.values():
            nn.init.zeros_(head[-1].weight)
            nn.init.zeros_(head[-1].bias)

        self.deep_aef_injectors = nn.ModuleDict({
            str(l): AEFInjector(in_dim=aef_dim, out_c=in_channels_list[l], mode="mlp")
            for l in self.deep_levels
        })

    @torch.no_grad()
    def fit_and_init_codebook_kmeans(
        self,
        train_aef_vectors: torch.Tensor,
        province_name: str,
        seed: int = 42,
        num_iters: int = 15,
        metadata: Optional[dict[str, Any]] = None,
    ) -> None:
        """
        严格仅使用训练集 AEF 向量执行确定性余弦 K-Means 聚类并初始化省级字典。
        """
        if train_aef_vectors.ndim != 2 or train_aef_vectors.shape[1] != self.aef_dim:
            raise ValueError(f"Expected (N, {self.aef_dim}), got {tuple(train_aef_vectors.shape)}")
        clean = torch.nan_to_num(train_aef_vectors.float(), nan=0.0, posinf=0.0, neginf=0.0)
        valid = clean.abs().sum(dim=1) > 1e-8
        clean = F.normalize(clean[valid], p=2, dim=-1)
        if clean.shape[0] < self.num_prototypes:
            raise ValueError(f"Valid training AEF samples ({clean.shape[0]}) < num_prototypes ({self.num_prototypes})")

        gen = torch.Generator(device=clean.device)
        gen.manual_seed(seed)
        perm = torch.randperm(clean.shape[0], generator=gen, device=clean.device)
        centers = clean[perm[: self.num_prototypes]].clone()

        for _ in range(num_iters):
            sim = clean @ centers.T
            assign = sim.argmax(dim=1)
            new_centers = torch.zeros_like(centers)
            new_centers.index_add_(0, assign, clean)
            counts = torch.bincount(assign, minlength=self.num_prototypes).unsqueeze(1)
            non_empty = counts.squeeze(1) > 0
            new_centers[non_empty] = F.normalize(new_centers[non_empty], p=2, dim=-1)
            if (~non_empty).any():
                re_idx = torch.randperm(clean.shape[0], generator=gen, device=clean.device)[: (~non_empty).sum()]
                new_centers[~non_empty] = clean[re_idx]
            centers = new_centers

        self.province_codebook.copy_(centers.to(self.province_codebook.dtype))
        self.province_name = province_name
        self.codebook_metadata = {
            "province_name": province_name,
            "num_prototypes": self.num_prototypes,
            "aef_dim": self.aef_dim,
            "train_sample_count": int(clean.shape[0]),
            "seed": seed,
            **(metadata or {}),
        }

    def get_config_dict(self) -> dict[str, Any]:
        return {
            "in_channels_list": self.in_channels_list,
            "aef_dim": self.aef_dim,
            "num_prototypes": self.num_prototypes,
            "shallow_levels": list(self.shallow_levels),
            "deep_levels": list(self.deep_levels),
            "nir_drop_prob": self.nir_drop_prob,
            "temperature": self.temperature,
            "nir_input_mode": self.nir_input_mode,
            "province_name": self.province_name,
            "codebook_metadata": self.codebook_metadata,
        }

    def forward(self, feats: list[torch.Tensor], img: torch.Tensor) -> dict[str, list[torch.Tensor]]:
        c_in = img.shape[1]
        has_4th = c_in == 4
        if has_4th and self.nir_input_mode == "rgb_mean_placeholder":
            x_nir_in = img[:, :3, :, :].mean(dim=1, keepdim=True)
        elif has_4th:
            x_nir_in = img[:, 3:4, :, :]
        else:
            x_nir_in = None

        use_nir = has_4th and (not (self.training and torch.rand(1, device=img.device).item() < self.nir_drop_prob))

        nir_feats: list[torch.Tensor] = []
        if x_nir_in is not None:
            curr = x_nir_in
            for stem_layer, f in zip(self.nir_pyramid_stem, feats):
                curr = stem_layer(curr)
                if curr.shape[-2:] != f.shape[-2:]:
                    curr = F.interpolate(curr, size=f.shape[-2:], mode="bilinear", align_corners=False)
                nir_feats.append(curr)

        codebook_norm = F.normalize(self.province_codebook, p=2, dim=-1)
        fused_feats, hat_aef_rgb_list, hat_aef_full_list = [], [], []

        for l, f in enumerate(feats):
            key = str(l)
            if l in self.shallow_levels:
                if use_nir:
                    f_out = f + self.shallow_nir_injectors[key](nir_feats[l], f.shape[-2:])
                else:
                    f_out = f
                fused_feats.append(f_out)
            elif l in self.deep_levels:
                b, _, h, w = f.shape
                q_rgb = self.deep_rgb_query[key](f)
                q_rgb_norm = F.normalize(q_rgb, p=2, dim=1).permute(0, 2, 3, 1).reshape(b, h * w, -1)
                attn_rgb = F.softmax((q_rgb_norm @ codebook_norm.T) / self.temperature, dim=-1)
                hat_aef_rgb = (attn_rgb @ codebook_norm).permute(0, 2, 1).reshape(b, -1, h, w)
                hat_aef_rgb_list.append(hat_aef_rgb)

                if x_nir_in is not None:
                    q_full = q_rgb + self.deep_nir_query_res[key](torch.cat([f, nir_feats[l]], dim=1))
                    q_full_norm = F.normalize(q_full, p=2, dim=1).permute(0, 2, 3, 1).reshape(b, h * w, -1)
                    attn_full = F.softmax((q_full_norm @ codebook_norm.T) / self.temperature, dim=-1)
                    hat_aef_full = (attn_full @ codebook_norm).permute(0, 2, 1).reshape(b, -1, h, w)
                    hat_aef_full_list.append(hat_aef_full)

                active_aef = hat_aef_full if use_nir else hat_aef_rgb
                f_out = f + self.deep_aef_injectors[key](active_aef, (h, w))
                fused_feats.append(f_out)
            else:
                fused_feats.append(f)

        return {
            "fused_feats": fused_feats,
            "proxy_rgb_only": hat_aef_rgb_list,
            "proxy_rgb_nir": hat_aef_full_list,
        }


class TinyUPerNet(nn.Module):
    """标准轻量 FPN + PPM 解码头"""

    def __init__(self, in_channels_list: list[int], num_classes: int, fpn_dim: int = 128):
        super().__init__()
        self.lateral_convs = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(c, fpn_dim, kernel_size=1, bias=False),
                nn.BatchNorm2d(fpn_dim),
                nn.ReLU(inplace=True),
            )
            for c in in_channels_list
        ])
        self.fpn_convs = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(fpn_dim, fpn_dim, kernel_size=3, padding=1, bias=False),
                nn.BatchNorm2d(fpn_dim),
                nn.ReLU(inplace=True),
            )
            for _ in in_channels_list
        ])
        self.cls_head = nn.Sequential(
            nn.Conv2d(fpn_dim * len(in_channels_list), fpn_dim, kernel_size=3, padding=1, bias=False),
            nn.BatchNorm2d(fpn_dim),
            nn.ReLU(inplace=True),
            nn.Conv2d(fpn_dim, num_classes, kernel_size=1),
        )

    def forward(self, feats: list[torch.Tensor], out_hw: tuple[int, int]) -> torch.Tensor:
        laterals = [lat(f) for lat, f in zip(self.lateral_convs, feats)]
        for i in range(len(laterals) - 1, 0, -1):
            up = F.interpolate(laterals[i], size=laterals[i - 1].shape[-2:], mode="bilinear", align_corners=False)
            laterals[i - 1] = laterals[i - 1] + up
        fpn_outs = [conv(lat) for conv, lat in zip(self.fpn_convs, laterals)]
        base_hw = fpn_outs[0].shape[-2:]
        cat_feat = torch.cat(
            [
                fpn_outs[0],
                *[F.interpolate(p, size=base_hw, mode="bilinear", align_corners=False) for p in fpn_outs[1:]],
            ],
            dim=1,
        )
        logits = self.cls_head(cat_feat)
        return F.interpolate(logits, size=out_hw, mode="bilinear", align_corners=False)


class SixArmSegmentationModel(nn.Module):
    """
    统一多臂与省级插件分割架构：
      - 支持 B0 / R / D / A / P-Flex-Prov / Linear-Proxy
      - 支持锁定公共 backbone + 公共 head，仅训练与热插拔省级插件
      - 支持完整元数据校验与单文件合并导出/重载
    """

    def __init__(
        self,
        backbone: nn.Module,
        in_channels_list: list[int],
        num_classes: int,
        arm: str = "P-Flex-Prov",
        aef_dim: int = 64,
        fpn_dim: int = 128,
        freeze_backbone: bool = True,
        freeze_common_head: bool = False,
        num_prototypes: int = 512,
        shallow_levels: tuple[int, ...] = (0, 1),
        deep_levels: tuple[int, ...] = (2, 3),
        temperature: float = 0.07,
        nir_input_mode: str = "real_nir",
        backbone_in_channels: int = 3,
    ):
        super().__init__()
        self.backbone = backbone
        self.in_channels_list = list(in_channels_list)
        self.num_classes = num_classes
        self.arm = arm
        self.aef_dim = aef_dim
        self.fpn_dim = fpn_dim
        self.freeze_backbone = freeze_backbone
        self.freeze_common_head = freeze_common_head
        self.backbone_in_channels = backbone_in_channels
        self.plugin_enabled = True
        self.folded_linear_proxy = False

        if freeze_backbone:
            set_frozen_eval(self.backbone)

        self.head = TinyUPerNet(in_channels_list, num_classes=num_classes, fpn_dim=fpn_dim)
        if freeze_common_head:
            set_frozen_eval(self.head)

        if arm == "R":
            self.injectors = nn.ModuleList([
                AEFInjector(in_dim=aef_dim, out_c=c, mode="mlp") for c in in_channels_list
            ])
        elif arm == "D":
            self.student_q_proj = nn.ModuleList([
                nn.Conv2d(c, aef_dim, kernel_size=1, bias=True) for c in in_channels_list
            ])
        elif arm == "A":
            self.adapter_in = nn.ModuleList([
                nn.Conv2d(c, aef_dim, kernel_size=1, bias=False) for c in in_channels_list
            ])
            self.injectors = nn.ModuleList([
                AEFInjector(in_dim=aef_dim, out_c=c, mode="mlp") for c in in_channels_list
            ])
        elif arm == "Linear-Proxy":
            self.linear_proxy = LinearRGBProxyModule(in_channels_list, aef_dim=aef_dim)
        elif arm == "P-Flex-Prov":
            self.provincial_plugin = ScaleDecoupledProvincialFlexPlugin(
                in_channels_list=in_channels_list,
                aef_dim=aef_dim,
                num_prototypes=num_prototypes,
                shallow_levels=shallow_levels,
                deep_levels=deep_levels,
                temperature=temperature,
                nir_input_mode=nir_input_mode,
            )
        elif arm != "B0":
            raise ValueError(f"Unknown arm: {arm}")

    def train(self, mode: bool = True):
        super().train(mode)
        if self.freeze_backbone:
            self.backbone.eval()
        if self.freeze_common_head:
            self.head.eval()
        return self

    def lock_common_head(self) -> None:
        self.freeze_common_head = True
        set_frozen_eval(self.head)

    def get_base_model_hash(self) -> str:
        return compute_base_model_hash(self.backbone, self.head)

    def get_trainable_parameters(self, freeze_codebook: bool = True) -> list[nn.Parameter]:
        if self.arm == "P-Flex-Prov":
            if not self.freeze_common_head:
                raise RuntimeError("省级插件训练前必须先调用 lock_common_head() 冻结公共解码头！")
            params = []
            for name, p in self.provincial_plugin.named_parameters():
                if freeze_codebook and name == "province_codebook":
                    p.requires_grad_(False)
                    continue
                p.requires_grad_(True)
                params.append(p)
            return params
        return [p for p in self.parameters() if p.requires_grad]

    def disable_plugin(self) -> None:
        self.plugin_enabled = False

    def enable_plugin(self) -> None:
        self.plugin_enabled = True

    def save_province_plugin(self, path: str, dtype: torch.dtype = torch.float32) -> None:
        if self.arm != "P-Flex-Prov":
            raise RuntimeError("save_province_plugin 仅支持 P-Flex-Prov 路线")
        sd = {k: v.detach().cpu().to(dtype) for k, v in self.provincial_plugin.state_dict().items()}
        payload = {
            "format_version": "v3.4-prov-plugin",
            "base_model_hash": self.get_base_model_hash(),
            "plugin_config": self.provincial_plugin.get_config_dict(),
            "weight_dtype": str(dtype),
            "state_dict": sd,
        }
        torch.save(payload, path)

    def load_province_plugin(self, path: str, strict_base_hash: bool = True) -> None:

            raise RuntimeError("load_province_plugin 仅支持 P-Flex-Prov 路线")
        payload = torch.load(path, map_location="cpu", weights_only=True)
        if strict_base_hash:
            expected_hash = self.get_base_model_hash()
            file_hash = payload.get("base_model_hash")
            if file_hash != expected_hash:
                raise ValueError(f"Base model hash mismatch: plugin={file_hash}, current={expected_hash}")

        self.provincial_plugin.province_name = cfg["province_name"]
        self.provincial_plugin.codebook_metadata = cfg.get("codebook_metadata", {})
        self.plugin_enabled = True

    def fold_linear_proxy_into_head(self) -> None:
        """
        将纯线性 RGB 代理模块数学折叠进 TinyUPerNet 横向卷积：
          W_new = W_old @ (I + W_inj @ W_proj)
          b_new = b_old + W_old @ b_inj
        """
        if self.arm != "Linear-Proxy":
            raise RuntimeError("fold_linear_proxy_into_head 仅适用于 Linear-Proxy 路线")
        with torch.no_grad():
            for l, lat_block in enumerate(self.head.lateral_convs):
                conv: nn.Conv2d = lat_block[0]
                w_old = conv.weight.detach().clone().squeeze(-1).squeeze(-1)  # (fpn_dim, C)
                b_old = (
                    conv.bias.detach().clone()
                    if conv.bias is not None
                    else torch.zeros(w_old.shape[0], device=w_old.device, dtype=w_old.dtype)
                )
                w_proj = self.linear_proxy.rgb_to_proxy[l].weight.detach().squeeze(-1).squeeze(-1)  # (64, C)
                w_inj = self.linear_proxy.injectors[l].proj.weight.detach().squeeze(-1).squeeze(-1)  # (C, 64)
                b_inj = self.linear_proxy.injectors[l].proj.bias.detach()  # (C,)

                eye = torch.eye(w_old.shape[1], device=w_old.device, dtype=w_old.dtype)
                w_new = w_old @ (eye + w_inj @ w_proj)
                b_new = b_old + w_old @ b_inj

                conv.weight.copy_(w_new.unsqueeze(-1).unsqueeze(-1))
                if conv.bias is None:
                    conv.bias = nn.Parameter(b_new)
                else:
                    conv.bias.copy_(b_new)

        delattr(self, "linear_proxy")
        self.arm = "B0"
        self.folded_linear_proxy = True

    def export_merged_province_checkpoint(self, path: str) -> None:
        """
        单文件合并导出（支持 P-Flex-Prov 与已折叠或待折叠的 Linear-Proxy）。
        保存完整构造元配置以保证跨进程/新实例严格重载。
        """
        if self.arm not in ("P-Flex-Prov", "Linear-Proxy", "B0"):
            raise RuntimeError(f"export_merged_province_checkpoint 不支持 arm={self.arm}")
        meta: dict[str, Any] = {
            "format_version": "v3.4-merged-ckpt",
            "arm": self.arm,
            "in_channels_list": self.in_channels_list,
            "num_classes": self.num_classes,
            "aef_dim": self.aef_dim,
            "fpn_dim": self.fpn_dim,
            "backbone_in_channels": self.backbone_in_channels,
            "plugin_enabled": self.plugin_enabled,
            "folded_linear_proxy": self.folded_linear_proxy,
            "base_model_hash": self.get_base_model_hash(),
        }
        if self.arm == "P-Flex-Prov":
            meta["plugin_config"] = self.provincial_plugin.get_config_dict()
        torch.save({"meta": meta, "state_dict": self.state_dict()}, path)

    @classmethod
    def load_merged_province_checkpoint(
        cls,
        path: str,
        backbone_builder,
        map_location: str = "cpu",
    ) -> "SixArmSegmentationModel":
        payload = torch.load(path, map_location=map_location, weights_only=True)
        meta = payload["meta"]
        arm = meta["arm"]
        p_cfg = meta.get("plugin_config", {})
        backbone = backbone_builder()
        model = cls(
            backbone=backbone,
            in_channels_list=meta["in_channels_list"],
            num_classes=meta["num_classes"],
            arm=arm,
            aef_dim=meta["aef_dim"],
            fpn_dim=meta["fpn_dim"],
            freeze_backbone=True,

        )
        if meta.get("folded_linear_proxy", False):
            for lat_block in model.head.lateral_convs:
                conv: nn.Conv2d = lat_block[0]
                if conv.bias is None:
                    conv.bias = nn.Parameter(torch.zeros(conv.out_channels))
        model.load_state_dict(payload["state_dict"], strict=True)

    def export_student_d_inference(self, path: str) -> None:
        """D 路线独立纯推理导出（显式剥离训练辅助投影器 student_q_proj）"""
        if self.arm != "D":
            raise RuntimeError("export_student_d_inference 仅支持 arm='D'")
        sd = {k: v for k, v in self.state_dict().items() if not k.startswith("student_q_proj.")}
        meta = {
            "format_version": "v3.4-student-d-infer",
            "in_channels_list": self.in_channels_list,
            "num_classes": self.num_classes,
            "aef_dim": self.aef_dim,
            "fpn_dim": self.fpn_dim,
            "backbone_in_channels": self.backbone_in_channels,

    @classmethod
    def load_student_d_inference(
        cls,
        path: str,
        backbone_builder,
        map_location: str = "cpu",
    ) -> "SixArmSegmentationModel":
        payload = torch.load(path, map_location=map_location, weights_only=True)
        meta = payload["meta"]
        model = cls(
            backbone=backbone_builder(),
            in_channels_list=meta["in_channels_list"],
            num_classes=meta["num_classes"],
            arm="D",
            aef_dim=meta["aef_dim"],
            fpn_dim=meta["fpn_dim"],
            freeze_backbone=True,
            freeze_common_head=True,
            backbone_in_channels=meta.get("backbone_in_channels", 3),
        )
        missing, unexpected = model.load_state_dict(payload["state_dict"], strict=False)
        if unexpected or any(not k.startswith("student_q_proj.") for k in missing):
            raise RuntimeError(f"Invalid D checkpoint keys: missing={missing}, unexpected={unexpected}")
        delattr(model, "student_q_proj")
        model.eval()
        return model

    def forward(
        self,
        img: torch.Tensor,
        teacher_aef: Optional[torch.Tensor] = None,
        **forbidden_kwargs,
    ) -> dict[str, Any]:
        if forbidden_kwargs:
            raise ValueError(f"Unsupported forward kwargs (cache/coord forbidden): {list(forbidden_kwargs.keys())}")
        if img.ndim != 4 or img.shape[1] not in (3, 4):
            raise ValueError(f"Expected img shape (B, 3|4, H, W), got {tuple(img.shape)}")
        if self.arm != "R" and teacher_aef is not None:
            raise ValueError(f"arm={self.arm} forbids teacher_aef at forward/inference time!")

        out_hw = (img.shape[2], img.shape[3])
        rgb = img[:, : self.backbone_in_channels, :, :]
        if self.freeze_backbone:
            with torch.no_grad():
                feats = self.backbone(rgb)
        else:
            feats = self.backbone(rgb)

        aux: dict[str, Any] = {}
        if self.arm == "B0":
            fused_feats = feats
        elif self.arm == "R":
            if teacher_aef is None:
                raise ValueError("arm='R' requires teacher_aef")
            fused_feats = [f + inj(teacher_aef, f.shape[-2:]) for f, inj in zip(feats, self.injectors)]
        elif self.arm == "D":
            fused_feats = feats
            if hasattr(self, "student_q_proj"):
                aux["student_q"] = [proj(f) for f, proj in zip(feats, self.student_q_proj)]
        elif self.arm == "A":
            fused_feats = [f + inj(adp(f), f.shape[-2:]) for f, adp, inj in zip(feats, self.adapter_in, self.injectors)]
        elif self.arm == "Linear-Proxy":
            out = self.linear_proxy(feats)
            fused_feats = out["fused_feats"]
            aux["proxy_rgb_only"] = out["proxy_rgb_only"]
        elif self.arm == "P-Flex-Prov":
            if self.plugin_enabled:
                out = self.provincial_plugin(feats, img)
                fused_feats = out["fused_feats"]
                aux["proxy_rgb_only"] = out["proxy_rgb_only"]
                aux["proxy_rgb_nir"] = out["proxy_rgb_nir"]
            else:
                fused_feats = feats
        else:
            raise RuntimeError(f"Unhandled arm: {self.arm}")

        logits = self.head(fused_feats, out_hw)
        return {"logits": logits, **aux}

class DummyMultiScaleBackbone(nn.Module):
    """输出标准 [stride-4, stride-8, stride-16, stride-32] 金字塔的桩骨干"""

    def __init__(self, in_c: int = 3, dims: list[int] = [128, 256, 512, 1024]):
        super().__init__()
        self.stages = nn.ModuleList([
            nn.Sequential(
                nn.Conv2d(in_c if i == 0 else dims[i - 1], d, kernel_size=3, stride=4 if i == 0 else 2, padding=1),
                nn.ReLU(inplace=True),
            )
            for i, d in enumerate(dims)
        ])

    def forward(self, x: torch.Tensor) -> list[torch.Tensor]:
        outs = []
        curr = x
        for s in self.stages:
            curr = s(curr)
            outs.append(curr)
        return outs
