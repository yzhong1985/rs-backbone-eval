## 1. 一句话结论

**“把主干特征对齐到教师的 64/128 维空间，从而得到更好的表征”这条路线不成立。**

对齐本身很容易（验证集余弦 0.92～0.955），但**“像教师”不等于“好用”**：冻结读出的
学生普遍不如它自己的原始特征；解冻主干后涨的 0.1 分全部来自标签，教师项在 ±0.005～±0.015
之间摆动且方向依赖读出；跨任务迁移还掉了 0.11。

唯一有正面信号的是**对比学习（InfoNCE）**：它稳定优于余弦/MSE 蒸馏（+0.026～+0.037，
跨 4 个任务×主干对全部种子为正），但把读出预算、特征标定对齐之后，它**没有超过
“原始特征 + 逐通道标准化 + 小头”这个零成本基线**，也没有超过“用标签训编码器”；
长预算（80 epoch）下它追平同宽度的标签监督读出，这算它的边际价值，不是信息量优势。

## 2. 路线：原设计想做什么

原设计的想法是：AEF 的 64 维年度 embedding 冻结使用效果很好（T11 上 0.485），那就训练一个
“特征编码器”，把 Clay/Prithvi 的 1024 维 token 压成 64 维并尽量像 AEF，希望
（1）冻结档位下超过 AEF，（2）解冻微调后超过现有主干和 LIM。

实际比原设计多做了一步：**教师从 AEF 扩到 OlmoEarth v1.3**（后者在 PASTIS 上明显更强：
原生 64 / 128 维 = 0.579 / 0.614），主干从 Prithvi 扩到 Clay、AnySat，并补了
“只给 10% 标签”“跨数据集迁移”“读出预算”“特征标定”等对照。

| 做了什么 | 对应原设计 | 主干 |
|---|---|---|
| 冻结主干，蒸馏到 AEF64 / OE64 / OE128 | 第二、三阶段 | Clay、Prithvi、AnySat |
| 同维度**只用标签**训练的投影（S64/S128） | 第七阶段 | 同上 |
| PCA 64/128 维对照（无目标线性压缩） | 第一阶段 | 同上 |
| 逐通道 z-score 的原始特征读出（无目标、无标签） | 原设计未写（本轮补） | Clay、Prithvi |
| 解冻末 4/8 块，标签 ± 教师 | §5.1 联合微调 | Clay、Prithvi、AnySat |
| 只给 10% 标签，教师能否补上 | 原设计未写 | Clay、Prithvi、AnySat |
| 冻结特征 + 教师投影**拼接**进下游头 | 原设计未写（本轮对照） | Clay |
| 把蒸馏后的特征迁到 GF-2（T8） | 第三层迁移评价 | Clay |
| 读出预算 8 / 20 / 80 epoch 网格 | 原设计未写（本轮修正） | Clay |

## 3. 实验设置（读数字前必须知道的）

| 项 | 值 |
|---|---|
| 任务 | T11D：PASTIS-HD，B02/B03/B04/B08，2019-only，≤20 帧，128×128，20 类；T11P：同样 4 帧但六波段（B02/B03/B04/B08/B11/B12，6→4/10 适配） |
| 读出 | 时间均值 token（Clay 1024 维 stride-8，(1024,16,16)）→ 线性/瓶颈头 → token logits 双线性上采样到 128×128 |
| 训练 | AdamW，lr 3e-3，有效 batch 2；诊断组长训练用 `warmup1-cosine` |
| 种子 | 17 / 42 / 73；配对差按同种子相减后取均值 |
| 准入 | 只有 `completed` + 全量评测 + 未被 superseded 的 run 才进结论；诊断轨（B*D/B*N 等）不进 headline/D1/scorecard/Portal |
| 评测 | validation 482 / test 496（T11D）、496/496（T11P）；**探针不按 validation 选 epoch**，报告的是训练结束时的终态 |

**两个必须一起读的限制**：

1. T11D/T11P 的 test 与 train 存在组重叠（PASTIS-HD 官方 split 的已知问题，与 T1/T2/T5 同类），
   所以这些分数是**同分布留出**，不是跨区域/跨事件泛化。
2. AnySat 的预训练数据**包含 PASTIS-HD**，它的绝对分数不能当架构优势。

## 4. 结果

### 4.1 逐点蒸馏（余弦）：对齐做到了，下游没涨

| 64/128 维冻结读出（T11D，Clay，8 epoch 探针） | test mIoU |
|---|---:|
| AEF 原生 64 维（教师） | 0.485 |
| OlmoEarth 原生 64 / 128 维（教师） | 0.579 / 0.614 |
| Clay 原始 1024 维（不压缩） | 0.3185 |
| Clay → 蒸馏到 OE64 | 0.3010 |
| Clay → 蒸馏到 AEF64 | 0.2873 |
| Clay → PCA64（无目标压缩） | 0.2674 |

验证集余弦能到 **0.92～0.955**，但下游三个主干（Clay/Prithvi/AnySat）都低于各自原始特征。
“压缩 + 对齐”本身就在丢信息，而教师在冻结档位补不回来。

### 4.2 MSE 与 PCA 对照：都没有更好

- **MSE 蒸馏**：T11D 配对差 −0.008 / −0.025（OE64/AEF64）；T11P 128 维 Clay −0.006、
  Prithvi −0.071、AnySat −0.070 —— 均不如余弦，更远低于原始特征。
- **PCA128（T11P 三主干）**：Clay 低于 O128/S128（−0.015/−0.007），Prithvi 三者持平，
  **AnySat 上 PCA128（0.3159）反而最高**（比 O128 高 0.034、比原始 1536 维高 0.012）。
  这条异常是后面“原始探针没训够”的第一个线索。

### 4.3 把教师投影拼进下游头：没有收益

T11D，Clay，三臂：R = 只用 F（1024 维）；X = `[F, N(E_未训练(F))]`；T = `[F, N(E_教师训练(F))]`。

| 臂 | test mIoU（3 seed） |
|---|---:|
| R（只用原始特征） | **0.4696** |
| X（拼未训练投影） | 0.4481 |
| T（拼教师训练投影） | 0.4622 |

T − R = **−0.0074**（三 seed 全负）；T − X = +0.0140。结论：拼接本身没帮助，反而轻微稀释；
“比随机投影好”在 seed 73 上反转，不能稳定归因于教师。

### 4.4 解冻主干：涨分来自标签，不来自教师

T11D，Clay：

| 配置 | test mIoU |
|---|---:|
| 冻结，原始特征 | 0.319 |
| 解冻末 4 块，**仅标签** | 0.427 |
| 解冻末 4 块，标签 + 教师 | 0.435（验证集不支持） |
| 解冻末 4 块，**去掉 128 维投影、换宽头，仅标签** | **0.458** |
| 解冻末 8 块，仅标签 | 0.430 |

T11P 三主干的“加教师 − 不加”：

| 主干 | 128 维 E 读出 | 宽头同读出 |
|---|---:|---:|
| Clay | +0.015（3/3 正） | −0.003（1/3 正） |
| Prithvi | −0.002 | +0.004（test 3/3 正、val 持平） |
| AnySat | 无 128 维 B 层 | +0.003（2/3 正） |

**放开主干、用标签训练涨了约 0.1；在此基础上加教师，效果在 0 附近。** Clay 的 +0.015
只在 128 维 E 读出出现，换宽头就消失，是“投影器与教师损失耦合”的读出效应，不能算主干增益。

### 4.5 少标签（10%）：教师项在 ±0.01 内

T11P 宽头 B 层、146 个训练 patch（8 epoch）的配对差： Clay −0.0030、Prithvi +0.0089
（3/3 正）、AnySat +0.0080（3/3 正），**全部落在 ±0.01 内**。

T11D 128 维读出、8 epoch 时为 **−0.021（3/3 负）**，曾被读成“标签少时教师有害”。
**80 epoch（步数与全量 8 epoch 对齐）重跑后变为 +0.0021，且符号随种子翻转**，说明那是
短训练的产物，不是稳定负效应。

> 状态：P1 的 6 条 80 epoch 正在全量重跑（原批次继承了 `CLAY_WORKER_EVAL_LIMIT=2`，
> 只评了 2 个 patch，数字作废）。截至 2026-11-16 10:56，seed 17 的两臂已完成：
> **仅标签 0.2747 / 加教师 0.2915（配对差 +0.017）**，单条墙钟约 26 min；
> validation 都在 e30～e40 见顶（0.3033 / 0.3130）后回落，80 epoch 已过拟合。
> 另两个种子在 `T11DP1FULL` lane 里跑，完成后才能按预声明判据（±0.01 三档）落档。

### 4.6 对比学习（InfoNCE）：最好的蒸馏目标，但没有超出零成本基线

做法：对称 InfoNCE，τ=0.07，每步 8 个 patch、抽 1024 个有效 token 作负样本，按 val InfoNCE
选 epoch；蒸馏阶段完全不读标签。

**跨 4 个任务×主干对，NCE 都优于余弦蒸馏**：

| 任务 / 主干 | 余弦 | InfoNCE | 配对差 |
|---|---:|---:|---:|
| T11D（Clay，OE64） | 0.3010 | 0.3340 | +0.033（3/3 正） |
| T11D（Clay，AEF64） | 0.2873 | 0.3211 | +0.034（3/3 正） |
| T11P（Clay，OE128） | 0.2375 | 0.2635 | +0.026（3/3 正） |
| T11P（Prithvi） | 0.1973 | 0.2318 | +0.035（3/3 正） |
| T11P（AnySat） | 0.2819 | 0.3188 | +0.037（3/3 正） |

**但把读出预算与标定对齐后，它并不领先**。T11D（Clay）的 3×3 网格（全量评测）：

| 读出 | 8 epoch | 20 epoch | 80 epoch |
|---|---:|---:|---:|
| 未标定原始 1024 | 0.3185 | 0.3608 | 未跑 |
| **原始 + 逐通道 z-score** | **0.3511** | **0.3644** | 0.3358 |
| OE64 InfoNCE | 0.3340 | 0.3482 | **0.3539** |
| S64 标签监督 | 0.3174 | **0.3687** | 0.3530 |

同预算配对差：

| 预算 | NCE − z-score | S64 − z-score |
|---|---:|---:|
| 8 epoch | −0.0171（3/3 负） | −0.0337（3/3 负） |
| 20 epoch | −0.0162（3/3 负） | +0.0043（3/3 正） |
| 80 epoch | +0.0181（3/3 正） | +0.0172（3/3 正） |

六波段（T11P，20 epoch 探针）：

| 主干 | z-score | NCE | S128 |
|---|---:|---:|---:|
| Clay | 0.2815 | 0.2765 | **0.2868** |
| Prithvi | **0.2379** | 0.2318 | 0.1951 |
| AnySat | 无同类对照 | **0.3188** | 0.2877（PCA128 0.3159） |

解读：

- 8 / 20 epoch 两个预算上，NCE 都低于**标准化后的原始读出**（−0.017 / −0.016，3/3 负），
  20 epoch 也低于**未标定**原始读出（0.3482 vs 0.3608）。
- 80 epoch 上 NCE 反超 z-score（+0.018），但那时 z-score 与 S64 都已过拟合
  （20→80 分别 −0.029 / −0.016），而且 NCE 的 0.3539 仍低于它们在 20 epoch 的峰值。
- 80 epoch 下 NCE 与同宽度标签监督 S64 持平（0.3539 vs 0.3530）：无标签对比读出在长预算、
  64 维瓶颈下追平标签监督，这是它的边际价值。
- 去教师对照（正样本 = 学生自身特征的固定随机投影）= **0.2259**（8 epoch 全量），
  且检索 top-1 0.996～1.000：没有外部结构时对比目标只会学出那个随机投影。所以
  “教师结构确实在起作用”，只是这份结构没有超过“标定 + 小头”。

### 4.7 跨任务迁移（T8，GF-2，25 类，seed 17、缩减预算）

| 迁移过去的特征 | test mIoU |
|---|---:|
| Clay 原始特征 | **0.367** |
| 蒸馏到 OlmoEarth 128 维 | 0.258 |
| 蒸馏到 AEF 64 维 | 0.256 |

**对齐到教师空间后换个任务掉 0.11**：压缩只保留了“教师关心的信息”，把主干更通用的
信息丢了。这与原设计“提升跨任务泛化”的预期相反。

## 5. 当前结论：哪些成立，哪些收回

| 结论 | 状态 | 证据 |
|---|---|---|
| 冻结档位下“像教师”可以做到（余弦 0.92～0.955） | ✅ 成立 | T11D/T11P 蒸馏诊断 |
| 冻结档位下学生对下游不如自己的原始特征 | ✅ 成立 | 三个主干、多个预算一致 |
| MSE 不优于余弦蒸馏 | ✅ 成立 | T11D −0.008/−0.025；T11P −0.006/−0.071/−0.070 |
| 教师投影没有超出“无目标线性压缩”的优势 | ✅ 成立 | PCA128 在 AnySat 最高，其余持平 |
| 拼接教师投影进下游头有帮助 | ❌ 收回 | T−R −0.0074（3/3 负） |
| 解冻主干涨分归功于教师 | ❌ 收回 | 涨 0.1 来自标签；教师项 ±0.005～0.015 且随读出翻转 |
| 标签少时教师有害 | ❌ 收回 | 8 epoch −0.021 → 80 epoch +0.002（符号随种子翻转） |
| “像教师”能提升跨任务泛化 | ❌ 收回 | T8 迁移 −0.11 |
| 对比学习明显优于余弦/MSE 蒸馏 | ✅ 成立 | 4 个任务×主干对，全部种子为正 |
| 对比学习让冻结特征超过原始特征 | ❌ 收回 | 同预算下低于 z-score 原始读出（−0.016），AnySat 与 PCA128 持平 |
| 对比学习超过标签监督 | ❌ 收回 | 8/20 epoch 均低于 S64/S128；仅 80 epoch 追平 |
| 冻结读出 8 epoch 就饱和 | ❌ 收回 | 原始 8→20 +0.042、S64 +0.051；只有部分主干（Prithvi/AnySat 六波段）确实早饱和 |
| 特征标定是主要混淆项 | ⚠️ 修正 | 标定主要省短预算训练时间：8 epoch +0.033，20 epoch 仅 +0.004 |

**净结论**：这条路线的最好结果（0.458 / T11P 0.357）都是**完全不用教师**得到的；
教师项在所有对照里都没有稳定的正贡献。**路线关闭**，剩下的问题转移为
“特征标定 / 读出头训练 / 更强的监督基线”。

## 6. 方法论教训（比结论更值钱）

1. **评测预算会把结论翻转。** 8 epoch 探针把 S64 低估了 0.057、原始特征低估了 0.042；
   “NCE 超过原始特征/S64”完全是这两个欠训练基线造成的。任何“A 超过 B”的结论必须报
   预算网格，至少 2 个点，并说明是否同预算。
2. **特征标定是必须单独的对照。** 逐通道 z-score（恒等变换 + 仿射，不增加信息）能让原始
   读出从 0.3185 涨到 0.3511（8 epoch）、0.3608→0.3644（20 epoch）。不做这个对照，
   会把“可优化性”误读成“信息量”。
3. **smoke 泄漏比想象中容易。** 2026-11-13 的两个 lane 从启动 shell 继承了
   `CLAY_WORKER_EVAL_LIMIT=2`，只用 2 个 patch 评测却照样写 `completed`，一批已发布数字
   因此作废。现在 `scripts/rerun_baselines.sh` 会在 fork 前拒绝这种环境，账本里也能用
   `tags.smoke` / `validation_samples_evaluated` 查出来。
4. **种子必须三个一起看。** P1 的单种子配对差是 +0.011 / −0.015 / +0.010，只看一个种子
   会得出相反结论。
5. **“超过原始特征”不是硬判据**，因为原始读出本身可能没训好；更硬的是
   “同预算 + 标定后 + 标签监督”三条基线一起比。

## 7. 值得继续探索的方向（按性价比排序）

### 7.1 把读出训练到饱和，给“可优化性 vs 信息量”定论（最高优先）

现在唯一没堵上的漏洞：z-score/NCE/S64 在不同预算下互有胜负，80 epoch 时 z-score 与 S64
都过拟合，无法判断“NCE 的信息是否只是更好优化”。

- 做法：三条读出（z-score 原始、NCE、S64）用同一套强读出（例如 2 层 MLP + dropout，
  或线性头 + 200 epoch + 早停按 validation），比较各自 plateau。
- 判据（先写死）：若 NCE 的 plateau 仍低于 z-score 达 0.01 且 3/3 一致 → “无信息增益”定论；
  若追平或反超 → 对比蒸馏的价值需要重估。
- 成本：单主干 Clay T11D，3 读出 × 3 种子，约 2～3 h。

### 7.2 把“标定 + 线性/MLP 读出”变成标准基线

所有后续工作（包括 T1–T5、T8）都应报告 `z-score/whitening + 线性头` 的分数。
本轮的成本教训是：一个不做任何蒸馏的基线就能吃掉大部分“方法增益”。

### 7.3 无标签教师 + 解冻主干（原设计里唯一没被排除的形态）

把年度 embedding 当“大范围、不要标签的监督信号”，在大量无标签 patch 上继续训练主干，
再在多个下游任务上微调。现有信号（冻结持平、微调教师项≈0、迁移变差）都偏负面，先验不看好。

- 最小验证：1 个主干（Clay）、2,000～5,000 个无标签 patch、2～3 个下游任务（T1/T2/T8）。
- 判据：多数任务不掉分、部分任务涨分；只在一个任务上涨不算。
- 成本：约 6～10 h（需要新增无标签采样与教师 token 管线）。

### 7.4 在“教师给不了的地方”验证价值

AEF/OlmoEarth 已覆盖全球、每年发布。近似它们只在**它们给不了的地方**有用：
1～4 m 的 GF 影像（T8）、尚未发布的年份、单期影像即时推理、SAR（T1S）。

- 先做最便宜的：T8 用全预算、三个种子重跑“原始 vs OE128 蒸馏”，确认掉 0.11 不是预算伪影。
- 判据：目标域不掉分 + 至少一个域外任务涨分。

### 7.5 补强监督基线

T11D 上“解冻 + 宽头 + 仅标签”已经 0.458。需要确认这是该数据的上限还是仍有空间
（例如 LIM/B0 参考、更强增广、更长训练）。如果方法的天花板本来就等于普通微调，
“教师引导”的讨论就没有意义。

### 7.6 评测协议本身值得修

T11D 的 validation 在 e30 之后下降而 test 上升，说明 split 的组重叠在影响选模与解读。
建议：用 `holdout-manifest` 做一次组级 holdout（Bolivia 式的独立证据），至少对
Clay T11D + 一条基线跑通，再把结论从“同分布留出”升级为“跨组”。

### 7.7 若继续做对比学习，换个定位

不要再把它当“蒸馏教师的手段”，而是当**无标签自监督正则**：与时间一致性、数据增强、
MAE 之类同台比较，判据是“在标签稀缺时是否比无正则更强”。这需要新的基线组，
工作量大于上面几项。
