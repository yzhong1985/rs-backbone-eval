# 高分遥感多场景变化检测与内网交付验证方案

修订版 v2 · 2026-11-18  
关联研发路线：冻结公共 LIM 底座、可选省级 AEF 特征插件。本文修订业务目标和实验设计；模型效果与研发周期均待实测。

## 1. 立项目标与交付边界

客户把两期影像放进内网，希望系统圈出值得看的变化，能按业务要求筛选，并把结果交给现有 GIS 作业流程。研发团队拿不到客户影像和标签，现场主要负责数据接入。因此，首版要交付的是**已经训练好的变化检测模型、任务头和默认阈值**。验收问题是：换一个没有参与开发的地区，产品能找回多少真实变化，又会产生多少需要人工排查的图斑？

首版优先支持两期高分 RGB。保留 RGB＋NIR 扩展，取得真实四波段配对影像和相应标注后单独验证。开发和模拟交付均从公开数据开始。客户不回传数据；模型推理可以在断网环境中完成。

| 交付能力 | 输入 | 用户拿到什么 | 首版验证边界 |
|---|---|---|---|
| 通用变化筛查 | 同一区域已配准的前后两期影像 | 变化概率栅格、候选变化图斑、面积及置信分数，可定位到两期影像复核 | 按训练及评测数据覆盖的地物变化定义统计成绩 |
| 按业务筛选 | 两期影像、支持的类别和筛选规则 | 例如只显示“低矮植被→建筑”，或按变化面积筛选 | 语义头只输出经过标注和验证的类别；每个方向报告样本数 |
| 历史底图辅助更新 | 旧矢量及新影像；旧影像可用时一起输入 | 待新增、待复核或建议修改的要素，以及与原要素的关联 | 第二阶段先做建筑新增；保留原图，复核通过后再更新 |

同一处水域扩大，在岸线监测任务中是有效变化，在新增建设巡查中可能无需上报。通用层判断是否发生了标注体系关注的变化，业务层决定向谁上报。收割、阴影、错位和水位变化都可以作为错误分析的案例；其性质由当次任务的定义决定。

## 2. 公开数据如何支撑结论

第一轮先做 JL1-CD 和 SECOND，各自训练对应任务头。另预留一组与交付任务定义一致、地理独立的公开区域做最终盲测。两套任务标签不同，分开打分。

| 优先级与数据集 | 任务与选择理由 | 必交结果 | 解释成绩时的限制 |
|---|---|---|---|
| P0 · JL1-CD | 国产吉林一号通用二值变化检测。中国多地、5,000 对、0.5–0.75 米，4,000 对训练、1,000 对测试。含人工地物及自然地表变化 | 官方测试集变化类 F1/IoU、按变化图斑面积分组的召回率 | 二值掩膜无法单独给出逐类精度。从官方训练部分划开发验证集。若无法恢复原始场景归属，官方分数只支持同基准测试结论。[作者数据卡](https://huggingface.co/datasets/circleLZY/JL1-CD) |
| P0 · SECOND | 中国多城市语义变化，涉及非植被地表、树木、低矮植被、水体、建筑、运动场六类 | 官方 SeK、可复现设置下的 F_scd、主要类别转换的 F1 与混淆矩阵 | 未变化区和有效类别按官方编码处理。低矮植被不能直接解释成耕地。总规模 4,662 对；按实际可获标签确定可本地评价的范围。[作者项目页](https://captain-whu.github.io/SCD/) |
| P1 · SpaceNet 7 | 月度影像与真实建筑轮廓。构造“旧底图＋新影像”新增建筑任务，留整片地区做外测 | 新增建筑对象召回、误报/km²、旧要素误改率；比较有无旧底图 | 平均约 4 米，评价对象限定为可辨识建筑。每个地区的各月份必须进入同一划分。[官方数据说明](https://spacenet.ai/sn7-challenge/) |
| 专项 · CLCD | 广东 GF-2 耕地变化，2017/2019 双时相、0.5–2 米，共 600 对，官方划分 360/120/120 | 耕地变化 F1、图斑漏报及误报分析 | 标签是耕地变化二值掩膜。若要测物候或阴影误报，另设有原因标注的审查样本，单列结果。[作者仓库](https://github.com/liumency/CropLand-CD) |

**与已有实验的关系。** WHU-OPT-SAR、PASTIS-HD 继续回答单期地表分类或作物识别问题；变化检测单独出表。Hi-UCD 可用于精细边界压力测试，其正式版为爱沙尼亚塔林 0.1 米航片。GID/LoveDA 上人为改动地类，可演示图库属性错误检出；真实增量更新用有两期证据的 SpaceNet 7 检验。[Hi-UCD 作者说明](https://github.com/Daisy-7/Hi-UCD-S)

## 3. 模型与对照实验

在原 v3.4 单期编码器接口上增加变化检测分支。对 T1 和 T2 用相同权重提取多尺度特征；各尺度融合有序的 T1、T2 特征及其绝对差，再用变化头预测变化区域。有序特征让“新增”和“拆除”可区分。SECOND 增加前后类别输出，根据官方有效标签计算损失。输出概率图后，按同一套连通、面积过滤和跨切片合并规则生成候选图斑。

训练时在有位置、年份和可靠配准的公开影像上，用 AEF 特征指导插件。推理时，插件根据所见影像及已经学到的省级原型产生特征。**它能否从两期影像学到有助于判断变化的信息，是实验要验证的假设。** 年度 AEF 汇总 10 米网格的全年观测；对亚米级新增物、同年短时事件，单列漏报，防止深层特征把小变化一并平滑掉。[Google AEF 数据说明](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL)

| 实验组 | 训练设置 | 用途 |
|---|---|---|
| A · 现有最强 LIM | 双时相 LIM 全量微调＋变化头 | 比较客户实际能拿到的最佳既有模型 |
| B · 冻结 LIM | 编码器冻结，仅训练相同的融合层和变化头 | 衡量只训练任务头的起点 |
| C · 同容量插件 | 与 D 相同的架构、输入、训练影像、下游标签和预算，关闭 AEF 教师监督；明确记录替代训练目标 | B→C 观察额外模块的收益；C→D 估计加入教师监督的增益。若预训练数据或预算不同，报告差异 |
| D · AEF 教师训练的插件 | 冻结公共 LIM，训练插件；导出后按预设冻结策略训练变化头 | 与 A 比产品效果，与 C 比教师贡献；同时报告训练成本、显存和离线推理速度 |

省份已知时可以人工选已发布的插件；无法判断地域或没有对应插件时使用通用模型。实际像素定位由输入影像的空间参考提供；无坐标切片能测模型推理，但导出有地理位置的矢量仍需地理参考。模型使用的 RGB、波段次序、数值缩放、设备和执行时间必须随结果一同记录。

**实现检查。** 原方案的共享编码器及多尺度融合思路可复用。先核对真实特征通道、步长和输出尺寸；显式设置冻结模块的梯度和训练模式，并检查一次反传后的梯度。单独调用 `eval()` 只会切换运行模式。首版不依赖浅层边界一定保持不变的假设，边界效果实测。

## 4. 两套评测分别模拟开发和交付

**基准评测。** 使用公开训练集训练、开发验证集选模型和工作阈值，最后在公开测试划分上评分。记录数据版号、划分、输入波段、训练方式、随机种子、阈值与指标实现；相同任务内保持后处理一致。

**模拟客户现场的盲测。** 在训练任何阶段前，按原始地区或整景划出最终测试区，同地不同月份、同景切片和重叠区域一起留出。插件蒸馏数据也做空间交叉检查。测试区样本不参与省级原型构建、模型选择、阈值调整或形态学参数选择。开发端锁定交付包后，对整区一次推理。

| 盲测条件 | 能支持的结论 |
|---|---|
| 已有省级插件，测试该省未参与训练的独立地区 | 已适配省内的新项目能直接用到什么程度 |
| 目标省及其影像未参与底座适配或插件训练，按预设规则用通用模型 | 首次进入新省、无需现场样本时的表现 |
| 无法核对训练与测试地理重叠 | 记录为官方划分或跨数据集测试，地理泛化结论待补 |

使用跨数据集外测时，先统一“什么算变化”。例如把只标建筑的数据用于评测通用变化模型时，只有输出也限定为建筑变化，才可据此解释误报。若缺少可核验的通用变化外测区，先在可留整区的建筑任务上报告盲测，通用变化只报告官方基准成绩。

## 5. 验收指标和读数规则

| 要回答的问题 | 评价方法 |
|---|---|
| 漏了多少该查的事？ | **图斑召回率**＝找回的真变化图斑数／真变化图斑总数。预先约定图斑的一对一空间匹配规则；报告匹配 IoU 阈值、小中大图斑分组及各组样本数。二值掩膜的连通区域用作图斑代理时明确注明 |
| 多给作业员派了多少活？ | **误报图斑数/km²**＝未匹配预测图斑数／实际有效评测面积。整区包含无变化背景；无法恢复可靠面积时，改报每 100 幅切片误报数，并注明抽样条件 |
| 同样的核查预算下，谁找到的真变化更多？ | 报 Precision–Recall 曲线与固定工作点。阈值在验证集选定，例如目标对象召回 80%；在新地区同时报告实际召回和误报密度。另报 FDR＝FP／(TP＋FP)。人工节时须通过相同审查任务计时获得 |
| 变化位置和类型报得准吗？ | 二值任务报变化类 F1/IoU；语义任务报 SeK 与逐转换 F1；对新建、拆除及关键变化方向分别统计。缺对应标签的指标留空 |
| 能否形成可复核的矢量？ | 记录碎斑数量、边界 F1 和同一对象被拆分的情况。边界 F1 双向计算预测与真值边界匹配；容差及最小制图面积按米、平方米记录，同时保留像素换算 |
| 到了新地区是否稳定？ | 同报合并结果、各地区等权平均以及最差地区，标注真变化数量。按地区或独立场景做配对比较；样本过少时列原始计数，不承诺固定百分比收益 |

同时展示 D 相对 A、C 的真实漏报和误报案例，抽取季节、阴影、几何错位、水陆界面及小目标等条件。挑出的示例用于解释；分层统计需预先确定样本与标注规则。

## 6. 执行次序与决策

1. **核对可用数据。** 建立清单，记录来源、影像使用条件、标签定义、可用波段、拍摄日期、空间信息、训练和测试区域。研究评测与商用权重训练分别核对授权。JL1-CD 作者数据卡标明 MIT；其余数据逐项记录。导出第一份区域划分和盲测区清单。
2. **先跑通可交付的基线。** 在 JL1-CD 上完成 A、B，输出官方指标和一批可叠加检查的候选图斑。用双期恒等输入、时期交换、拼接边界与无效像元检查数据管线。该步骤可与省级插件训练并行。
3. **检验插件和语义能力。** 在相同的 JL1-CD 测试条件下补完 C、D。在 SECOND 上复用双期编码器，单独训练语义任务头。输出能力对照表、转换混淆表和固定工作点下的误报与漏报。CLCD 仅在需要评估耕地任务时加入。
4. **验证开箱交付。** 打包权重、波段映射、预处理、任务头、阈值和后处理配置，在隔离地区离线推理。若 D 能在多个地区降低核查量且不引入不可接受的漏报，纳入默认候选；若收益集中在某一类区域，把它作为该场景选件；若 A 综合更优，优先交付 A。
5. **验证历史底图更新。** 在 SpaceNet 7 给定旧建筑轮廓，比较“仅影像”“相同影像＋旧轮廓”以及“沿用旧底图”的结果。独立搜索旧轮廓外的新增建筑。输出新增候选、旧要素误改率和复核样例；对应日期的新轮廓只用于评分。

**交付评审材料。** 一套断网可运行的推理包，一份官方基准成绩表，一份锁定模型的整区盲测表，一组同时展示两期影像、真值、预测和错误原因的 GIS 样例。评审时依据实际测量填写“覆盖哪些变化、陌生地区漏多少、每平方公里多查几个图斑、哪些场景值得开启插件”。这些结果支持产品选型，现场节省的工时另行验证。
