# T13 基于全量微调 LIM 的 NIR 与 SAR 插件融合实验方案

**2026-11-24 · 评审通过，已补充执行细节**

## 1. 决策与目标

保留纯 RGB 全量微调 LIM（FT-B0）作为交付基线，分别验证原生 NIR 和配对 SAR 能否在此基础上提升地物分割。先做可独立启停的轻量分支。两种模态各自通过验证后，再测试同时输入时收益能否叠加。

上次只读核对 89 的账本时，seed 17 的冻结 RGB 为 52.65%，冻结 RGB+AEF 为 54.54%，全量微调 RGB 为 56.98%，全量微调 RGB+AEF 为 57.11%。纯 RGB 全量微调比冻结 RGB+AEF 高 2.44 个百分点，AEF 在该全量微调对照上的边际提升为 0.14 个百分点（账本原值 0.5711498 − 0.5697940 = 0.136），目前是一对种子的观察。G2 三种子中，随机字典 Bcap 为 53.02%，AEF 字典加对齐的 P 为 53.01%。本轮直接测同一批影像的新输入给强基线带来的收益，训练损失用分割 CE。 [T13 全量微调方案](实验执行方案_v3.4_补充_FT_2026-11-19.md)

需要回答三个问题。

1. NIR 带来多少收益，轻量插件是否优于把首层扩到四通道？
2. 配对 SAR 带来多少收益，提升是否依赖同位置的 SAR 信息？
3. 两个插件能否组合使用，收益能否覆盖新增推理开销？

## 2. 数据与接入验收

WHU-OPT-SAR 包含湖北的 100 幅 GF-1 光学影像、对应的 GF-3 SAR 影像和像素标签。89 上的 `optical/`、`sar/`、`lbl/` 各有 100 个同名 TIFF。此前抽查的 3 幅在每个三元组内尺寸一致，光学为四波段 uint8，SAR 为单波段 uint8，样本文件无 CRS、仿射或 nodata 元数据。SAR 的极化和数值编码以发布资料或文件核验为准。 [数据集官方说明](https://github.com/AmberHen/WHU-OPT-SAR-dataset) [仓库接入说明](../evaluation/WHU_OPT_SAR_接入说明_2026-11-16.md)

- **固定样本。** 复用 FT-B0 的 T13 manifest、图幅分组和 72/8/20 划分。窗口 512×512、步长 384、末块贴边。训练时 RGB、NIR、SAR 和标签同步翻转，评估沿用逐图幅拼接、忽略标签 0、7 类 mIoU 的口径。SAR 接入不得改变对照的测试图幅或像素集合。 [T13 manifest 构造](../../src/rs_backbone_eval/data/datasets/whu_opt_sar.py)
- **校验逐幅配对。** 构建单独的 SAR 图幅索引，以 `group_id` 关联同名 SAR。记录相对路径、尺寸、波段数、文件 SHA-256、有效像素规则和配准版本，给索引自身计算哈希。对 100 幅检查重名、缺失、尺寸、波段及窗口越界。NIR 从光学 TIFF 第 4 波段读取。
- **验收配准。** 在训练和验证图幅抽查水岸、道路交会、明显地块边界，覆盖平原、丘陵和城镇。用叠图检查中心及边缘偏移，区分统一平移、局部形变和可能的时相差。若偏移相对拟融合尺度不可忽略，先纠正或停在较粗尺度。任何配准处理都记录版本，并对所有实验臂使用同一规则。测试标签不参与核验和调参。
- **处理数值和缺测。** RGB 保持 FT-B0 归一化。NIR 和 SAR 各用训练划分拟合独立的裁剪和归一化统计，固定应用到验证与测试。SAR 是发布版 uint8，先按编码值处理，确认物理量含义后才考虑对数变换。真实低回波和缺测分开处理。若没有可靠像素级掩码，只把可证实的无覆盖区域或模态缺失标记为无效。

## 3. 模型设计

主路继续使用 `RGB → LIM MiT-Huge → 四级特征 → UPerNet`，从同种子的 `whu_ft_b0/best_full_checkpoint.pt` 加载骨干及头。分支在送入 UPerNet 前修正对应层的 LIM 特征。两个分支各有独立参数、开关和有效性掩码。

| 分支 | 首版实现 | 这么做的原因 |
|---|---|---|
| NIR | 单波段小 CNN，取 stride 8、16 的特征。经 1×1 投影对齐到对应 LIM 层的通道数，做残差相加。 | NIR 与 RGB 来自同一光学栅格，可以利用较细的光谱和边界信息。 |
| SAR | 单波段小 CNN，取 stride 16、32 的特征。用 RGB 和 SAR 的上下文生成轻量门控，调节 SAR 残差幅度。 | 先在较粗尺度吸收纹理和结构，降低小幅配准误差及斑点对细边界的影响。 |

每个尺度的形式为 `融合特征 = RGB 特征 + NIR 残差 + SAR 残差`，只计算已启用分支。分支末端投影初始输出为零，避免接入时改变基线预测。模态缺失时显式跳过对应分支，有效性掩码要在残差输出处生效，避免卷积偏置或归一化把无效区域重新变成非零。首轮冻结 LIM 和 UPerNet，保持两者的 eval 状态，只训练新分支。验收时比较全部插件关闭与 FT-B0 在相同输入、相同精度下的 logits。

**掩码与池化。** NIR 或 SAR 的缺测掩码只作用于该分支。比如某个区域缺 SAR，融合特征在该区域仍包含有效 RGB，UPerNet 的 PPM 保持使用完整融合特征和原有分母。若插件的门控需要池化 SAR 上下文，则只在 SAR 分支内按有效像素归一化。池化分子为 `sum(mask × feature)`，分母为 `sum(mask)`，全无效的区域输出零。缺测覆盖率单独记录。首轮测试覆盖模态全缺、片内部分缺失和全部有效三种情况。 [UPerNet 池化实现](../../src/rs_backbone_eval/heads.py#L87)

借鉴 MaRS 的模态专属特征提取和后续融合。MaRS 用两套 SwinV2，交替进行模态内与跨模态注意力，预训练使用约 0.35 m 的 X 波段 SAR。WHU 是约 5 m 的 GF-3 产品，首轮用小 CNN 验证本域 SAR 的信息量。只有 SAR 残差分支通过验证后，才比较在 stride 16 或 32 上增加一次局部交叉注意力的收益和延迟。 [MaRS 官方方法与数据](https://rsidea.whu.edu.cn/mars.htm)

## 4. 实验顺序与控制变量

| 阶段 | 实验臂 | 该阶段要做的决定 |
|---|---|---|
| 数据与 smoke | RGB 回归、NIR 单分支、SAR 单分支 | 检查输入对齐、无模态回退、插件参数更新和显存。 |
| 验证集筛选 | RGB 基线、RGB+NIR 插件、RGB+SAR 插件、RGB+NIR 四通道首层 | 用 seed 17 比较验证集及资源开销。锁定进入复核的结构和配置。 |
| 三种子配对 | RGB 基线与通过筛选的各单分支；保留四通道首层作为 NIR 对照 | 在 17/42/73 上判断边际收益。SAR 若有收益，加同结构的图幅错配控制。 |
| 联合输入 | RGB、RGB+NIR、RGB+SAR、RGB+NIR+SAR | 两个单分支通过后测联合增益。先加载独立训练的插件测直接组合，再视验证结果决定是否联合训练两个插件。 |

**训练配方。** 单分支首轮建议 20 epoch、CE、AdamW、插件学习率 1e-3、weight decay 1e-4、首 epoch warmup 后 cosine。沿用 T13 有效 batch 8，先用 micro 2 × 累积 4 做 smoke，每 5 epoch 验证，按验证 mIoU 保存最佳插件。四通道对照同样从 FT-B0 起步，用独立的单通道卷积实现新增首层权重，与原 RGB 首层输出相加。这样原 RGB 权重及偏置可以保持冻结，也避开 AdamW 对同一个权重张量施加权重衰减。首轮固定同一训练预算和配方。若后续解冻骨干或头，须加同起点、同额外预算的 RGB 继续微调对照。

**初始化与梯度。** 四通道对照的 NIR 卷积权重用零初始化，偏置关闭，初始化时同输入的 logits 应与 FT-B0 一致。残差插件通过末端投影清零，门控初始值须能让投影获得梯度。冻结参数时保留损失到新增参数的计算图。深层插件的 RGB 特征可在 `no_grad` 下提取，但后续 UPerNet 前向要保留梯度。四通道对照的 NIR 进入 LIM 首层，后续 LIM 和 UPerNet 的前向均需保留对输入的梯度，单独记录它的显存开销。Smoke 检查零初始化投影或卷积的梯度有限且非零，完成首次非零学习率更新后核对权重有变化，并复核原 RGB 权重未更新。

**SAR 归因。** 若 RGB+SAR 跨过验证门槛，预先固定各 split 内的异图幅错配映射。读取错配图幅的相同窗口位置，尺寸略有差异时把窗口移到最近的合法位置，保留所有目标样本和标签。保持输入形状、模型参数和训练预算一致，记录真实配对与错配的同种子差。仅推理时换成错配 SAR 可以另作依赖性诊断，主要归因看训练和评估均使用预定错配的对照。

若配对臂优于错配臂，结论写为收益依赖同位置的 SAR 信息。边界、纹理和地物组成可同时贡献这份收益，具体机制结合逐类指标和可视化分析。

**组合读法。** 联合输入分别减去两个单分支的分数。另报告交互项 `联合 − NIR − SAR + RGB`。联合模式若没有明显超过更好的单分支，优先保留收益相当且成本更低的输入组合。

## 5. 评估口径与建议门槛

主指标是逐图幅拼接后的测试集 7 类 mIoU。报告每个种子、同种子配对差和三种子均值，同时给出逐类 IoU 和逐图幅差值。可以补一组按图幅重采样的区间作为稳定性描述。湖北的相邻图幅可能共享边界，结果适用于当前图幅划分。跨区域效果需要地理独立的数据另证。

**边界退化监测。** 在同一份拼接后的预测上按类计算 Boundary IoU。首轮固定边界带宽为原图 2 像素。对每类的预测与标注分别提取像素内侧边界带。统计时使用同一有效区域，排除距离未标注像素（标签 0）或图幅外边界不足一个边界带宽的位置，再累计边界交并集。并集为空的类别记为缺项。报告七类的宏平均和逐类差，重点看道路的 Boundary IoU 和普通 IoU。先在验证集对照 RGB 基线复核退化，并保留代表性图幅叠图。Boundary IoU 用于诊断和决定是否继续推进，选检查点仍按验证 mIoU。 [Boundary IoU 原论文](https://openaccess.thecvf.com/content/CVPR2021/html/Cheng_Boundary_IoU_Improving_Object-Centric_Image_Segmentation_Evaluation_CVPR_2021_paper.html)

| 阶段 | 首轮门槛 |
|---|---|
| 单种子筛选 | 相比同 seed RGB 基线，验证 mIoU 至少提高 0.5 个百分点，才扩到三种子。 |
| 三种子复核 | 平均配对提升至少 0.5 个百分点，至少 2/3 种子为正。报告最差种子和逐类变化，配对 SAR 应表现出比错配控制更一致的收益。 |
| 交付评估 | 单分支新增参数先以 100 万以内为设计目标。在同一张 4090 上记录相同精度、batch=1、512×512 的中位和 P95 推理延迟及峰值显存。首轮建议单插件中位延迟额外开销不超过 15%，联合不超过 25%。单独记录 TIFF 读取、预处理和模型前向，避免漏算 SAR IO。 |

门槛按评审意见锁定。首轮根据验证集选择结构、权重和开关策略，测试集只对锁定的候选评一次。既有 RGB 测试分数用于复核基线。缺 NIR、缺 SAR、两者都缺三种模式分别统计，SAR 研究结果不自动外推到只有光学影像的交付现场。

## 6. 工程落地与交付边界

1. **数据层。** T13 保留原光学 manifest 和既有 run 标识。新协议读取带哈希的 SAR 索引，按同一窗口读取模态，数据集输出显式可用标记。SAR 分支实验启动时校验索引完整性，遇到错配和越界直接失败。测试中的缺模态回退通过显式开关演练。
2. **训练层。** 将残差模块接在现有 `ArmModel` 的特征融合位置，新增独立诊断协议。启用前核对依赖的 FT-B0 checkpoint 来自同 seed、同 manifest、完整训练预算的已完成 run。记录依赖 run ID、基线权重哈希、索引哈希、归一化版本、启用模态、训练参数和训练环境。既有 checkpoint 和账本按原流程保留。 [现有融合位置](../../workers/lim/src/lim_worker/arms.py#L455) [全量微调检查点读写](../../workers/lim/src/lim_worker/t13.py#L358)
3. **插件产物。** 单独保存分支权重和配置，绑定基线 checkpoint 哈希，并记录输入通道、归一化、融合尺度和版本。加载时拒绝不匹配的基线；关闭插件的路径直接复用 RGB 输出。联合训练若实施，单独保存组合权重。
4. **上线前验证。** CPU 用 stub 检查窗口同步、残差尺寸、缺模态与通道顺序、基线回归和存取。4090 上跑 smoke，覆盖至少两个完整累积组，并核对已走过非零学习率更新、插件权重实际变化、loss 有限且验证输出完整。正式结果作为 T13 诊断轨单列。

**排期建议。** 首批只安排数据验收、smoke 和 seed 17 的三个增量对照。已有的 seed 17 FT-B0 可作为起点；做三种子配对前，先确认 seed 42、73 的完整基线 checkpoint。两条分支都通过时，每个增量臂最多需要补 2 个种子。联合、错配及交叉注意力按门槛追加，耗时以 smoke 的每步时间和实测显存估算。

**本轮执行范围。** 评审已同意以 RGB FT-B0 为交付基线，沿用 72/8/20 图幅划分，按 0.5 个百分点增益和 15%／25% 延迟门槛推进。执行从 seed 17 的数据接入和单分支 smoke 开始。通过 smoke 后做验证集筛选，按第 4 节顺序决定后续实验。
