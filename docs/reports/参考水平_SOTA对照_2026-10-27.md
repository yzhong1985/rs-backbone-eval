# 参考水平：我们的分数处在什么位置

日期：2026-10-27
用途：回答"这些数字是什么水平"。所有外部数值来自 Prithvi-EO-2.0 论文（arXiv 2412.02732v2 / TGRS 2026）表 III–IX；"平凡解"由本地账本的混淆矩阵实算。

---

## 一、先立三把尺子

单个分数没有意义，必须和参照物比。我们有三把：

| 尺子 | 含义 | 作用 |
|---|---|---|
| **平凡解** | 全预测"最多的那一类"能拿多少分 | 下限：低于它说明模型无效 |
| **论文基线** | Prithvi 论文里 U-Net / Prithvi-EO-1.0 的数值 | 外部同级参照 |
| **论文最强** | Prithvi-EO-2.0 600M(-TL) | 该数据集公开的天花板参考 |

**注意**：论文用 10 个种子 + Optuna 调参 + UPerNet；我们 3 个种子 + 固定网格 + 轻量头。**差距有几个点属于方法差异，不是模型差异。**

## 二、五个任务的对照表

### T1 洪水（Sen1Floods11，指标 water IoU）

| 参照 | 数值 |
|---|---:|
| 平凡解（全预测陆地） | **0** |
| 论文：Prithvi-EO-1.0-100M | 79.6 |
| 论文：Prithvi-EO-2.0-300M | 82.2 |
| 论文：Prithvi-EO-2.0-300M-TL | 82.6 |
| 论文最强：600M-TL | **83.1** |
| **我们：B0（UPerNet 官方协议）** | **75.0** |
| 我们：Prithvi B1（统一轻量头） | 72.8 |
| **我们：AnySat B1** | **82.3** |
| 我们：Clay B1 / B2 | 76.0 / 77.4 |

**读法**：AnySat 已达到论文 600M 的水平（82.3 vs 83.1，差距 0.8 分，小于种子波动），说明**数据与评测管线没问题**；而我们的 B0 比同配方论文低 7.6 分 → 问题在 **B0 的训练细节**（448 输入 vs 我们的 224 裁剪 + 512 评测、没做调参搜索）。

### T2 火烧迹地（HLS burn scars，指标 burn scar IoU）

| 参照 | 数值 |
|---|---:|
| 平凡解（全预测未烧） | **0** |
| 论文：Prithvi-EO-1.0-100M | 76.8 |
| 论文：300M / 300M-TL | 79.9 / 81.1 |
| 论文最强：600M | **83.2** |
| 我们：Prithvi B1（轻量头） | **76.9** |
| 我们：Clay B1 / AnySat B1 | 63.1 / 51.9 |

**读法**：Prithvi 的 76.9 刚好落在论文 100M 与 300M 之间，**考虑到我们用的是轻量头而非 UPerNet，这是合理的**。AnySat 的 51.9 明显偏低，属于"全量微调过拟合"的已知现象。

### T3 火烧强度（5 类，指标 mIoU）

| 参照 | 数值 |
|---|---:|
| **平凡解（全预测背景）** | **14.1** |
| 论文：U-Net | 29.3 |
| 论文：300M / 600M | 29.4 / 28.6 |
| 我们：B0（50 epoch） | 15.6 |
| 我们：Prithvi B1 | **19.6** |
| 我们：Clay / Olmo / AnySat B2 | 14.8–17.7 |

**读法**：**这是唯一"离地平线很近"的任务。** 论文的 29 分几乎是我们的两倍，而我们的 B0 只有 15.6。**训练轮数已被排除**：B0 协议下 50 / 100 / 150 epoch 的 mIoU 分别为 0.1539 / 0.1530 / 0.1529（各 3 种子），延长训练没有任何增益。差距更可能来自损失函数、decoder 结构或标签映射，**目前尚未定论**，不能写成"模型能力不足"，也不能写成"只是没训够"。

### T4 滑坡（Landslide4Sense，指标 mIoU）

| 参照 | mIoU | 前景 IoU | 前景 F1 |
|---|---:|---:|---:|
| **平凡解（全预测非滑坡）** | **49.1** | **0** | **0** |
| 论文：U-Net | 70.4 | — | 59.7 |
| 论文：U-Net++ | 69.0 | — | 50.2 |
| 论文最强：600M（Lovasz） | 71.3 | — | **60.7** |
| 我们：AnySat B2（1 种子） | 69.7 | **41.1** | 58.3 |
| 我们：Clay B2（3 种子） | 66.9 | 35.3 | 52.2 |
| 我们：OlmoEarth Base B2 | 62.6 | 26.9 | 42.4 |
| 我们：OlmoEarth Tiny B2 | 60.1 | 21.8 | 35.8 |
| 我们：Prithvi B2（冻结） | 56.5 | **14.8** | 25.8 |
| 我们：Clay B1（1 种子） | 65.9 | 33.7 | 50.4 |

**读法（这段很关键）**：

1. **mIoU 在这个数据集上有欺骗性**：背景占 98.1%，全猜背景就有 49.1。所以 mIoU 0.62 和 0.70 的实际差距，远小于数字表面的差距。
2. **换成前景 IoU 后，模型差距被放大**：AnySat 0.411 vs Prithvi 冻结 0.148，**接近 3 倍**。mIoU 只显示 0.697 vs 0.565（1.23 倍）。
3. **和论文对齐要用前景 F1**：论文 L4S 表报 F1，600M 为 60.7；AnySat 58.3、Clay 52.2，属于同一档但略低。
4. **Prithvi 在 T4 冻结路径上实质失效**（前景 IoU 0.148），这与它 mIoU 0.565 "看起来还行"形成鲜明对比——**这就是必须报前景指标的理由**。

### T5 多季作物（US multi-temporal crop，13 类，指标 mIoU）

| 参照 | 数值 |
|---|---:|
| **平凡解（全预测多数类）** | **1.5** |
| 论文：U-Net | 42.6 |
| 论文：Prithvi-EO-1.0-100M | 42.7 |
| 论文：300M / 600M | 48.6 / **50.7** |
| **我们：AnySat B2S（两阶段冻结）** | **55.4** |
| 我们：Clay B2 / Prithvi B1 | 47.8 / 41.2 |

**读法**：这个任务**最难被平凡解解释**（下限 1.5），分数含金量最高。AnySat 的 55.4 超过论文 600M 的 50.7，但轨道不同（两阶段冻结 vs 全量微调），只能说明**这一格没坏**。

### T8 GF-2 25 类（域外）

| 参照 | 数值 |
|---|---:|
| 平凡解 | 1.3 |

## 2.5 去掉背景后的"前景 mIoU"（2026-10-27 补充）

多类任务的 mIoU 会被背景放大。把 class 0（背景/忽略类）剔除后重算，结论变化很大：

| 任务 | 模型 | mIoU | **去掉背景** | 解读 |
|---|---|---:|---:|---|
| T3 火烧强度 | Prithvi B1 | 0.196 | **0.082** | 4 个强度类几乎学不到 |
| T3 | OlmoEarth Base B2 | 0.177 | 0.070 | 同上 |
| T3 | Clay B2 / B1 | 0.158 / 0.148 | 0.084 / 0.066 | 同上 |
| T3 | Prithvi B0（论文协议） | 0.156 | 0.059 | 同上 |
| T5 多季作物 | AnySat B2S | 0.554 | **0.553** | 背景不主导，数字可信 |
| T5 | Clay B2 | 0.478 | 0.477 | 同上 |
| T5 | Prithvi B1 | 0.412 | 0.409 | 同上 |
| T8 GF-2 | Clay B2 / Prithvi B2 | 0.433 / 0.430 | **0.433 / 0.430** | class 0 是忽略类，本来不计入 |
| T4 滑坡 | 各模型 | 0.565–0.697 | **0.148–0.411** | 见上一节 |

**三条要点**：

1. **T3 是"看起来接近平凡解、实际上几乎为零"**：去掉背景后只有 0.05–0.08，各模型之间无实质差别。**任何"某模型在 T3 更强"的说法都不成立。**
2. **T5、T8 的分数是干净的**：去掉背景几乎不变（≤0.002），说明这两个任务的 mIoU 没有被背景注水。
3. 实现方式：**不写进 run.json**，而是由报告从混淆矩阵按任务配置计算（见 §2.3.2）。任务在 `configs/tasks/*.yaml` 里声明 `background_class`——T1/T1S/T2/T3/T4 为 0；**T5 的 class 0 是有效作物类别、T8 的 class 0 是忽略类，均不声明**，因此这两行显示"—"。早先版本按"固定剔除 class 0"实现在多类指标里，语义错误，已回退（review 2026-10-27）。

## 三、把六个数放在一起看

| 任务 | 平凡解 | 我们最好 | 论文最强 | 相对位置 |
|---|---:|---:|---:|---|
| T1 water IoU | 0 | **82.3** | 83.1 | ✅ 持平（差 0.8） |
| T2 burn IoU | 0 | 76.9 | 83.2 | 🟡 低 6 分（头不同） |
| T3 mIoU | 14.1 | 19.6 | 29.4 | 🔴 明显偏低（轮数已排除，原因未定论） |

## 四、竞赛类基准的注意事项

如果需要引用竞赛榜单（如 Landslide4Sense 挑战赛、Sen1Floods11 各类 leaderboard）：

1. **不要直接比**。竞赛榜前列通常用了**集成、自定义标签精修、测试集标注泄漏纠正**，论文自己也注明 L4S 竞赛结果"based on customized label refinement and ensemble methods"，与单模型不可比。
2. **只比"单模型 + 官方划分 + 官方指标"**这一档。
3. **报三件事**：数据集版本、划分、指标定义。缺一项就不能横向比。
