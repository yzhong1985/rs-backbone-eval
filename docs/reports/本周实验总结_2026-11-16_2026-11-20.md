# 本周实验总结（2026-11-16 至 2026-11-20）

- 快照时间：2026-11-20 09:30（北京时间）。数字取自 `/geodata/rs-eval/runs/*/run.json`，账本是唯一权威结果，本文只是快照。
- 指标：除特别说明外，都是 test 划分的 mIoU（%），3 个种子 17/42/73。“配对差”是同种子相减。
- 本周所有新跑的 run 都是诊断轨，不进 headline 和 D1。

## 1. 一句话结论

- **WHU（T13）上，推理时带 AEF 有稳定增益**：R 比 B0 高 1.93 个百分点，3 个种子都在 +1.89 到 +1.96 之间；两种置零/错配的对照与 B0 持平，所以增益来自 AEF 内容本身。
- **推理时只用影像的两条路线，目前都没有拿到这份增益**：蒸馏（D）与 B0 持平；插件（Bcap、P）比 B0 高约 0.4 到 0.5 个百分点，但 AEF 字典版（P）和随机字典版（Bcap）没有差别，说明这点增益来自插件结构，不是 AEF。
- **SpaceNet 7 变化检测（T14）第一版失败**：模型把所有像素都判成“不变”。原因已定位并修复，还没有重跑。

### 3.5 T14 SpaceNet 7 建筑变化

- 管线：两期影像经冻结 LIM 提特征，取差的绝对值 |f2 − f1| 送入 UPerNet 头。标签是“t2 有建筑、t1 没有”；云和无效像素（UDM、alpha=0）标为忽略。
- 结果：3 个种子的测试变化 F1 都是 0，mIoU 都是 0.4998，等于“全判不变”。
- 原因：训练集变化像素只占有效像素的 0.088%（945,745 / 1,073,748,114），损失没有类别权重；验证 F1 一直是 0，选模并列时保留了最早的第 5 个 epoch。用种子 17 的检查点在 20 个验证 AOI 上测，AUC 0.61，最佳阈值下 F1 只有 0.027。说明模型对变化像素的区分能力本身就弱，单靠调阈值救不回来。
- 修复：新协议 `t14_b0_wce`，变化类权重 34（负正像素比的平方根），并列时取较晚的 epoch。旧的 3 条已标为“已被取代”。新协议还没有在 GPU 上跑，修复后能提升多少目前不知道。
- 与公开结果的关系：SpaceNet 7 官方指标是按建筑实例算的 SCOT（基线 0.17，冠军 0.41；变化项基线 0.06，冠军 0.20），和我们的逐像素变化 F1 不可比。本项目按自己的像素指标报告。

## 4. 到目前为止的整体结论

1. **AEF 本身有信息量**。在 WHU 上，推理时带真实 AEF 稳定 +1.93 个百分点，并且有 null 对照排除了“结构带来的增益”。
2. **把这份信息“装进”纯影像模型，目前没有成功**。蒸馏（D）无增益；插件的 +0.4 到 +0.5 来自结构，AEF 字典和对齐损失没有额外贡献（P ≈ Bcap）。P 种子 17 还没出结果，但另外两个种子方向一致。
3. **PASTIS 上的教师蒸馏也只是小幅效应**：少标签时 +1.3，冻结读出时反而为负。和 WHU 的结论一致：教师信息在推理阶段缺席时，能保留下来的很少。
4. **业务上的含义**：如果部署时能拿到 AEF（或同类年度嵌入），R 路线已有可用增益；如果只能输入影像，目前的方法里最好的是插件结构的 +0.5 左右。这个取舍需要业务侧决定。
