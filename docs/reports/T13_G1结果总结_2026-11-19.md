# T13 G1 结果总结（WHU-OPT-SAR：B0 基线与 AEF 教师参照）

日期：2026-11-19
状态：G1 的 14 条 run 全部完成（学习率扫描 3 条；B0 的 seed 42、73；R、R_null_zero、R_null_shuffle 各 3 个种子），判据通过，可进入 G2。G2 尚未运行。

## 1. 结论

- 冻结 LIM（MiT-Huge）加 UPerNet 头、只用光学输入：B0 基线 test mIoU 为 52.57%（3 个种子的均值）。
- 加入 AEF 2019 教师输入（R）：test mIoU 为 54.50%，比 B0 高 1.93 个百分点，3 个种子都为正。
- 把 AEF 换成零（R_null_zero）或换成别的图幅的 AEF（R_null_shuffle），增益消失：分别比 B0 高 0.09 和低 0.15 个百分点。
- 按 G1 事先声明的三条判据，全部通过。

## 2. 实验设置

| 项目 | 设置 |
|---|---|
| 数据 | WHU-OPT-SAR，官方图幅级划分；manifest 共 15,000 片：train 10,800 / validation 1,200 / test 3,000 |
| 类别 | 8 类，背景（0）忽略；指标为 7 类 mIoU |
| 编码器 | MiT-Huge（LIM），冻结，fp16 在线前向 |
| 头 | UPerNet（GroupNorm，fpn 256），可训练 |
| 优化 | AdamW，weight decay 1e-4，学习率 1e-3，1 epoch warmup 后余弦衰减，有效 batch 8，20 epoch |
| 增强 | 水平和竖直翻转（影像、标签、AEF 同步） |
| 选 epoch | 每 5 epoch 验证一次，按 validation mIoU 选；test 只评一次 |
| 种子 | 17、42、73 |
| AEF | AlphaEarth 2019，10 m，64 维，重投影到影像网格 |

四个臂：

- **B0**：光学基线，不加 AEF。
- **R**：B0 加 AEF 注入，在 LIM 第 2、3 级特征上加零初始化的残差。
- **R_null_zero**：R 的结构不变，AEF 输入全零。
- **R_null_shuffle**：R 的结构不变，AEF 取自另一幅图（另一个 sheet）同一位置的 tile。

## 5. 判定（G1 预先声明的判据）

| 判据 | 结果 | 是否通过 |
|---|---|---|
| R − B0 均值 ≥ +1.0 pt，且 3/3 为正 | +1.93 pt，3/3 为正 | 通过 |
| R_null − B0 在 ±0.5 pt 以内 | zero：+0.09 pt；shuffle：−0.15 pt | 通过 |
| R − R_null ≥ (R − B0) 的一半（约 +0.97 pt） | 对 zero：+1.84 pt；对 shuffle：+2.08 pt | 通过 |

结论：在 WHU-OPT-SAR 上，AEF 对冻结的 LIM 有可迁移的增益，进入 G2（D、Bcap、P）。

## 6. 解读

- 增益来自 AEF 的内容，而不是额外的参数或结构：零输入的 R_null 与 B0 几乎没有差别。
- 增益稳定：三个种子的 R − B0 都在 1.89 至 1.96 pt 之间。B0 三个种子的标准差约 0.2 pt，远小于 1.9 pt 的增益。
- 逐类 IoU 还没有统计，所以目前不能说增益集中在哪几类。

## 7. 限制与注意事项

1. 只有 3 个种子。学习率只在 seed 17 上扫描，其他超参没有扫。
2. 预算固定为 20 epoch。validation 曲线在第 10 至 15 epoch 之后基本持平，更长的训练预计收益很小，但没有验证。
3. validation mIoU（约 0.56 至 0.59）比 test（约 0.52 至 0.55）高约 3 至 4 个百分点。这是官方划分的分布差异。选 epoch 只用 validation，test 只评一次，但两者的差距说明数字之间存在系统偏差。
4. 协议文件 `configs/protocols/whu_r_null_shuffle.yaml` 的注释写的是“同一 batch 里另一个 tile 的 AEF”，但代码（`donor_rows`）实际取的是另一幅图同一位置的 tile。代码行为和 G1 执行说明一致，注释需要修正。
5. 四个 commit（`4dd3db`、`aeb2fb`、`6beacdf`、`6cedf32`）上，T13 相关的代码和配置（worker 的 arms、mit、t13、t13_data、runner，以及 lim 模型、T13 任务和 whu 协议配置）没有改动，所以结果可以放在一起比较。
6. 没有和外部发表的数字直接比较。WHU-OPT-SAR 原论文的协议和指标我还没有核实（doi.org 无法访问）。搜索到的 OPT-SAR-MS2Net 报告 mIoU 为 45.2%，但它是光学加 SAR 的多源方法，口径不同，不能直接对照。
7. 这些结果属于 T13 的 G1 诊断结论，不属于 Prithvi 官方套件的 D1 结论，报告时要按 AGENTS.md 的规则单列。
