## 4. 读法

1. **预算收益真实但不大**：各 cell 的同 seed 配对均值只有 +0.016～+0.023。
   单看 s17 会得到 +0.02～+0.05，那是种子波动（AEF UPerNet 的 s17 是三个种子里最高的）。
2. **产品差距不随预算变化**：8ep 和 20ep 都是 +0.09 量级，说明 8epoch 的 +0.09
   主要不是预算造成的。但 UPerNet 的 loss 到第 20 轮仍以 −0.004～−0.005/epoch 下降
   （MLP 已走平到 −0.001/epoch），不能外推到更长预算。
3. **128 维的优势没有随预算扩大**：MLP 持平（+0.0349 → +0.0358），
   UPerNet 反而略降（+0.0228 → +0.0171），且 20ep 的 s73 为 −0.0187。
   8ep 的配对差已能代表维度收益。
4. **仍不是正式结果**：20ep 是对 8-epoch 主口径的敏感性诊断，`panel=diagnostic`，
   不进 headline、scorecard、Pareto 与 Portal；AEF 对照的正式口径仍为 64 维、8 epoch。
