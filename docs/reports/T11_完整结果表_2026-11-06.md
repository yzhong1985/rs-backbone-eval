## 3. 口径说明

- **BA/BAM**：AEF 2019 年度 64 维 embedding + UPerNet/MLP 头；不是 backbone，单独成轨；AEF 的 host tag 未记录（CPU 轨）。
- **BB1**：单景 S2。LIM 只解码 B04/B03/B02 三波段，其他模型 10 波段，不能单看骨干归因。
- **BBT**：20-bin 时序。AnySat 用原生时序注意力，LIM/Clay/OlmoEarth 用 LTAE2d；OlmoEarth 是 Tiny 且输入上采样到 224 px。
- **BBF/BBFL/BBF20**：20-bin + LTAE2d 全量微调。BBF 是 8-epoch baseline（1e-4），BBFL 是 8-epoch LR 探索（5e-5 / 1e-5），BBF20 是 20-epoch lr5e-5。三者分轨。
- **BBF20 与 BBT 不可直接归因**：BBF20 经过 LR 筛选且 20 epoch，BBT 是 8 epoch、未调 LR；+0.0206 只能表述为“当前调参/预算下”。
- **BBM median**：历史 median run 已 superseded，不进入正式表。
- **AEF**：10 m 年度 embedding 产品，不是高分辨率影像；不用于 iSAID/FAIR1M 级别小目标。
- **checkpoint**：BBF/BBFL/BBF20 的 `final_checkpoint.pt` 约 2.1 GB；lr1e5 的已清理；冻结/AEF 轨不保存最终权重。
