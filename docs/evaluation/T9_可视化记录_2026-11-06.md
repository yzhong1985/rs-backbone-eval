- 归一化：ImageNet RGB（与 run tags 一致）

## 图

目录：`/home/yzhong/rs-eval/audits/t9-20261106/`

| 文件 | 内容 |
|---|---|
| `t9_lim_mit_huge-T9-upernet_frozen-train-17-v4_grid.png` | 6 张测试图的汇总（每行一张图） |
| `..._P0003.png` 等 6 个 | 单图五联：RGB / ground truth / prediction / error / RGB+prediction |
| `README.md` | 图内图例与类别 id 对照 |

每行五列：

1. **RGB**：原始 iSAID 测试图；
2. **ground truth**：iSAID 调色板语义掩码；
3. **prediction**：模型全图预测；
4. **error**：正确为深灰、错误为红色；
5. **RGB + prediction**：预测半透明叠加，便于看边界。

iSAID 官方调色板本身偏暗（例如 storage_tank 是 `(0,63,63)`、Small_Vehicle 是 `(0,0,127)`），所以 GT/pred 两列在深色背景上对比度有限；看边界和错误时以第 4/5 列为准。

## 观察

- 大型目标（飞机、储罐、船只、球场）整体位置和形状基本正确；
- 小目标（Small_Vehicle、Helicopter）漏检/粘连明显，符合 0.4556 的 mIoU 水平；
- error 图中红色主要是小目标边缘和密集停放区，属于 iSAID 的典型难点；
- 这是 **同分布官方 test split** 的定性记录，不是跨区域/跨传感器泛化证据；iSAID 官方 train/val 无地理坐标，组泄漏无法排除。
