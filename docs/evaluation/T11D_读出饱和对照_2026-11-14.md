三条读出的差别只在 head：

- **z-score 原始 1024 维**：训练集每维均值/方差标准化后接 1024→N 的线性头（134k 参数）。
- **OE64 InfoNCE**：OlmoEarth v1.3 2019 教师蒸馏出的 64 维投影 + head（11k 参数）。
- **S64 标签监督**：直接用标签训 64 维瓶颈 + head（290k 参数），同一 64 维预算的上界参照。
- 另列**未标定原始 1024 维**（8 / 20 epoch 全量点）作为“不做事”的参照。

## 2. 预声明判据

2026-11-13 写死：若 80 epoch 下 NCE − z-score 的 validation 均值收敛到 0 或符号翻转，
NCE 的短预算优势属于**可优化性差异**；若仍 ≥ 0.01 且 3/3 为正，则不是短预算的假象。

## 4. 结论

**判据满足**：80 epoch 下 NCE 仍领先同预算的 z-score 原始读出（val +0.0147、test +0.0181，
3 seed × 2 split 全为正），NCE 的读出不是“小探针学不动”造成的假象。

但把判据放回三预算网格，它回答的问题和原先设想的不同：

1. **在 8 / 20 epoch 两个预算上，NCE 都落后于 z-score 原始读出**（−0.017 / −0.016 test，
   3/3 种子为负），也落后于**未标定的**原始读出（20 epoch：0.3482 vs 0.3608）。
   NCE 只在 80 epoch 领先，而那时 z-score 与 S64 都已过拟合（分别 −0.029 / −0.016）。
2. **z-score 相对未标定原始读出的“标定收益”只在短预算存在**：8 epoch +0.033，
   20 epoch 只剩 +0.004（0.3644 vs 0.3608，落在种子噪声内）。原先用 z-score@20 对比
   未标定@20 得出的“标定是主要混淆项”被本轮修正为“标定主要省的是短预算的训练时间”。
3. **80 epoch 下 OE64 NCE 与 S64 标签监督持平**（val +0.0021、test +0.0009，2/3 种子正）：
   无标签对比读出在长预算下追平同宽度的标签监督读出。
4. **S64 在 20 epoch 是全表最高点**（0.3687 test / 0.3888 val），到 80 epoch 掉回 0.3530；
   z-score 的最高点是 20 epoch 的 0.3644，NCE 的最高点是 80 epoch 的 0.3539。

因此：

- 能写的是：**对比读出不是短预算假象；长预算下它与标签监督的 64 维读出持平**。
- 不能写的是：**“NCE 比原始特征更好”**。同预算比较，NCE 在 8 / 20 epoch 都低于 z-score
  原始读出，20 epoch 也低于未标定原始读出；它唯一领先的 80 epoch 是宽头过拟合的预算点，
  而且 0.3539 仍低于 z-score 与 S64 各自 20 epoch 的峰值。
- 对整条路线：**“冻结特征 + 小头”设定下，对比蒸馏没有超过“原始特征 + 小头”的零成本基线**；
  它在长预算、64 维预算受限时追平标签监督读出，这算它的边际价值，但不是信息量优势。

## 5. 账本修正：多个已发布结论建立在 2 样本 smoke run 上

`CLAY_WORKER_EVAL_LIMIT=2`。worker 只评测 2 个 patch，但仍写 `completed` 的 `run.json`
（`tags.smoke=true`、`validation_samples_evaluated=2`、`test_samples_evaluated=2`），
文档把这些数字当成了全量结果。

### 5.1 因此作废或改写的结论

- `T11D_对比学习蒸馏对照_实验说明_2026-11-13.md` §7：
  - (a) “无教师 NCE = 0.2105，远低于 0.334 → 教师的结构确实有贡献”：**定性保留**
    （重跑后 0.2259，仍远低于 OE64 的 0.3340），数字换成全量值。
  - (b) “z-score = 0.3254，NCE 的相对优势压到 +0.009”：**方向反转**。全量重跑后
    z-score = 0.3511，比 OE64 NCE（0.3340）**高 0.017**，3/3 种子为正。
  - §7.2 “稳的结论”第 2 条改写为：对比读出没有超过标准化后的原始读出，8 / 20 epoch
    同预算下还低 0.016～0.017。
- `蒸馏训练预算与学习率对照_执行说明_2026-11-13.md`：
  - P4 的“冻结读出几乎不随探针预算变化”**不成立**：原始 8→20 是 +0.042，O64 余弦
    +0.026，只有 S64 的涨幅最大（+0.051）。
  - 同预算排序中 `原始 0.3294`、`O64 余弦 0.3048`、`S64 0.3745` 三行改为全量值
    0.3608 / 0.3265 / 0.3687；`原始+z-score 0.3644` 本来就是全量，可用。
  - “标定是主要混淆项”修正为“标定主要省短预算训练时间”：20 epoch 下未标定原始仅比
    z-score 低 0.004。
  - P1（10% 标签、80 epoch）的“教师差 +0.0021 → 短训练伪影确认”**暂作废**，等重跑。
- `docs/reviews/审查响应_2026-11-13_第7轮.md` §7 的同一张表：加更正指针。

## 7. 局限

- 20 / 80 epoch 用的是不同总步数的余弦日程（14560 vs 58240 步），不是同一条 schedule 的前缀。
- 探针不按 validation 选 epoch，“20 epoch 峰值”只说明各自收敛后的终态；40 epoch 等中间预算未测。
- 未标定原始 1024 维没有 80 epoch 点，`20 → 80` 的过拟合判断只覆盖 z-score / NCE / S64。
- 只做 Clay T11D + OE64 教师；T11P 三主干、AnySat、A8/A32 未覆盖。
- 三 seed 是工程复核，不是跨区域/跨事件泛化证据；P1 的 10% 标签结论仍待重跑。
