## 1. 预先声明的判据（跑之前写死）

主指标：探针 test mIoU，同一种子配对，n=3。对照值（跑前用 run.json 核一遍）：

| 教师 | 余弦（已有） | MSE（`T11DMSE`，已有） | S64 标签监督 | 原始 1024 维 |
|---|---:|---:|---:|---:|
| OE64 | 0.2963 / 0.3045 / 0.3023 → **0.3010** | 0.2910 / 0.2904 / 0.2967 → **0.2927** | 0.3174 | 0.3185 |
| A64 | 0.2811 / 0.2962 / 0.2845 → **0.2873** | 0.2602 / 0.2722 / s73 待核 | 0.3174 | 0.3185 |

| 结果（对比 − 余弦，配对均值） | 结论 |
|---|---|
| 两个教师都 < +0.01 | 对比学习也不行；原设计第四至六阶段**关闭** |
| 某教师 ≥ +0.01 且 3/3 为正，但仍 < S64（0.3174） | “对比学习比余弦好一些，但仍不如直接用标签”；阶段结论不变，补一句 |
| 某教师 ≥ S64 且 3/3 种子都 ≥ 该种子的 S64 | “对比学习能追上标签监督”，**修改阶段结论 §3.1**，并建议在 T11P 上复核 |
| 超过原始 1024 维（0.3185） | 同上，且需要先排查是否有泄漏或评测问题 |

另外报告：val cosine（对比学习不直接优化它，偏低不代表失败）、检索准确率（见 §3.4）。

## 2. 对比学习在这里具体是什么

一句话：**学生某个位置的向量，要和“教师在同一位置的向量”最像，和“教师在别的位置的向量”
不像。** 余弦蒸馏只管“和对的那个像”；对比学习还要求“和错的那些不像”，因此会更关注
不同地物之间的差别。

```
一个 batch 里取 N 个有效 token（学生 z_i，教师 t_i，都做 L2 归一化）
相似度矩阵 S[i, j] = z_i · t_j / τ
损失 = 交叉熵(S 的每一行, 正确答案是第 i 列)          # 学生 → 教师
     + 交叉熵(S 的每一列, 正确答案是第 i 行)           # 教师 → 学生（对称）
     ÷ 2
```

即 CLIP 式的对称 InfoNCE，只是“图文对”换成了“同一位置的学生 token / 教师 token”。

## 3. 实现（`workers/clay/src/clay_worker/rgbn.py`）

### 3.1 协议与 target

```python
DISTILL_PROTOCOLS |= {
    "clay_rgbn_distill_o64_nce": ("oe64nce", "olmoearth-2019", 64),
    "clay_rgbn_distill_a64_nce": ("aef64nce", "aef-2019", 64),
}
PROBE_PROTOCOLS |= {
    "clay_rgbn_probe_o64_nce": ("distilled", "oe64nce"),
    "clay_rgbn_probe_a64_nce": ("distilled", "aef64nce"),
}
DISTILL_LOSS |= {
    "clay_rgbn_distill_o64_nce": "infonce",
    "clay_rgbn_distill_a64_nce": "infonce",
}
```

新 target 名保证投影器发布路径独立，不覆盖余弦 / MSE 的投影器。投影器结构不变
（`build_projector(1024, 64)`：1024→256→64），探针代码不改。

### 3.2 一个 batch 怎么组（这是关键，按下面固定，不要自行调）

现有蒸馏循环一步取 2 个 patch（`range(0, len(order), 2)`），每个 patch 16×16=256 个 token，
一步最多 512 个 token。对比学习需要足够多的负样本，所以**本分支改成一步取 8 个 patch**：

| 项 | 取值 | 说明 |
|---|---|---|
| 每步 patch 数 | 8 | 只在 `infonce` 分支生效；余弦 / MSE 分支仍为 2，**不得改变** |
| 每步 token | 从 8 个 patch 的有效 token 中**无放回随机抽 1024 个**（不足就全用） | 抽样用 `torch.Generator().manual_seed(1_000_000 * seed + 1_000 * epoch + step)`，不消耗全局 RNG |
| 温度 τ | **0.07**，固定 | 不扫参；在 tags 里记录 |
| 相似度 | 学生、教师都先 L2 归一化 | 教师 token 是块内平均后的向量，长度不为 1，同样要归一化 |
| 损失 | 对称 InfoNCE（§2） | |
| 学习率、epoch、优化器 | 与余弦组相同（`3e-3`、8、AdamW wd=1e-4） | 不调 |

为什么每步换成 8 个 patch：负样本只来自同一步的 token；如果只有 2 个 patch，大部分负样本
来自同一块田附近，太容易，也太容易“误伤”。8 个 patch 来自不同地块，负样本更有代表性。
每步样本数变多、步数变少（约 182 步/epoch，余弦组约 728 步），这在 tags 里如实记录即可，
是对比学习本身的需要。

### 3.3 假负样本

同类地物的不同位置会被当成负样本（比如两块小麦田）。原设计 §4.3 提到可以用“空间间隔筛选、
类别辅助”来处理。**本轮不处理**：
- 类别辅助会用到标签，那就不再是“只看教师”的对照了；
- 跨 8 个 patch 随机抽 token 已经降低了同一地块的比例。

在结果里写明“未做假负样本处理”。如果结果接近 S64 但差一点，这是下一步唯一值得做的改进。

### 3.4 记录与选择

- 每个 epoch 在验证集上记录：
  - `val_infonce`（用同样的抽样规则，固定种子，保证每个 epoch 可比）；
  - `val_cosine`（和余弦 / MSE 组可比）；
  - `val_retrieval_top1`：在验证集抽样的 token 集合里，学生向量最相似的教师向量是不是
    同一位置的那个（衡量“能不能认出自己”）。
- 选最佳 epoch：按 `val_infonce` 最小。
- tags：`distill_loss="symmetric InfoNCE over sampled observed tokens"`、`distill_selection="val_infonce"`、
  `infonce_temperature="0.07"`、`infonce_tokens_per_step="1024"`、`infonce_patches_per_step="8"`、
  `false_negative_handling="none"`；`writer.complete` 的说明文字按实际损失写。
- 继续写 `mean_baseline_val_cosine` / `mean_baseline_val_mse`（复用已有函数）。
