# 非 RGB 波段解析主干：补充实验设计

日期：2026-10-16。状态：设计草案，尚未实现或运行新增实验。

前提：系统已经拥有较强的 RGB 视觉主干。本阶段面向近红外、短波红外、热红外和 SAR，设计并选择能够解析这些观测的主干，同时验证其与现有 RGB 主干的互补性。现有 RGB 主干的具体型号、特征接口和部署预算尚未写入本文，实验实施前补齐；不以某个未经确认的 RGB 模型代替它。

数据和原论文实验的核对依据见[公开评测与红外／SAR 数据调研](./AnySat_Clay_OlmoEarth公开评测与红外SAR数据调研_2026-10-16.md)。本文定义下一步实验和判断标准，不把模型支持某传感器、前向能运行或已有论文成绩视为本项目的验证结果。

## 1. 目标与需要回答的问题

新增主干的目标是提取 RGB 难以直接表达的光谱、温度和微波观测信息，输出可供分割、变化检测、回归等任务使用的空间和时序特征。

重点回答四个问题：

1. **独立解析能力**：只输入非 RGB 波段，能否在相应任务上获得有效、可迁移的表征？
2. **对 RGB 的增量价值**：现有 RGB 主干加入新增分支后，是否在相同样本和预算下获得稳定收益？
3. **可见光不足时的可用性**：RGB 缺失或质量下降时，非 RGB 分支能否独立工作，或者提高系统可用性？
4. **收益与代价**：所获效果是否值得新增的训练、推理、显存、数据处理和部署成本？

“非 RGB 单独超过 RGB”不是所有任务的必要条件。融合带来稳定收益，或在 RGB 缺失条件下仍可完成任务，都可能构成实际价值；具体结论需对应相应实验。

当前 T1～T7 保留为既有光学任务与参考结果。新增实验需要明确记录输入子集和模型分支，不能把已有六／十波段实验直接改名为“非 RGB 主干实验”。

## 2. 输入范围与主干职责

| 输入类型 | 典型输入 | 主要验证方向 | 需要区分的事项 |
| --- | --- | --- | --- |
| 近红外 NIR | S2 B8/B8A、HLS 对应 NIR | 植被、水体、作物状态 | 与红边分别记录；不能把含 RGB 的完整 S2 输入算作 NIR-only |
| 短波红外 SWIR | S2 B11/B12、HLS SWIR1/2 | 火烧迹地／强度、植被水分等 | 优先复用 T2/T3；效果与机理假设仍需消融验证 |
| 热红外 TIR | Landsat B10/B11，或 ST_B10 等温度派生产品 | 云／云影解析、农业时序中的热状态信息 | Level-1 DN、辐亮度、亮温、地表温度分别定义，不能混用缩放和统计量 |
| SAR | Sentinel-1 VV/VH 时间序列 | 洪水、森林变化、作物、生物量 | dB／线性功率、轨道和校正产品需固定；VV/VH 比值属于派生特征 |

NIR/SWIR 反射率、TIR 温度／辐射和 SAR 后向散射具有不同数据语义。候选架构可以共享高层空间编码器，但必须先验证各模态的输入模块、归一化和有效性标识；不预设“只给一个波长就能统一处理所有模态”。

## 3. 候选系统结构

### 3.1 基础结构

```text
RGB 影像 ──────────> 已有 RGB 主干 ────────────┐
                                             ├─> 特征对齐／轻量融合 ─> 任务头
非 RGB 观测 ─> 模态输入模块 ─> 非 RGB 主干 ────┘
                  │                │
                  │                └─> 可选时序聚合
                  └─> 波段、量纲、时间、GSD、有效性标识

非 RGB 主干也单独接任务头，评估独立解析能力。
```

第一阶段固定已有 RGB 主干的权重，新增分支先使用现有遥感预训练模型验证。先比较简单、可解释的特征融合；交叉注意力、复杂门控及联合微调放在有增量收益之后。

### 3.2 主干设计选项

| 方案 | 定义 | 本轮用途 |
| --- | --- | --- |
| 模态专用主干 | 分别选择／训练反射光谱、TIR、SAR 编码器 | 建立各模态有效性的起点，量化统一模型可能付出的代价 |
| 模态输入模块＋共享主干 | 各模态使用独立输入模块和统计量，再进入共享空间编码器 | 优先研究的统一结构；与专用方案比较效果及参数／推理成本 |
| 原生多模态预训练主干 | 使用 AnySat、Clay、OlmoEarth 已有模态接口 | 作为现成候选和参考，不自动等于满足非 RGB-only 输入约束 |

本文不直接决定最终必须采用一个统一主干。先完成模态能力和互补性验证，再判断统一编码与专用分支的取舍，避免仅依据接口形式选择架构。

### 3.3 新主干的输出与训练目标

新主干需要输出空间特征而非只有一个全局向量，第一版统一记录：

- 空间特征及其实际 stride／GSD；若提供多尺度特征，记录每一级的地理覆盖与有效区域。
- 时序特征、真实日期和有效时相 mask；单日期输入作为明确的特例。
- 输入传感器、波段及数值域，缺失波段／像素的有效性标识；不能由填充值隐式推断缺失。
- 可选的 pooled embedding，用于场景分类；分割和回归保留空间输出。

初期用监督下游实验判断这些特征是否有效，再决定是否进行统一预训练。新架构若进入预训练阶段，至少比较以下目标：

| 目标 | 目的 | 对照要求 |
| --- | --- | --- |
| 本模态掩码预测／重建 | 保留光谱、温度、后向散射本身的信息 | 按各模态数值域与有效区域定义损失，不直接把不同量纲误差相加 |
| 时序表征学习 | 利用同地点跨日期观测，支持状态变化与时序解析 | 日期选择、云／nodata mask 固定；不强行让真实变化前后表征完全一致 |
| 配对 RGB 特征对齐／蒸馏（可选） | 利用已有强 RGB 主干的空间和语义知识 | 与不蒸馏版本对照；只在可靠配准的有效观测区域施加约束 |
| 下游监督适配 | 使输出可被任务头解码，并量化迁移成本 | 固定分割／回归头和搜索预算；与现成预训练主干及随机初始化比较 |

RGB 蒸馏只作为可选辅助目标。若仅要求非 RGB 特征复现 RGB 特征，可能削弱那些 RGB 本来难以表达的温度／微波信息；因此需保留本模态目标，并用 N 独立任务和 F 的增量收益检查是否发生信息损失。损失权重、共享层数和输入模块设计均由开发集选择，不通过测试集调节。

## 4. 最小对照组

设 RGB 输入为 R，选定非 RGB 输入为 N；不同数据集中的 N 必须在运行记录中具体列出，不能统一写成“多光谱”。

| 编号 | 输入及系统 | 回答的问题 |
| --- | --- | --- |
| R | RGB → 已有 RGB 主干 → 任务头 | 当前系统基线 |
| N | 非 RGB → 候选主干 → 同类型任务头 | 非 RGB 独立解析能力 |
| F | RGB 主干特征＋非 RGB 主干特征 → 简单融合 → 任务头 | 新增分支对已有系统的实际增益 |
| C | RGB → 增加可比容量的投影／解码模块 → 任务头 | F 的收益是否主要来自更大的融合器或任务头 |
| I | 候选分支预训练初始化与同架构随机初始化分别运行 | 区分预训练与架构／容量的贡献 |

公平性要求：

- R、N、F、C 使用相同地理样本、标签、时段、划分和评价器。N 可增加的日期数量必须单列，不把多日期收益误写成波段收益。
- RGB 基线必须使用用户现有强 RGB 主干，而不是仅取某个遥感模型的 RGB 子集代替。可以另外报告遥感模型的 RGB 子集，但名称应区分。
- R 的任务头与 F 的任务头／融合器按预设规则控制容量。C 应尽量匹配新增可训练容量，并同时披露整个系统的总参数量和计算量；不能声称匹配了全部主干成本。
- 初期 RGB 主干冻结。候选主干的冻结探针和下游适配分别成表，不用一个模型的全量微调结果对比另一个模型的冻结结果。
- I 的两个初始化使用一致的冻结／解冻规则和预算；冻结随机特征与可训练随机主干是两个不同对照，不混为一组。
- BraDD-S1TS 等未提供配对 RGB 的数据，先做 N；若另外下载光学影像再做 F，应形成新增配准数据版本，并重新审计可用样本和日期。

F−R 是非 RGB 分支在指定融合和预算下的系统增益，不能单独归因为某一波段的物理作用。需要进一步的输入消融和 C／I 对照辅助解释。

P0 先覆盖三类新增观测：反射光谱、热红外、SAR。任务并非理论上必须依赖这些波段；增量大小、独立可解码性和适用场景由实验判断。

### 5.1 红外实验的具体输入组合

在 I1 上按以下组合分别训练，使用相同样本和时间窗口：

1. RGB；
2. NIR-only；
3. SWIR1＋SWIR2；
4. NIR＋SWIR1＋SWIR2；
5. RGB 主干＋组合 4 的非 RGB 分支。

红边可在作物任务另加，不混入 I1 首轮。T3 同时提供三期观测时，应另列单期／三期结果；不能用三期非 RGB 对照单期 RGB 后直接解释为光谱增益。

H1 的热红外增益至少比较“相同非热红外光学输入”与“该光学输入＋B10/B11”。仅比较 RGB 与完整 Landsat 全波段，会同时引入 NIR、SWIR、卷云等信息，不能把全部差值归因于 TIR。需要同时保留强 RGB 基线 R，区分系统选型与 TIR 归因两类结论。

### 5.2 SAR 与模态缺失

S1 首轮使用配对样本的交集，分别报告 RGB、SAR、RGB＋SAR。光学与 SAR 的实际拍摄日期、时间差、产品级别和空间对齐误差要记录。

同时报告 SAR 有数据但 RGB 缺失的样本覆盖率与 SAR-only 效果。真实云遮挡分组需有可审计质量信息；人工遮挡仅作为诊断，不能等同于真实云天泛化。只用“所有模态都有”的交集评测，不能代表系统在全部业务输入上的可用性。

## 6. 候选模型与输入门禁

| 候选 | 优先验证内容 | 实施前必须核实 |
| --- | --- | --- |
| AnySat | S1 时序、光学非 RGB、原生多模态特征 | 公开 S2 入口固定十波段，NIR/SWIR-only 不能默认原生可用；L8 的实际有效通道和缺失 mask 路径需检查 |
| Clay v1.5 | 可变光学波段、S1 表征 | 每个输入子集的波段顺序、传感器元数据、归一化；标准 Landsat 配置不含 TIR，新增 TIR 是适配实验 |
| OlmoEarth v1.2 | S1/S2/Landsat，含热红外的潜在迁移能力 | 具体权重的 bandset、缺失波段标识和特征输出；官方支持模态与本项目 worker 已接通范围分别记录 |
| Prithvi-EO-2.0 | 现有六波段光学对照、NIR/SWIR 适配参考 | 当前参考入口没有原生 SAR/TIR 依据；新增输入需要适配，单列成本和协议 |
| 轻量监督编码器 | 每种 N 输入的可训练起点 | 使用相同原始信息和任务头；它检验实际投入收益，不能单独用于归因大模型的预训练效果 |

对于固定通道入口，可比较显式可训练输入适配器、经验证的原生缺失通道机制、重设输入模块三种办法，但需要给出独立配置与训练状态。只有波段子集本身作为真实观测输入，不以补零后标称“完整传感器输入”绕过门禁。

适配器位于冻结主干之前且需要训练时，梯度仍必须经过主干；不能使用 `no_grad()` 切断它，也不能按纯冻结特征缓存估算训练成本。

## 7. 数据划分、校准和空间约束

### 7.1 分组与数据独立性

- 优先保留可复用的官方划分；额外建立地理／事件独立评价时，保存新的 manifest 和分组规则，单独报告。
- 同一地块、原影像、火灾事件的相邻裁块和多个日期绑定分组，禁止先裁块后随机分配导致跨集合泄漏。
- SPARCS 首轮先审计原始 Landsat 场景与重叠范围，再锁定分组和划分；80 个影像子集不直接等同于 80 个独立场景。
- SICKLE 在作者 test 未公开时，锁定可用 train 内的开发划分，作者 validation 用作项目最终评价集；禁止用同一个 validation 同时调参和当作独立 test。结果明确标为项目协议。
- 披露候选模型的预训练覆盖：AnySat 使用过 PASTIS-HD 等数据来源，相关下游结果与完全外部数据集泛化分开解释。

### 7.2 产品与数值域

- 反射率、辐射／温度和后向散射分别记录单位、scale/offset、有效值与 nodata。学习得到的统计量只来自训练集；使用官方预训练统计量时记录来源与匹配条件。
- SPARCS 为历史 Pre-Collection 数据，按配套元数据校准；不能套用 Landsat Collection 2 温度缩放常数。QA、云掩膜和人工标签不作为云分割输入。
- SICKLE `ST_B10` 是温度派生输入，不是原始热辐射 DN；不能用同一个 ST_B10 同时作为输入和回归目标来证明热状态解析能力。
- SAR 固定 GRD/RTC 等产品选择、轨道和线性／dB 转换；派生比值记录计算域，不对 dB 值直接套用线性功率比的含义。

### 7.3 对齐和分辨率

输入和特征对齐使用地理范围、GSD、时间和有效区域，不只按张量尺寸缩放。记录原生分辨率及重采样方式；例如 Landsat 8/9 TIR 的原生采样约 100 m，重采样为 30 m 不代表新增了 30 m 独立热信息。[USGS 波段说明](https://www.usgs.gov/faqs/what-are-band-designations-landsat-satellites)

不同模型可以使用各自合适的 token 网格，但须覆盖同一物理范围，评价在共同标签网格与有效掩膜上进行。地理位置／日期元数据的使用也要记录，避免把额外元数据收益归为新增波段收益。

## 8. 训练与评估流程

### 阶段 A：数据与接口验收

P0 每项先选少量分组检查：波段数值与空间对齐、真实有效通道、前向输出、梯度是否到达计划训练的模块、忽略标签和指标。小样本过拟合检查用于发现训练问题，不作为泛化成绩。

先完成单卡小规模试跑，再执行至少一轮完整训练和一次评价，测量实际显存峰值。短探针能跑通不足以证明长训练稳定，也不能证明吞吐优于其他 batch 设置。

### 阶段 B：低成本候选筛选

先做 S1、I1、H1，每项固定一个开发种子 42，使用按分组抽取的固定 10% 训练子集。首轮以冻结主干＋轻量头检验可解码性；确需输入适配器时单列适配参数与成本。

每项在启动前锁定 optimizer-step 预算、评价频率、搜索次数和验证集选择规则，并写入实验配置。不同任务可用不同预算；同一对照中的候选采用相同预算规则。具体数值依据阶段 A 的耗时和可用资源确定，不能运行后按测试结果追加某个模型预算。

先用 N 筛去明显无效／不可接入的候选，再对留下者完成 R、F、C，避免一开始铺开所有数据、模型、融合器的笛卡尔积。

### 阶段 C：正式验证

冻结候选、输入方式、融合器和超参后，使用 17、42、73 三个训练种子。报告单个种子、均值和标准差，不挑最好种子。选定任务补充 10%、30%、100% 的嵌套分组训练子集，评价少标注价值。

先比较冻结和轻量适配；只有结果表明值得投入时，再单列部分／全量微调。不同种子从同一指定预训练初始化独立训练。

评价时按影像／事件／区域进行配对重采样，比较 F 与 R 的差值；全局 IoU 的区间通过每次重采样重新累计混淆矩阵计算。像素数不能当作独立统计样本数。

### 阶段 D：实用性验证

增加一个地理或时间独立划分，评价自然质量分组和缺模态条件，确认融合收益是否仅存在于同分布样本。缺失模态分别报告有无相应训练策略，不能要求未训练的融合器自动处理任意缺失输入。

在实际计划部署的 GPU 上记录吞吐与显存；固定有效 batch、输入范围、时相、精度和预热规则。若比较 A100 与 4090，分别列出结果，不跨硬件直接比较每轮时间。

## 9. 输出表与选择标准

| 维度 | 必须输出 |
| --- | --- |
| 独立能力 | N 的绝对 IoU/F1/RMSE，低标注和域外结果 |
| RGB 互补 | R、F、C 的绝对成绩；F−R 或误差下降及配对区间 |
| 模态归因 | 相同其他输入下增加／去除 NIR、SWIR、TIR、SAR 的重新训练对照 |
| 缺失可用性 | 各输入组合的覆盖率、有效样本数、实际缺失情况下的任务效果 |
| 使用成本 | 总参数、训练参数、MACs/可用计算量估计、端到端延迟、吞吐、训练 GPU 小时 |
| 资源稳定性 | 训练及评价的峰值 allocated/reserved 显存、设备总占用，OOM 与重试情况 |
| 可复现性 | manifest、划分、波段／单位、源码与权重版本、训练设置、种子、任务头与融合器配置 |

分割增益按百分点报告；回归同时给出原始误差与误差减少量，统一说明越大／越小越好。各类指标保留原始单位，不把它们直接平均为一个“非 RGB 能力分”。

选择标准在阶段 B 结束后、正式 test 前锁定：

1. 非 RGB 输入路径语义正确，计划训练的模块确实得到梯度，完整运行稳定。
2. 在预先指定的关键场景获得可重复的融合收益，或在 RGB 不可用场景满足业务效果要求。
3. 增益经过头部容量、初始化、时相和样本差异的对照后仍有解释力。
4. 成本满足部署预算；具体显存／延迟上限需根据实际系统补齐，不在本文臆定。

若只有个别模态有效，允许采用专用分支；如果更大模型或更复杂融合没有稳定增益，保留较简单方案。结论应说明“在哪些波段、任务和观测条件下值得加入该主干”。

## 10. 与当前工程及已运行实验的关系

- 正在进行的 T5 和其他既有运行继续按原协议归档，不把新设计套回历史结果，也不修改正在续训的源码或设置。
- T1S 可作为 S1 的起点，但需补齐强 RGB 基线、配对样本审计和融合对照；当前单路 SAR 入口不是完整双主干系统。
- T2/T3 当前 worker 使用六波段适配路径。I1 的 NIR/SWIR-only 必须新增真实输入子集处理和相应适配器，不能仅改任务名称或 YAML 波段列表。
- H1、BraDD、融合器及相关数据管线目前是待实现内容；不能因为公开数据和预训练权重存在，就标记为已支持。
- 纯冻结且输入固定时可以缓存特征；存在会更新的输入适配器时不能复用过期特征。费用分别记录特征提取、头训练和完整适配。
- checkpoint 需保持模型结构、输入协议、优化器与有效 batch 等身份一致；更改结构或训练设置形成新实验，不强行加载旧断点续训。

## 11. 第一批交付范围

第一批只做 **S1：SAR 洪水、I1：NIR/SWIR 火烧解析、H1：TIR 云分割**，交付各任务的数据审计、输入支持矩阵、R/N/F/C 对照结果和精度—成本表。三类观测验证完成后，再决定是否投入统一主干预训练，以及加入 BraDD、PASTIS-R、BioMassters、SICKLE 等时序／融合任务。
