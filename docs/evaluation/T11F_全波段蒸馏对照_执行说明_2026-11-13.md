# T11F：全波段（S2 十波段）蒸馏对照（执行说明，交给 agent）

- 日期：2026-11-13
- 背景：同事报告“Clay 和其他主干蒸馏教师有收益”，他们用的是全波段输入；本路线的 T11D
  用 RGB+NIR 四波段，T11P 用六波段（含 SWIR）、4 期。本实验回答：**换成 PASTIS S2 全部
  十个波段（20 期，与 T11D 同一时间规则），教师项 / 蒸馏读出的结论会不会变？**
- 只做 Clay（十波段是 Clay `sentinel-2-l2a` 的原生输入，无需适配器）。
- 全部是诊断（`panel: diagnostic`），不进 headline / scorecard / Portal。
- 规模：冻结 4 组 + B 层 2 组，3 个种子，约 24 条 run；**GPU 约 2.5 h**（先跑 seed 17 约 50 min）；
  工程约半天。

## 2. 协议（全部 `tasks: [T11F]`、`seeds: [17, 42, 73]`、`epochs: 8`、`panel: diagnostic`）

配方与 T11D 对应协议**完全一致**，只换任务；协议 ID 用 `clay_s2ten_` 前缀：

| 组 | 协议 | 对应 T11D 协议 | 说明 |
|---|---|---|---|
| 冻结 | `clay_s2ten_probe_raw` | `clay_rgbn_probe_raw` | 原始 1024 维，时间平均 |
| 冻结 | `clay_s2ten_probe_s64` | `clay_rgbn_probe_s64` | 标签监督 64 维投影 |
| 冻结 | `clay_s2ten_distill_o64` → `clay_s2ten_probe_o64` | `clay_rgbn_distill_o64` / `probe_o64` | 余弦蒸馏 OE64 |
| 冻结 | `clay_s2ten_distill_o64_nce` → `clay_s2ten_probe_o64_nce` | `…_o64_nce` | InfoNCE 蒸馏 OE64（配方同 T11DNCE） |
| B 层 | `clay_s2ten_ft_last4_raw1024` | `clay_rgbn_ft_last4_raw1024` | 末 4 块 + 1024 维宽头，仅标签 |
| B 层 | `clay_s2ten_ft_last4_raw1024_distill` | 新增（T11D 没有宽头+教师） | 同上 + 独立 128 维 teacher projector 的 OE128 余弦，权重 1.0 |

- 新 target 名（如 `oe64ten`、`oe64tennce`）保证投影器路径独立。
- B 层两臂：先建 head、再建 teacher projector；显式按 `1000*seed+epoch` 打乱；有效 batch 2，
  **每 2 个 patch 一次优化器步（每 epoch 728 步）**——上一轮 Clay 宽头就错在这里，加断言。
- `matrix.py` 每个探针 / B 层一个新 track，全部进 `DIAGNOSTIC_TRACKS`。

## 3. 预先声明的判据（跑之前写死）

同一种子配对，n=3。和 T11D（四波段）的对应值放在同一张表里对照。

| 比较 | 判定 |
|---|---|
| B 层（+ 教师）−（仅标签） | ±0.01 内：全波段下教师项仍约等于 0。≥ +0.01 且 3/3 为正：**全波段下教师有收益**，与同事结论一致，修改阶段结论并说明“取决于输入波段”。≤ −0.01 且 3/3 为负：教师有害 |
| O64 余弦 − 原始 | 同上三档；≥ +0.01 且 3/3 为正才说明全波段下余弦蒸馏读出超过原始特征 |
| O64 NCE − 原始、− S64 | 只描述，与 T11D 的 +0.016 / +0.017 对照 |
| 原始（十波段）− 原始（四波段，T11D） | 只描述：多出的六个波段本身值多少 |

## 4. 运行

- 先 GPU smoke：每个新协议一条（`-smoke`，限样本），包括 B 层两臂；确认缓存指纹、
  教师 token 读取、步数（smoke 下按实际行数算）。
- lane `T11FBAND`：

  ```text
  RS_EVAL_MANIFEST=<T11F manifest>
  for seed in 17 42 73:
    clay_s2ten_probe_raw
    clay_s2ten_probe_s64
    clay_s2ten_distill_o64      → clay_s2ten_probe_o64
    clay_s2ten_distill_o64_nce  → clay_s2ten_probe_o64_nce
    clay_s2ten_ft_last4_raw1024
    clay_s2ten_ft_last4_raw1024_distill
  ```

  第一条 run 会构建特征缓存。时间紧时先只跑 `seed 17`，看方向后再补 42/73。
- 预计：冻结组单条 2～3 min，B 层单条约 20 min；三种子合计约 2.5 h。
