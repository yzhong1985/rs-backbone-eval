## 2. 统一配方（所有臂相同）

冻结 LIM（fp16 在线前向）+ GroupNorm UPerNet 头（fpn 256）；20 epoch；AdamW wd 1e-4；
1 epoch 线性 warmup + 余弦衰减；有效 batch 8；水平/竖直翻转（影像、标签、AEF 同步）；
每 5 epoch 验证一次，按验证集 mIoU 选 epoch，test 只评一次。种子 17/42/73。

## 3. 步骤与预声明判据（跑之前写死）

### 3.1 学习率扫描（seed 17）

`whu_b0_lr1e4` / `whu_b0`（1e-3）/ `whu_b0_lr3e3`。

- 按 **validation** mIoU 选，不看 test。
- 最高者与 1e-3 相差 < 0.005 时取 1e-3（其余臂的协议已按 1e-3 写好）。
- 若胜出者不是 1e-3：先为 R / R_null / D / Bcap / P 补同学习率的协议，再开 3.2，
  并在本文件写明。

### 3.2 B0 与 R（3 种子）

B0（选定学习率）补 seed 42/73；`whu_r`、`whu_r_null_zero`、`whu_r_null_shuffle` 各 3 种子。

| 比较（同种子配对，test 7 类 mIoU） | 判定 |
|---|---|
| R − B0 | 均值 ≥ **+1.0 pt** 且 3/3 为正：教师有用，进入 G2（D / Bcap / P） |
| R_null − B0（零输入、跨片打乱各自） | 均值在 ±0.5 pt 内：R 的增益不是多出来的参数造成的 |
| R − R_null | 必须 ≥ R − B0 的一半；否则 R 的增益主要来自结构，G2 的 P 门槛按 R_null 重算 |
| R − B0 < +1.0 pt 或不是 3/3 为正 | **停在 G1**：AEF 在 WHU 上对冻结 LIM 没有可迁移的增益，D / P 无从谈起；写结论，不开 G2 |

报告：每种子 test/validation、选中 epoch、配对差、逐类 IoU（看增益集中在哪几类）。

## 4. 时间估算

smoke 测得每 batch 约 0.35～0.5 s（含读盘），单条完整 run 约 2.5～3.5 h（R 比 B0 多读 AEF）。

| 步骤 | run 数 | GPU |
|---|---:|---:|
| 3.1 学习率扫描 | 3 | 约 8～9 h |
| 3.2 B0 补种子 + R + R_null×2 | 2 + 9 | 约 30～35 h |

先跑 3.1，看完 validation 再排 3.2。若时间紧，R_null 可先只跑 seed 17，
在 R − B0 处于临界（+1.0 附近）时再补。
