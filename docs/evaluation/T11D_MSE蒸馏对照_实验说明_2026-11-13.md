## 1. 要回答的问题与预先声明的判据

**问题：** 把余弦损失换成 MSE，蒸馏出的 64 维特征在 PASTIS 分割上会不会更好？

**主指标：** 探针 test mIoU，**同一种子配对**（MSE − 余弦），n=3。

| 结果 | 结论 |
|---|---|
| 两个教师的配对均值都在 ±0.01 内 | 损失函数不是瓶颈，阶段结论不变 |
| 某个教师 ≥ +0.01 且 3/3 种子为正 | 记为“MSE 有小幅帮助”；再和原始特征 0.3185、S64 0.3174 比，**只有超过原始特征**才改变阶段结论 |
| 某个教师 ≤ −0.01 且 3/3 种子为负 | 记为“MSE 更差” |

判据先写在这里，跑完后不改。三个种子全部报告。

## 3. 参考值：“全部预测成平均向量”能拿多少（已算好）

用于判断余弦和 MSE 的数值到底有多大意义。做法：训练集所有有效 token 的教师向量取
平均，得到一根“平均箭头”，拿它去预测验证集每个 token（token 聚合方式与
`teacher_tokens` 相同：8×8 像元块内对有效像元取平均）。

| 教师 | 验证集 token 数 | 平均箭头的 val cosine | 平均箭头的 val MSE（= 总方差） | token 向量长度（p10 / p50 / p90） |
|---|---:|---:|---:|---|
| OE64 | 123,392 | **0.781** | 0.03246 | 2.07 / 2.25 / 2.52 |
| AEF64 | 123,392 | **0.766** | 0.00612 | 0.94 / 0.98 / 1.00 |

据此可以先读出两点：

- 余弦组的 0.95 明显高于“平均箭头”的 0.77～0.78，**蒸馏确实学到了平均值以外的东西**，
  不是空洞的高分。
- AEF token 的长度几乎都接近 1，**长度里基本没有信息**，所以 AEF 上 MSE 与余弦应当
  差不多；OE token 的长度有 ±10% 的变化，MSE 在 OE 上才有可能学到额外的东西。

## 4. 实现

### 4.1 工作方式（重要）

- **在独立 worktree 里开发**（`git worktree add ../rs-backbone-eval-mse main`）。部署仓库
  `/home/yzhong/projects/rs-backbone-eval` 里有正在跑的 lane，worker 每条 run 启动时都会
  读这里的 `rgbn.py`。在这里改代码会改变后续 run 的代码，并让它们带上 `-dirty`。
- **lane 在跑时不要改 `scripts/rerun_baselines.sh`**（bash 是边跑边读脚本的，T11O20 出过事）。
  开跑前检查：`pgrep -af 'rerun_baselines.sh --detached'` 必须为空。
- 部署仓库目前有一个未提交的文档修改（`docs/evaluation/教师蒸馏_当前状态总结_2026-11-12.md`），
  它会让新 run 带上 `-dirty`。开跑前要么提交，要么先确认归属再处理，**不要直接丢弃**。

### 4.2 代码改动（`workers/clay/src/clay_worker/rgbn.py`）

1. **新的 target 名**，避免和余弦组的投影器路径冲突：

   ```python
   DISTILL_PROTOCOLS = {
       ...,
       "clay_rgbn_distill_o64_mse": ("oe64mse", "olmoearth-2019", 64),
       "clay_rgbn_distill_a64_mse": ("aef64mse", "aef-2019", 64),
   }
   PROBE_PROTOCOLS = {
       ...,
       "clay_rgbn_probe_o64_mse": ("distilled", "oe64mse"),
       "clay_rgbn_probe_a64_mse": ("distilled", "aef64mse"),
   }
   # 未列出的蒸馏协议一律是 cosine，保证旧路径不变
   DISTILL_LOSS = {
       "clay_rgbn_distill_o64_mse": "mse",
       "clay_rgbn_distill_a64_mse": "mse",
   }
   ```

   `TARGET_TREE_DIMS` 和 `DISTILL_PROTOCOLS_BY_TARGET` 是由 `DISTILL_PROTOCOLS` 推出来的，
   会自动包含新 target。

2. **MSE 损失**（新函数，不改 `_cosine`）：在 token 有效掩膜上，对**不做长度归一化**的
   预测与教师向量求逐维平方误差，再取平均。

   ```python
   def _masked_mse(prediction, target, mask):
       # prediction/target: (B, D, 16, 16); mask: (B, 16, 16) bool
       error = ((prediction - target) ** 2).mean(dim=1)
       return error[mask].mean()
   ```

   不做逐维标准化。OE64 各维标准差在 0.11～0.32 之间，最多差 3 倍，可以接受。

3. **`_train_distill` 按 `DISTILL_LOSS` 分支**：
   - 训练损失：`cosine` 时为 `1 − _cosine(...)`（原样不动），`mse` 时为 `_masked_mse(...)`。
   - 验证集上**两个量都算**：val cosine 和 val MSE。
   - 选最佳 epoch：`cosine` 组按 val cosine 最大（原样），`mse` 组按 val MSE 最小。
   - 写入指标：保留 `val_cosine`；`mse` 组另加 `val_mse`（direction=minimize）。
   - tags：`distill_loss` 按实际损失写（`mse` 组写
     `"mean((z - teacher)^2) over observed tokens, no L2 normalisation"`）；新增
     `distill_selection`（`val_cosine` / `val_mse`）。
   - `writer.complete(...)` 的说明文字里目前写死了 `cosine loss`，改成按实际损失写。
   - **可选（建议做）**：在 `mse` 组额外写两个 tag
     `mean_baseline_val_cosine` / `mean_baseline_val_mse`（训练集平均向量对验证集的结果），
     和 §3 的数值核对，允许 ±0.005 的差异（worker 按 2-patch batch 求平均，§3 是按 token）。

4. **探针不用改**：`_train_probe` 的 `distilled` 分支按 target 名加载投影器，新 target 会
   自动加载 MSE 投影器。确认 `projector_source_path` 指向
   `projector/oe64mse/...` / `projector/aef64mse/...`。

## 5. 运行

```bash

        # MSE-vs-cosine distillation control (diagnostic). Distill before probe
        # for each seed: the probe loads the projector the distill run publishes.
        export RS_EVAL_RERUN_STOP_ON_FAIL=1
        TASK=T11D
        export RS_EVAL_MANIFEST=/geodata/rs-eval/data/manifests/T11D/8e674fc75f1b878cf4688a323666e68601b6ffb1baa942bac6029795b45541a6.jsonl
        for seed in 17 42 73; do
            for teacher in o64 a64; do
                run_named clay_v1_5 "clay_rgbn_distill_${teacher}_mse" "$seed" \
                    "clay_v1_5-T11D-clay_rgbn_distill_${teacher}_mse-train-${seed}"
                run_named clay_v1_5 "clay_rgbn_probe_${teacher}_mse" "$seed" \
                    "clay_v1_5-T11D-clay_rgbn_probe_${teacher}_mse-train-${seed}"
            done
        done
        ;;
```
