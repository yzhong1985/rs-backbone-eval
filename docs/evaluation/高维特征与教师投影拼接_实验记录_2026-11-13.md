三臂：

| 臂 | head 输入 | 说明 |
|---|---|---|
| R | F，1024 维 | 新头，不使用源 head |
| X | `[F, N(E_init(F))]`，1152 维 | E 与 T 同结构，未训练 |
| T | `[F, N(E_best(F))]`，1152 维 | E 由阶段 A 用教师余弦训练 |

`N(z)=sqrt(128)*z/max(||z||₂,1e-6)`，沿通道。X/T 的 head 第一层复制 1024 通道权重，新增 128 通道初始化为 0，因此训练前 logits 与 R 一致。

## 3. 预声明判据与结论

方案 §8 的门槛：

- T−R：三 seed validation 均为正，且平均差 ≥ 0.01 → **未达到**（三 seed 全负，均值 −0.0077）。
- T−X：三 seed validation 均为正，且平均差 ≥ 0.01 → **未达到**（seed 73 为负，均值 +0.0114）。

因此按预声明规则，本轮结论是：

> **当前"冻结 F + 教师投影拼接"配方没有显示稳定收益；T 相对只读 F（R）在三个种子上都略低。**

补充解读（不改变上面的判定）：

1. T 相对随机投影 X 在 seed 17/42 有正效应（+0.023 / +0.019），但 seed 73 反转（X 0.4736 > T 0.4662，甚至略高于 R）。这说明该配方对种子敏感，不能把 T−X 的正值稳定归因于教师信息。
2. T−R 的负值在所有种子上一致，说明增加一条 128 维分支本身没有帮助，反而轻微稀释了 1024 维原始读出的训练。
3. 这并不否定"教师信息有用"的其它路径（例如把教师当辅助损失、或继续训练主干），只否定本方案"冻结 F 后拼接教师投影"这一种读出方式。
